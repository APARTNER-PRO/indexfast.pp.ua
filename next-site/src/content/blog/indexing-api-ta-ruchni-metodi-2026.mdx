## Чому нові сторінки не з'являються в Google

Власники сайтів часто стикаються з тим, що нові сторінки тижнями не з'являються в пошуку. Алгоритми стали вибагливішими, і звичайна індексація сторінок в Google тепер займає більше часу, ніж раніше. Якщо вам потрібно швидко заявити про себе, стандартних інструментів може бути недостатньо.

Ця проблема особливо болюча для:
- Інтернет-магазинів з десятками нових товарів щодня
- Блогів з регулярними публікаціями
- Нових сайтів, які працюють над наповненням контентом
- Сайтів після редизайну або масового оновлення контенту

## Спосіб 1: Google Search Console — ручна відправка

Найпростіший спосіб — вручну ввести URL в інструмент перевірки URL в Search Console і натиснути "Запитати індексацію". Це хороший метод для 1-2 сторінок, але якщо їх сотні, цей підхід не працює.

Ліміти ручної відправки:
- Максимум 10–15 URL на день
- Немає можливості відстежити статус кожної відправки
- Потребує постійної ручної роботи

Для невеликих сайтів з рідкими оновленнями цього достатньо. Для всього іншого — потрібні інші методи.

## Спосіб 2: Карта сайту (sitemap.xml)

Базовий елемент SEO. Ви додаєте карту в консоль, і краулер поступово її обходить. Sitemap повідомляє Google про існування сторінок, але не прискорює їхню індексацію.

Проблема в тому, що "поступово" може означати тижні або навіть місяці. Googlebot обходить sitemap за власним розкладом, спираючись на crawl budget сайту.

Що робить sitemap:
- Повідомляє Google про нові і оновлені сторінки
- Допомагає краулеру знайти всі URL на сайті
- Не гарантує швидкості індексації

## Спосіб 3: Google Indexing API — потужний інструмент

Google Indexing API — офіційний інструмент від Google, призначений переважно для сторінок з вакансіями або трансляціями, який багато хто намагається адаптувати для звичайних сайтів.

На відміну від sitemap, API дозволяє безпосередньо повідомляти Google про нові URL і ініціювати їхнє сканування. Результат — індексація за години замість днів і тижнів.

Налаштування вимагає технічних знань:
- Реєстрація в Google Cloud Console
- Створення сервісного акаунту
- Отримання JSON-ключа
- Написання коду для відправки POST-запитів
- Додавання email сервісного акаунту як власника в Search Console

Ліміти: 200 запитів на день на сайт за замовчуванням. Для більшості проектів цього достатньо.

## Чому виникають складнощі

Часто в панелі вебмайстра можна побачити статус "Виявлено, не проіндексовано". Це означає, що Google знає про сторінку, але не вважає її пріоритетною для сканування.

Причини цього статусу:
- Низький crawl budget для нового сайту
- Відсутність зовнішніх посилань на сторінку
- Сторінка не знаходиться через внутрішню структуру посилань
- Дублікат контенту або тонкий контент
- Високий рівень конкуренції в ніші

Щоб ускорити індексацію сторінки в таких випадках, потрібен зовнішній поштовх — і саме тут допомагає Google Indexing API.
