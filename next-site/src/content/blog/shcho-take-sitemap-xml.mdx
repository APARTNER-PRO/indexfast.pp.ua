## Що таке sitemap.xml?

      
Sitemap (карта сайту) — це XML-файл, який містить список всіх важливих URL вашого сайту. Він розміщується за адресою <code>https://your-site.com/sitemap.xml</code> і є своєрідним «путівником» для пошукових роботів.

      
Уявіть, що ваш сайт — це великий офісний будинок. Без плану поверхів прибиральник (Googlebot) буде блукати коридорами навмання, можливо так і не знайшовши деяких кімнат. Sitemap — це саме той план, який показує де що знаходиться.


      <div>
        **📌 Офіційна позиція Google**
        
Google рекомендує використовувати sitemap для будь-якого сайту з більш ніж 500 сторінок, нових сайтів з мало зовнішніх посилань, а також для сайтів з медіаконтентом (відео, зображення).

      </div>

      
## Структура sitemap.xml

      
Базовий sitemap виглядає так:


      <div><span>&lt;?xml version="1.0" encoding="UTF-8"?&gt;</span>
<span>&lt;urlset</span> xmlns=<span>"http://www.sitemaps.org/schemas/sitemap/0.9"</span><span>&gt;</span>

  <span>&lt;url&gt;</span>
    <span>&lt;loc&gt;</span>https://your-site.com/about<span>&lt;/loc&gt;</span>
    <span>&lt;lastmod&gt;</span>2026-01-20<span>&lt;/lastmod&gt;</span>
    <span>&lt;changefreq&gt;</span>monthly<span>&lt;/changefreq&gt;</span>
    <span>&lt;priority&gt;</span>0.8<span>&lt;/priority&gt;</span>
  <span>&lt;/url&gt;</span>

  <span>&lt;url&gt;</span>
    <span>&lt;loc&gt;</span>https://your-site.com/blog/post-1<span>&lt;/loc&gt;</span>
    <span>&lt;lastmod&gt;</span>2026-01-15<span>&lt;/lastmod&gt;</span>
    <span>&lt;changefreq&gt;</span>weekly<span>&lt;/changefreq&gt;</span>
    <span>&lt;priority&gt;</span>0.6<span>&lt;/priority&gt;</span>
  <span>&lt;/url&gt;</span>

<span>&lt;/urlset&gt;</span></div>

## Типи sitemap


      
### Звичайний sitemap

      
Перелік URL у форматі XML. Підходить для сайтів до 50 000 сторінок.


      
### Sitemap Index

      
Якщо у вас більше 50 000 URL або файл перевищує 50 МБ — використовуйте sitemap index. Це «файл-батько», який посилається на окремі sitemap-файли:


      <div><span>&lt;sitemapindex</span> xmlns=<span>"http://www.sitemaps.org/schemas/sitemap/0.9"</span><span>&gt;</span>
  <span>&lt;sitemap&gt;</span>
    <span>&lt;loc&gt;</span>https://your-site.com/sitemap-pages.xml<span>&lt;/loc&gt;</span>
  <span>&lt;/sitemap&gt;</span>
  <span>&lt;sitemap&gt;</span>
    <span>&lt;loc&gt;</span>https://your-site.com/sitemap-products.xml<span>&lt;/loc&gt;</span>
  <span>&lt;/sitemap&gt;</span>
  <span>&lt;sitemap&gt;</span>
    <span>&lt;loc&gt;</span>https://your-site.com/sitemap-blog.xml<span>&lt;/loc&gt;</span>
  <span>&lt;/sitemap&gt;</span>
<span>&lt;/sitemapindex&gt;</span></div>

## Як зареєструвати sitemap в Google

      
Мати sitemap — недостатньо. Google має знати де він знаходиться. Є два способи:


      
### Спосіб 1: через robots.txt

      <div>User-agent: *
Allow: /

Sitemap: https://your-site.com/sitemap.xml</div>

      
### Спосіб 2: через Google Search Console

      

        - Відкрийте Search Console → оберіть ваш сайт.

        - У лівому меню: Індексування → Sitemap.

        - Введіть URL вашого sitemap та натисніть «Надіслати».

      


      
## Поширені помилки з sitemap

      

        - **URL з noindex** — не включайте в sitemap сторінки з тегом <code>noindex</code>.

        - **Биті посилання** — всі URL у sitemap мають повертати код 200, не 301 або 404.

        - **Неоновлена дата lastmod** — якщо вказуєте lastmod, оновлюйте її реально при змінах.

        - **Sitemap не в robots.txt** — Google може просто не знайти ваш файл.

        - **Відносні URL** — використовуйте тільки абсолютні URL з <code>https://</code>.
