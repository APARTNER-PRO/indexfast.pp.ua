## What is IndexNow?

      
IndexNow is an open-source ping protocol created by **Microsoft (Bing) and Yandex**. It allows websites to instantly notify search engines whenever a page is created, updated, or deleted.

      
Instead of search engines pulling data from your site on their own slow schedule, IndexNow allows your site to <em>push</em> data to search engines immediately — the moment content changes.


      <div>
        **💡 Does Google use IndexNow?**
        
No. Google uses its own proprietary Google Indexing API. This is why you need a tool that supports <em>both</em> the Google API and IndexNow to cover 100% of the search market.

      </div>

      
## How IndexNow Works

      
The protocol is elegantly simple. When you publish or update a page, your server sends a single HTTP request to any IndexNow-compatible search engine. That search engine then shares the notification with all other participating engines.


      
### A basic IndexNow ping looks like this:

      <div>POST https://api.indexnow.org/indexnow
Content-Type: application/json

{
  "host": "your-website.com",
  "key": "your-api-key",
  "urlList": [
    "https://your-website.com/new-page",
    "https://your-website.com/updated-page"
  ]
}</div>

      
## The Problem: Manual Setup is Difficult

      
While the concept of IndexNow is brilliant, the manual setup process is highly technical. To configure it yourself, you must:

      

        - Generate a unique API key (an 8–128 character hexadecimal string).

        - Create a <code style="background:rgba(255,255,255,0.06); padding:2px 6px; border-radius:4px;">.txt</code> file named with your API key and upload it to your web server root.

        - Configure your CMS or server to automatically trigger a POST request to the IndexNow endpoint every time you publish or update content.

        - Handle errors, retries, and rate limits in your custom script.

      


      <div>
        **⚠️ Common Mistake**
        
Many developers forget to re-ping the API after content updates, only after new posts. Google and Bing both treat significant page updates as important indexing signals. Missing updates means slower re-ranking.

      </div>
