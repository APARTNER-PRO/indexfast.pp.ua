ℹ️
Co to jest interfejs API indeksowania Google? Oficjalne narzędzie Google do powiadamiania wyszukiwarki o nowych lub zaktualizowanych stronach. Umożliwia wysłanie do 200 adresów URL dziennie za darmo i uzyskaj odpowiedź w ciągu 24-48 godzin.

⚡ Szybki start

Aby rozpocząć korzystanie z IndexFast, musisz wykonać 3 kroki. Cały proces trwa około 10-15 minut.

1
Utwórz konto usługi w Google Cloud

Idź do konsola.cloud.google.com, utwórz nowy projekt (lub wybierz istniejący) i włącz go Interfejs API indeksowania wyszukiwania internetowego. Utwórz konto usługi i prześlij klucz JSON.

Szczegółowe instrukcje znajdują się w dziale 🔑 Konto serwisowe.

2
Dodaj konto usługi do Search Console

У Konsola wyszukiwania Google dodaj swój adres e-mail konta usługi jako pełnomocnika właściciel strona

Szczegółowe instrukcje znajdują się w dziale 🔗 Konsola wyszukiwania.

3
Połącz witrynę ze swoim kontem osobistym

Zarejestruj się lub zaloguj Szafka IndexFast. Dodaj witrynę, wstaw klucz JSON konta usługi, a indeksowanie rozpocznie się automatycznie.

✅Wymagania

Zanim zaczniesz, upewnij się, że masz:

1
Konto Google

Wymagane, aby uzyskać dostęp do Google Cloud Console i Google Search Console.

2
Witryna zweryfikowana w Google Search Console

Twoja domena musi zostać zweryfikowana pod adresem Konsola wyszukiwania Google dowolną dostępną metodą.

3
Plik sitemap.xml

Twoja witryna musi być publicznie dostępna mapa witryny.xml. IndexFast odczytuje go, aby uzyskać listę adresów URL do zaindeksowania.

4
Klucz JSON konta usługi

Plik pobrany z Google Cloud Console .json z prawami do interfejsu Web Search Indexing API.

💡
Jeśli Twojej witryny nie ma jeszcze w Search Console, dodaj ją najpierw i potwierdź własność. Szczegółowa instrukcja dostępna jest pod adresem witryna Google’a.

☁️ Ustawienia Google Cloud

Włączenie API

Przejdź do konsoli Google Cloud → Interfejsy API i usługi → Biblioteka. Znajdź to „API indeksowania wyszukiwania internetowego” i naciśnij Włączać.

⚠️
Co ważne API musi być włączone w projekcie, z którym połączone jest Twoje Konto Usługi. Jeśli API nie zostanie aktywowane, pojawi się błąd 403 dostępNieskonfigurowany.

Tworzenie konta usługi

Konto usługi to konto techniczne niewymagające hasła, którego IndexFast używa do autoryzacji interfejsów API Google. Aby go utworzyć, potrzebujesz projektu w Google Cloud.

🛠
Zanim zaczniesz, włącz Indexing API w swoim projekcie poprzez narzędzie do strojenia. Bez tego kroku pojawi się błąd 403 dostępNieskonfigurowany.
1
Otwórz sekcję Konta usług

Idź do Google Cloud Console → IAM i administrator → Konta usług. W razie potrzeby wybierz żądany projekt.

2
Kliknij „Utwórz konto usługi”

Wpisz nazwę, np IndexFast-boti opis. Identyfikator można pozostawić automatyczny. Trzask „Utwórz i kontynuuj”.

Sekcja „Prawa dostępu” nie trzeba wypełniać - kliknij "Kontynuować", Następnie "Zrobione".

3
Utwórz klucz JSON

Otwórz nowo utworzone konto → zakładka Klawiatura → Dodaj klucz → Utwórz nowy klucz. Wybierz format JSON i naciśnij "Tworzyć".

Plik zostanie automatycznie pobrany na Twój komputer — jest to jedyna kopia klucza. Przechowuj go w bezpiecznym miejscu i nigdy nie publikuj go w Git ani w publicznych repozytoriach.

💡
Plik JSON powinien wyglądać tak - jeżeli struktura jest inna oznacza to, że klucz został wygenerowany niepoprawnie.
JSON konto-usługi.json 
{
  typ: „konto_usługi”,
  „id_projektu”: „identyfikator-twojego projektu”,
  „id_klucza_prywatnego”: „abc123…”,
  „klucz_prywatny”: "-----ROZPOCZNIJ KLUCZ PRYWATNY RSA-----\n...",
  „e-mail_klienta”: "[e-mail chroniony]",
  „id_klienta”: „123456789”,
  "auth_uri": „https://accounts.google.com/o/oauth2/auth”,
  „token_uri”: „https://oauth2.googleapis.com/token”
}

🔗 Połączenie z Search Console

Bez tego kroku interfejs API zwróci błąd 403 Zabronione nawet z właściwym kluczem. Konto Usługi musi otrzymać status właściciela witryny w Google Search Console.

1
Zweryfikuj własność witryny

Idź do Konsola wyszukiwania Google i sprawdź, czy witryna należy do Ciebie - w dowolny dostępny sposób (rekord DNS, plik HTML itp.).

2
Skopiuj adres e-mail konta usługi

Otwórz pobrany plik JSON i zlokalizuj pole e-mail_klienta. E-mail wygląda tak:

nazwa-konta@nazwa-projektu.iam.gserviceaccount.com

Na przykład: [e-mail chroniony]

3
Dodaj konto usługi jako wyznaczonego właściciela

W Search Console wybierz swoją witrynę → Ustawienia → Zweryfikowani właściciele → Dodaj właściciela. Wpisz adres e-mail konta usługi i potwierdź.

⚠️
Rola jest dokładnie taka, jaka jest potrzebna Właściciel (nie „Pełny dostęp”). Bez tego interfejs API powróci 403 Zabronione.
4
Poczekaj 1-2 minuty

Prawa nie są stosowane natychmiast. Następnie IndexFast będzie mógł wysyłać adresy URL do indeksowania w Twojej witrynie.

🗺 Mapa witryny.xml

IndexFast odczytuje Twoje mapa witryny.xml aby uzyskać adresy URL do przesłania do indeksowania. Obsługiwane są wszystkie formaty.

Obsługiwane formaty

  • ✅ mapa witryny.xml — standardowy plik z adresem URL
  • ✅ sitemap_index.xml — plik nadrzędny z linkami do mapy witryny podrzędnej (dowolna głębokość zagnieżdżenia)
  • ✅ Mapa witryny z tagami — filtrowanie według daty aktualizacji

Gdzie znaleźć adres URL mapy witryny

Standard: /sitemap.xml WordPress (Yoast): /sitemap_index.xml Shopify: /sitemap.xml Laravel: /sitemap.xml
⚠️
Co ważne Mapa witryny musi być publicznie dostępna bez autoryzacji. Sprawdź, czy plik otwiera się w przeglądarce bez logowania. Jeśli jest zamknięty, IndexFast nie będzie mógł go odczytać.

⚙️Jak działa usługa

IndexFast automatycznie odczytuje Twoje mapa witryny.xml i wysyła adres URL za pośrednictwem interfejsu Google Indexing API. Nie trzeba instalować żadnego skryptu - wszystkie operacje wykonywane są na serwerach IndexFast.

1
Dodajesz witrynę do szafki

Podaj domenę, adres URL mapy witryny.xml i wstaw klucz JSON konta usługi. IndexFast sprawdza dostępność mapy witryny i zapisuje ustawienia.

2
IndexFast odczytuje mapę witryny

Usługa obsługuje zwykłe mapy witryn i Indeks mapy witryny (przystawki o dowolnej głębokości). Adresy URL są automatycznie umieszczane w kolejce zgodnie z dziennym limitem Twojego planu.

3
Adresy URL są wysyłane do Google

Usługa wykorzystuje Twoje konto usługi do autoryzacji i wysyła adres URL za pośrednictwem oficjalnego interfejsu API Google Indexing. Wynik widzisz w czasie rzeczywistym na swoim koncie osobistym.

📊
Limity zależą od planu: Start – 10 adresów URL/dzień, PRO – 100 adresów URL/dzień, Agencja – 1000 adresów URL/dzień. Limit jest aktualizowany codziennie o godzinie 00:00.

🤖 Automatyczny harmonogram

IndexFast rozpoczyna indeksowanie automatycznie — nie ma potrzeby konfigurowania cron ani utrzymywania serwera. Usługa działa całodobowo po stronie IndexFast.

💡
Aby rozpocząć indeksowanie ręcznie, naciśnij „▶ Uruchom” na swoim koncie osobistym obok wybranej witryny. Wynik pojawi się w logach w ciągu minuty.

Jak zarządzać indeksowaniem

1
Tryb aktywny

Strona ze statusem Aktywny automatycznie wysyła adresy URL w ramach dziennego limitu. Limit jest dzielony równo pomiędzy wszystkie aktywne strony konta.

2
Pauza

Jeśli chcesz tymczasowo zatrzymać indeksowanie witryny - kliknij „⏸” w biurze Limit dzienny nie jest wykorzystany. Możesz przywrócić w dowolnym momencie.

3
Uruchomienie ręczne

Trzask „▶ Uruchom” — a IndexFast natychmiast wyśle ​​adres URL z mapy witryny w ramach pozostałego dziennego limitu. Wygodne po opublikowaniu nowych stron.

🖱 Ręczne indeksowanie

Oprócz trybu automatycznego IndexFast umożliwia w każdej chwili rozpoczęcie indeksowania ręcznego – bezpośrednio z konta osobistego.

1
Otwórz szafkę

Idź do IndexFast.pp.ua/app/dashboard i znajdź żądaną witrynę na liście.

2
Kliknij „▶ Start”

IndexFast natychmiast odczyta mapę witryny i wyśle ​​adres URL w ramach pozostałego dziennego limitu.

3
Zobacz wyniki w logach

Odpowiedzi Google API pojawiają się w zakładce Logi w ciągu 1-2 minut. Możesz zobaczyć stan każdego adresu URL: 200 OK, 403lub inną odpowiedź.

ℹ️
Indeksowanie ręczne wykorzystuje ten sam dzienny limit, co indeksowanie automatyczne. Jeśli limit zostanie osiągnięty, IndexFast umieści adres URL w kolejce na następny dzień.

📊 Limity API

Google zapewnia bezpłatny limit y 200 adresów URL dziennie na konto usługi. IndexFast automatycznie monitoruje limit i zatrzymuje się po jego osiągnięciu.

📡 Dokumentacja API

Upoważnienie

Używa Google Indexing API OAuth 2.0 za pośrednictwem konta usługi. IndexFast obsługuje autoryzację automatycznie – potrzebujesz jedynie klucza JSON.

Punkt końcowy, który ma otrzymać token:

HTTP
POST https://oauth2.googleapis.com/token

Typ zawartości: application/x-www-form-urlencoded

typ_grantu=urn:ietf:params:oauth:grant-type:jwt-bearer
&twierdzenie={JWT_TOKEN}

  „adres URL”: „https://twoja-witryna.com/nowa-strona”,

❓ Często zadawane pytania

Jak długo trwa indeksowanie po przesłaniu?

Google zazwyczaj przetwarza żądania w ramach 24–48 godzin. W większości przypadków strony pojawiają się w wyszukiwaniu już następnego ranka po wysłaniu.

Czy można przesłać więcej niż 200 adresów URL dziennie?

200 adresów URL to standardowy bezpłatny limit Google. W razie potrzeby możesz złożyć wniosek o zwiększenie limitu poprzez Google Cloud Console. IndexFast automatycznie zatrzymuje się po osiągnięciu limitu i wznawia następnego dnia.

Czy korzystanie z interfejsu Indexing API jest bezpieczne dla SEO?

Tak, to prawda urzędnik metoda zalecana przez samo Google. Brak ryzyka kary lub obniżenia ratingu – wręcz przeciwnie, szybsza indeksacja poprawia konkurencyjność.

Indeks map witryn czy zwykła mapa witryny?

IndexFast obsługuje oba typy. Jeśli przekażesz link do sitemap_index.xml — skrypt automatycznie ominie wszystkie załączone pliki i zapisze wszystkie adresy URL.
