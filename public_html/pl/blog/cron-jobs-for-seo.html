Cron Jobs dla SEO: Automatyzacja rutyny

Cron to harmonogram zadań w systemie Linux, który pozwala na uruchamianie skryptów według harmonogramu. Dla SEO oznacza to automatyczne aktualizacje mapy witryny, regularne wysyłanie adresów URL do indeksacji, generowanie raportów bez udziału człowieka.

Czym jest Cron i Crontab?

Cron to demon, który uruchamia zaplanowane polecenia. Crontab to plik konfiguracyjny.

Każdy wiersz w crontab ma format:

* * * * * polecenie │ │ │ │ └── dzień tygodnia (0-7, 0 i 7 = niedziela) │ │ │ └──── miesiąc (1-12) │ │ └────── dzień miesiąca (1-31) │ └──────── godzina (0-23) └────────── minuta (0-59)

Praktyczne przykłady dla SEO

Codzienna indeksacja przez IndexFast

Jeśli używasz skryptu PHP IndexFast do wysyłania adresów URL przez Google Indexing API:

# Uruchamiaj codziennie o 6:00 rano 0 6 * * * php /var/www/html/google_indexing.php >> /var/log/indexing.log 2>&1
💡 >> i 2>&1

Symbol >> dopisuje wyjście do pliku dziennika. 2>&1 przekierowuje błędy tam również.

Aktualizacja mapy witryny

# Aktualizuj mapę witryny co 6 godzin 0 */6 * * * php /var/www/html/generate_sitemap.php

Co tygodniowy audyt SEO

# W każdą niedzielę o 3:00 — sprawdzanie uszkodzonych linków 0 3 * * 0 python3 /scripts/check_links.py >> /var/log/links_audit.log

Pinging Google po aktualizacji

# Pinguj Google co 30 minut o aktualizacji mapy witryny */30 * * * * curl -s "https://www.google.com/ping?sitemap=https://yoursite.com/sitemap.xml" > /dev/null

Jak skonfigurować Crontab

  1. Połącz się z serwerem przez SSH
  2. Otwórz edytor crontab: crontab -e
  3. Dodaj wiersze z zadaniami (format opisany powyżej)
  4. Zapisz plik (w nano: Ctrl+O, Enter, Ctrl+X)
  5. Sprawdź, czy zadanie zostało dodane: crontab -l

Cron do automatycznej indeksacji z IndexFast

Skrypt PHP IndexFast jest idealny do cron. On:

  • Odczytuje adresy URL z sitemap.xml
  • Wysyła je przez Google Indexing API
  • Loguje wyniki każdego żądania
  • Zatrzymuje się, gdy osiągnięta zostanie dzienna kwota (200 adresów URL)

Monitorowanie Cron Jobs

Domyślnie cron wysyła wyjście na e-mail root. Aby otrzymywać e-maile, dodaj:

MAILTO="[email protected]"

Lub sprawdź dziennik systemowy: grep CRON /var/log/syslog
