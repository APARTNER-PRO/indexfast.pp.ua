Cron Jobs dla SEO: Automatyzacja

Cron to harmonogram zadań w systemie Linux.

Co to jest Cron i Crontab?

Cron uruchamia zaplanowane polecenia.

Format:

* * * * * komenda │ │ │ │ └── dzień tygodnia │ │ │ └──── miesiąc │ │ └────── dzień miesiąca │ └──────── godzina └────────── minuta

Praktyczne przykłady dla SEO

Codzienne indeksowanie z IndexFast

Jeśli korzystasz z IndexFast:

# Uruchamiaj codziennie o 6:00 0 6 * * * php /var/www/html/google_indexing.php >> /var/log/indexing.log 2>&1
💡 >> i 2>&1

Do zapisu logów.

Aktualizacja sitemap

# Aktualizuj co 6 godzin 0 */6 * * * php /var/www/html/generate_sitemap.php

Cotygodniowy audyt SEO

# Sprawdź uszkodzone linki 0 3 * * 0 python3 /scripts/check_links.py >> /var/log/links_audit.log

Pingowanie Google

# Pinguj co 30 minut */30 * * * * curl -s "https://www.google.com/ping?sitemap=https://yoursite.com/sitemap.xml" > /dev/null

Jak skonfigurować crontab

  1. Połącz się przez SSH
  2. Otwórz edytor: crontab -e
  3. Dodaj zadania
  4. Zapisz plik
  5. Sprawdź: crontab -l

Jeśli nie masz SSH

Większość paneli hostingowych to posiada.

⚠️ Ważne: Ścieżki bezwzględne

Zawsze podawaj pełne ścieżki w cron.
