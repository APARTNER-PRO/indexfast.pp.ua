FAQ

Preguntas frecuentes

Una vez enviadas a través de IndexFast, Google normalmente indexa las páginas en un plazo de 24 a 48 horas. es normal un escaneo del robot de Google puede tardar desde 2 semanas hasta varios meses.

Google proporciona una cuota de 200 URL por día de forma gratuita a través de la API de Indexing. Plan IndexFast Gratis gestiona automáticamente esta cuota. La cuota se puede ampliar a las tarifas Pro y Agency.

Para un uso básico, solo necesita conectar una cuenta de Google Search Console y especificar una URL mapa del sitio.xml. Se incluyen instrucciones paso a paso. Para la automatización a través de cron, necesitará lo básico conocimientos de linux.

IndexFast utiliza únicamente la API oficial de indexación de Google. Este es el método recomendado por Google para aceleración de la indexación. Sin riesgos para su sitio.

Sí, IndexFast también es totalmente compatible con el protocolo IndexNow. Esto significa que sus enlaces se envían automáticamente no sólo a Google, sino también a Bing, Naver, Seznam.cz y Yep al mismo tiempo.

IndexFast funciona con cualquier sitio que tenga un sitemap.xml: WordPress, Webflow, Wix, personalizado. si su sitio tiene un mapa del sitio: IndexFast funciona con él.

Las tarifas Pro y Agency llevan un planificador incorporado. En el plan gratuito, puedes configurar una tarea cron en el servidor: las instrucciones detalladas se encuentran en la documentación.
