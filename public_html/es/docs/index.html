ℹ️
¿Qué es la API de indexación de Google? Herramienta oficial de Google para notificar al buscador sobre páginas nuevas o actualizadas. Permite enviar a 200 URL por día gratis y obtenga una respuesta dentro de 24-48 horas.

⚡ Inicio rápido

Para comenzar con IndexFast, debe completar 3 pasos. Todo el proceso dura entre 10 y 15 minutos.

1
Crear una cuenta de servicio en Google Cloud

Ir a consola.cloud.google.com, cree un nuevo proyecto (o seleccione uno existente) y habilítelo API de indexación de búsqueda web. Cree una cuenta de servicio y cargue una clave JSON.

Las instrucciones detalladas están en la sección 🔑 Cuenta de servicio.

2
Agregar cuenta de servicio a Search Console

У Consola de búsqueda de Google agregue el correo electrónico de su cuenta de servicio como delegado el dueño sitio

Las instrucciones detalladas están en la sección 🔗 Consola de búsqueda.

3
Conecte el sitio en su cuenta personal

Regístrate o inicia sesión ÍndiceGabinete rápido. Agregue el sitio, inserte la clave JSON de la cuenta de servicio y la indexación comenzará automáticamente.

✅ Requisitos

Antes de comenzar, asegúrese de tener:

1
cuenta de google

Requerido para acceder a Google Cloud Console y Google Search Console.

2
Sitio verificado en Google Search Console

Su dominio debe ser verificado en Consola de búsqueda de Google por cualquier método disponible.

3
El archivo sitemap.xml

Su sitio debe tener disponible públicamente mapa del sitio.xml. IndexFast lo lee para obtener una lista de URL para indexar.

4
Clave JSON de cuenta de servicio

Archivo descargado de Google Cloud Console .json con derechos sobre la API de indexación de búsqueda web.

💡
Si su sitio aún no está en Search Console, agréguelo primero y confirme la propiedad. Las instrucciones detalladas están disponibles en sitio web de google.

☁️ Configuración de la nube de Google

Habilitación de API

Vaya a la consola de Google Cloud → API y servicios → Biblioteca. Encuéntralo "API de indexación de búsqueda web" y presione Permitir.

⚠️
En tono rimbombante La API debe estar habilitada en el proyecto al que está vinculada su cuenta de servicio. Si la API no está activada, recibirá un error 403 acceso no configurado.

Crear una cuenta de servicio

Una cuenta de servicio es una cuenta técnica sin contraseña que IndexFast utiliza para autorizar las API de Google. Para crearlo, necesitas un proyecto en Google Cloud.

🛠
Antes de comenzar, habilite la API de indexación en su proyecto a través de herramienta de sintonización. Sin este paso, obtendrás un error. 403 acceso no configurado.
1
Abra la sección Cuentas de servicio

Ir a Consola de Google Cloud → IAM y administrador → Cuentas de servicio. Si es necesario, seleccione el proyecto deseado.

2
Haga clic en "Crear una cuenta de servicio"

Introduzca un nombre, por ejemplo IndexFast-boty descripción. El identificador se puede dejar automático. Hacer clic "Crear y continuar".

Sección "Derechos de acceso" no es necesario completar - haga clic "Continuar", entonces "Hecho".

3
Crear una clave JSON

Abra la cuenta recién creada → pestaña Llaves → Agregar clave → Crear nueva clave. Elige un formato JSON y presione "Crear".

El archivo se descargará automáticamente a su computadora; esta es la única copia de la clave. Guárdelo en un lugar seguro y nunca lo publique en Git o repositorios públicos.

💡
El archivo JSON debería verse así: si la estructura es diferente, la clave se generó incorrectamente.
JSON cuenta-servicio.json 
{
  tipo: "cuenta_servicio",
  "id_proyecto": "tu-id-de-proyecto",
  "id_clave_privada": "abc123...",
  "clave_privada": "-----COMENZAR LA CLAVE PRIVADA RSA-----\n...",
  "correo electrónico_cliente": "[correo electrónico protegido]",
  "id_cliente": "123456789",
  "auth_uri": "https://accounts.google.com/o/oauth2/auth",
  "token_uri": "https://oauth2.googleapis.com/token"
}

🔗 Conexión a Search Console

Sin este paso, la API devolverá un error. 403 Prohibido Incluso con la clave correcta. La cuenta de servicio debe recibir el estado de propietario del sitio en Google Search Console.

1
Verificar la propiedad del sitio

Ir a Consola de búsqueda de Google y verifique que el sitio sea suyo, por cualquier medio disponible (registro DNS, archivo HTML, etc.).

2
Copie el correo electrónico de la cuenta de servicio

Abra el archivo JSON descargado y localice el campo. correo_cliente. El correo electrónico se ve así:

nombre-cuenta@nombre-proyecto.iam.gserviceaccount.com

Por ejemplo: [correo electrónico protegido]

3
Agregue la cuenta de servicio como propietario delegado

En Search Console, seleccione su sitio → Configuración → Propietarios verificados → Agregar propietario. Inserte el correo electrónico de la cuenta de servicio y confirme.

⚠️
El papel es exactamente lo que se necesita. Dueño (no "Acceso completo"). Sin esto, la API volverá 403 Prohibido.
4
Espere 1-2 minutos

Los derechos no se aplican instantáneamente. Después de eso, IndexFast podrá enviar URL para indexar a través de su sitio.

🗺 Mapa del sitio.xml

IndexFast lee su mapa del sitio.xml para obtener URL para enviar para indexación. Todos los formatos son compatibles.

Formatos soportados

  • ✅ mapa del sitio.xml — un archivo estándar con una URL
  • ✅ mapa del sitio_index.xml — archivo principal con enlaces al mapa del sitio secundario (cualquier profundidad de anidamiento)
  • ✅ Mapa del sitio con etiquetas <último mod> — filtrado por fecha de actualización

Dónde encontrar la URL del mapa del sitio

Estándar: /mapa del sitio.xml WordPress (Yoast): /sitemap_index.xml Shopificar: /mapa del sitio.xml Laravel: /mapa del sitio.xml
⚠️
En tono rimbombante El mapa del sitio debe ser accesible públicamente sin autorización. Compruebe que el archivo se abra en un navegador sin iniciar sesión. Si está cerrado, IndexFast no podrá leerlo.

⚙️ Cómo funciona el servicio

IndexFast lee automáticamente el tuyo mapa del sitio.xml y envía la URL a través de la API de indexación de Google. No es necesario instalar ningún script: todas las operaciones se realizan en servidores IndexFast.

1
Agrega un sitio en el gabinete.

Especifique el dominio, la URL sitemap.xml e inserte la clave JSON de la cuenta de servicio. IndexFast verifica la disponibilidad del mapa del sitio y guarda la configuración.

2
IndexFast lee el mapa del sitio

El servicio admite mapas de sitio regulares y Índice del mapa del sitio (accesorios de cualquier profundidad). Las URL se ponen en cola automáticamente según el límite diario de su plan.

3
Las URL se envían a Google.

El servicio utiliza su cuenta de servicio para autorización y envía la URL a través de la API oficial de indexación de Google. Ves el resultado en tiempo real en tu cuenta personal.

📊
Los límites dependen del plan: Inicio: 10 URL/día, PRO: 100 URL/día, Agencia: 1000 URL/día. El límite se actualiza todos los días a las 00:00 horas.

🤖 Horario automático

IndexFast comienza a indexar automáticamente, sin necesidad de configurar cron ni mantener un servidor. El servicio funciona las 24 horas del día en el lado de IndexFast.

💡
Para comenzar a indexar manualmente, presione "▶ Lanzar" en su cuenta personal junto al sitio deseado. El resultado aparecerá en los registros en un minuto.

Cómo gestionar la indexación

1
Modo activo

Sitio con estado Activo envía automáticamente URL dentro del límite diario. El límite se comparte equitativamente entre todos los sitios activos de la cuenta.

2
Pausa

Si necesita detener temporalmente la indexación del sitio, haga clic en "⏸" en la oficina No se gasta el límite diario. Puedes restaurar en cualquier momento.

3
inicio manual

Hacer clic "▶ Lanzar" – e IndexFast enviará inmediatamente la URL desde el mapa del sitio dentro del límite diario restante. Conveniente después de publicar nuevas páginas.

🖱 Indexación manual

Además del modo automático, IndexFast le permite comenzar a indexar manualmente en cualquier momento, directamente desde su cuenta personal.

1
abre el gabinete

Ir a IndexFast.pp.ua/app/dashboard y busque el sitio deseado en la lista.

2
Haga clic en "▶ Inicio"

IndexFast leerá instantáneamente el mapa del sitio y enviará la URL dentro del límite diario restante.

3
Ver los resultados en los registros.

Las respuestas de la API de Google aparecen en la pestaña Registros en 1 o 2 minutos. Puedes ver el estado de cada URL: 200 bien, 403, u otra respuesta.

ℹ️
La indexación manual utiliza el mismo límite diario que la indexación automática. Si se alcanza el límite, IndexFast pondrá la URL en la cola para el día siguiente.

📡 Referencia de API

Autorización

Usos de la API de indexación de Google OAuth 2.0 a través de la cuenta de servicio. IndexFast maneja la autorización automáticamente; solo necesita la clave JSON.

Punto final para recibir un token:

HTTP
CORREO https://oauth2.googleapis.com/token

Tipo de contenido: aplicación/x-www-form-urlencoded

tipo_concesión=urna:ietf:params:oauth:grant-type:jwt-bearer
&afirmación={JWT_TOKEN}

Envío de URL para indexación

ParámetroTipoObligatorioDescripción
URLcadenarequeridoURL completa con https://
tipoenumeraciónrequeridoURL_ACTUALIZADA o URL_BORRADA
HTTP
CORREO https://indexing.googleapis.com/v3/urlNotificaciones:publicar

Autorización: Portador {ACCESS_TOKEN}
Content-Type: application/json

{
  "URL": "https://tu-sitio.com/nueva-página",
  tipo: "URL_ACTUALIZADA"

❓ Preguntas frecuentes

¿Cuánto tiempo lleva la indexación después del envío?

Google suele procesar las solicitudes dentro de 24–48 horas. En la mayoría de los casos, las páginas aparecen en la búsqueda a la mañana siguiente de enviarlas.

¿Es posible enviar más de 200 URL por día?

200 URL es el límite gratuito estándar de Google. Si es necesario, puedes solicitar un aumento de límite a través de Google Cloud Console. IndexFast se detiene automáticamente cuando se alcanza el límite y se reanuda al día siguiente.

¿Es seguro para SEO utilizar la API de indexación?

Sí, lo es oficial Método recomendado por el propio Google. No hay riesgo de penalización o degradación; por el contrario, una indexación más rápida mejora la competitividad.

¿Índice del mapa del sitio o mapa del sitio normal?

IndexFast admite ambos tipos. Si pasas el enlace a mapa del sitio_index.xml — el script omitirá automáticamente todos los archivos adjuntos y guardará todas las URL.
