Core Web Vitals: Lo que Necesitas Saber

Los Core Web Vitals son tres métricas de Google que miden la experiencia real del usuario en un sitio. Desde 2021, han sido un factor de clasificación oficial. En 2024, INP reemplazó a FID. Vamos a desglosar cada métrica y cómo mejorarla.

Qué son los Core Web Vitals

Los Core Web Vitals (CWV) son un subconjunto de señales de Experiencia de Página que Google utiliza para clasificar. A diferencia de las pruebas de laboratorio de Lighthouse, los CWV se miden en usuarios reales a través del Informe de Experiencia de Usuario de Chrome (CrUX).

📌 Bueno vs Malo

Para cada métrica: verde = bueno, amarillo = necesita mejora, rojo = malo. Google apunta al percentil 75.

LCP — Largest Contentful Paint

LCP mide el tiempo hasta que se muestra el elemento visible más grande en la página, generalmente una imagen principal o un H1.

ValorCalificación
≤ 2.5 segundos✅ Bueno
2.5 – 4.0 segundos⚠️ Necesita mejora
> 4.0 segundos❌ Malo

Cómo mejorar LCP

  • Optimiza las imágenes — convierte a WebP o AVIF, añade loading="eager" para las imágenes principales.
  • Precargar el elemento LCP — añade <link rel="preload" as="image">.
  • Usa CDN — reduce el TTFB.
  • Elimina recursos bloqueantes — mueve JS y CSS no críticos a defer/async.
  • Renderizado del lado del servidor — SSR mejora drásticamente el LCP para SPA.

CLS — Cumulative Layout Shift

CLS mide el desplazamiento acumulativo de los elementos de la página durante la carga.

ValorCalificación
≤ 0.1✅ Bueno
0.1 – 0.25⚠️ Necesita mejora
> 0.25❌ Malo

Cómo mejorar CLS

  • Especifica los tamaños de las imágenes — siempre añade width y height.
  • Reserva espacio para anuncios — establece tamaños fijos para los bloques de anuncios.
  • No insertes contenido sobre lo existente — los banners y avisos de cookies deben estar en la parte inferior.
  • Precargar fuentes — FOUT causa desplazamientos.

INP — Interaction to Next Paint

INP reemplazó a FID en marzo de 2024. Mide la demora entre la interacción del usuario y la actualización de la pantalla.

A diferencia de FID, INP rastrea todas las interacciones y toma el peor valor.

ValorCalificación
≤ 200 ms✅ Bueno
200 – 500 ms⚠️ Necesita mejora
> 500 ms❌ Malo

Cómo mejorar INP

  • Divide tareas largas — cualquier JS > 50ms bloquea el navegador.
  • Reduce el tamaño del paquete JS — división de código y eliminación de código muerto.
  • Evita operaciones sincrónicas en los controladores de eventos.
  • Revisa scripts de terceros — los chatbots y la analítica a menudo causan un mal INP.
⚠️ INP y CWV

INP es la métrica más difícil de optimizar.

Cómo Medir los Core Web Vitals

Datos del Campo

  • Google Search Console → "Experiencia de Página".
  • PageSpeed Insights — combina datos del campo y datos de laboratorio.
  • CrUX Dashboard en Looker Studio.

Datos de Laboratorio

  • Lighthouse en Chrome DevTools.
  • WebPageTest — pruebas detalladas de waterfall.
💡 Los Datos del Campo son más importantes que los Datos de Laboratorio

Google clasifica en función de los Datos del Campo (usuarios reales), no de Lighthouse.

Impacto de los CWV en SEO

Google confirmó: los CWV son un factor de clasificación, pero el contenido sigue siendo más importante.

Prácticamente: si tu sitio está en la zona verde, los CWV no obstaculizarán el crecimiento.
