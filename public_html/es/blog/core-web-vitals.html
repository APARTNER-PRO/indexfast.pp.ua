Core Web Vitals: Lo que necesitas saber

Los Core Web Vitals son 3 métricas de Google. En 2024, INP reemplazó a FID.

¿Qué son los Core Web Vitals?

Los Core Web Vitals (CWV) son métricas de la experiencia de página.

Tres métricas CWV actuales:

🖼️
LCP
≤ 2.5с
Largest Contentful Paint
Carga de contenido principal
⬜
CLS
≤ 0.1
Cumulative Layout Shift
Estabilidad visual
👆
INP
≤ 200мс
Interaction to Next Paint
Respuesta a la interacción
📌 Bueno vs Pobre

Google se centra en el percentil 75.

LCP — Largest Contentful Paint

LCP mide el tiempo de renderizado del elemento más grande.

ValorPuntuación
≤ 2.5 segundos✅ Bueno
2.5 – 4.0 segundos⚠️ Necesita mejora
> 4.0 секунди❌ Pobre

Cómo mejorar el LCP

  • Optimice las imágenes.
  • Haga Preload del elemento LCP.
  • Use CDN.
  • Elimine recursos que bloqueen el renderizado.
  • Renderizado del lado del servidor (SSR).

CLS — Cumulative Layout Shift

CLS mide la estabilidad visual de la página.

ValorPuntuación
≤ 0.1✅ Bueno
0.1 – 0.25⚠️ Necesita mejora
> 0.25❌ Pobre

Cómo mejorar el CLS

  • Especifique el tamaño de las imágenes.
  • Reserve espacio para los anuncios.
  • No inserte contenido dinámico encima del contenido existente.
  • Haga Preload de las fuentes web.

INP — Interaction to Next Paint

INP reemplazó a FID en 2024.

A diferencia del FID, INP considera todas las interacciones.

ValorPuntuación
≤ 200 ms✅ Bueno
200 – 500 ms⚠️ Necesita mejora
> 500 мс❌ Pobre

Cómo mejorar el INP

  • Divida las tareas largas.
  • Reduzca el tamaño del código JS.
  • Evite operaciones síncronas costosas.
  • Revise los scripts de terceros.
⚠️ INP y CWV

INP es la métrica más difícil de optimizar.

Cómo medir Core Web Vitals

Datos de campo (Field Data)

  • Google Search Console.
  • PageSpeed Insights.
  • Panel de CrUX.

Datos de laboratorio (Lab Data)

  • Lighthouse.
  • WebPageTest.
💡 Los datos de campo son más importantes

Google utiliza los datos de campo para el ranking.

El impacto de CWV en SEO

Google ha confirmado que CWV es un factor de ranking.

En la práctica, optimizar CWV mejora las clasificaciones.
