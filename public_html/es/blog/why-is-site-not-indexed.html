Por qué mi sitio no está indexado en Google — 12 razones y cómo solucionarlas

Lanzaste tu sitio, esperaste unas semanas — y nada en Google. O algunas páginas aparecen en la búsqueda, mientras que otras parecen no existir. Cubrimos las 12 razones más comunes por las que Google ignora un sitio o páginas individuales — y qué hacer exactamente en cada caso.

Primero: Verifica si hay un problema

Antes de buscar la causa, asegúrate de que el problema realmente exista. Escribe en Google:

site:yoursite.com

Si no hay resultados o significativamente menos que el número de páginas en el sitio — sigue leyendo.

También abre Google Search Console → Indexación → Páginas. Allí Google explica por qué cada página no está indexada.

12 razones y soluciones

Razón 01

Etiqueta noindex en la página

La razón más común para la "invisibilidad" en Google. El código de la página contiene una etiqueta que prohíbe directamente la indexación:

<meta name="robots" content="noindex">

Tal etiqueta puede haber aparecido por error durante el desarrollo, o si el CMS establece automáticamente noindex para ciertos tipos de páginas (etiquetas, categorías, páginas de búsqueda).

✓ Solución

Verifica el código de cada página (Ctrl+U en el navegador, busca "noindex"). En WordPress — verifica Yoast SEO o RankMath, configuraciones de visibilidad para cada tipo de publicación.

Razón 02

Bloqueado en robots.txt

El archivo robots.txt puede bloquear a Googlebot de rastrear secciones enteras del sitio. Abre yoursite.com/robots.txt y busca líneas como:

Disallow: / Disallow: /blog/
✓ Solución

Si la línea Disallow: / — esto bloquea todo el sitio. Elimina o reemplaza con Disallow: (valor vacío — permite todo). Verifica a través de la herramienta de prueba de robots.txt en Search Console.

Razón 03

El sitio está protegido por contraseña o en mantenimiento

Si el sitio requiere autorización o devuelve un código 503 — Googlebot no puede acceder al contenido. Esto es típico para nuevos sitios que se lanzan "silenciosamente".

✓ Solución

Asegúrate de que el sitio sea accesible sin autorización. Verifica a través de Google Search Console → Inspección de URL → "Probar URL en vivo".

Razón 04

Bajo presupuesto de rastreo — Googlebot no puede seguir el ritmo

Google asigna un cierto "presupuesto de rastreo" a cada sitio — el número de páginas que está dispuesto a rastrear en un tiempo determinado. Para sitios nuevos y pequeños, este presupuesto es mínimo.

Si el sitio tiene miles de páginas o cambia con frecuencia — Googlebot simplemente no puede rastrear todas las URL.

✓ Solución

Utiliza la API de Indexación de Google para páginas prioritarias. Elimina las URL "basura" del sitemap (etiquetas con 1 artículo, categorías vacías, consultas de búsqueda). Verifica la velocidad del sitio — un sitio lento recibe un presupuesto de rastreo menor.

Razón 05

Contenido duplicado y canónico

Si múltiples URL tienen el mismo contenido o contenido muy similar, Google elige una URL "canónica" y puede ignorar las otras. Problemas comunes:

  • Versiones HTTP y HTTPS del sitio sin redirección
  • Versiones www y no-www
  • Páginas con y sin barra final: /page y /page/
  • Parámetros de URL: /page?utm_source=... en lugar de /page
✓ Solución

Establece la etiqueta canónica en todas las páginas que apunte a la versión "principal". Configura redirecciones 301. En Search Console verifica el informe "Descubierto — actualmente no indexado" — a menudo contiene información sobre duplicados.

Razón 06

Contenido delgado o de baja calidad

Google puede negarse a indexar páginas con poco texto único. En riesgo:

  • Páginas con menos de 300–500 palabras
  • Contenido generado automáticamente
  • Páginas plantilla con contenido único mínimo (etiquetas, meses)
  • Contenido copiado de otros sitios
✓ Solución

Mejora significativamente el contenido o cierra tales páginas con la etiqueta noindex. Es mejor tener 50 páginas indexadas de calidad que 500 "invisibles".

Razón 07

Errores del servidor — códigos 4xx y 5xx

Si Googlebot recibe errores al solicitar páginas — deja de visitarlas y las elimina del índice. Códigos 404 (no encontrado), 500 (error del servidor), 503 (servicio no disponible) — todo esto reduce la actividad de rastreo.

✓ Solución

Search Console → Indexación → Páginas → "No encontrado (404)" y "Error del servidor (5xx)". Corrige o configura redirecciones 301 para páginas eliminadas. Verifica los registros del servidor en busca de errores masivos.

Razón 08

Velocidad de carga de página lenta

Google considera los Core Web Vitals al clasificar y al determinar el presupuesto de rastreo. Un sitio muy lento (LCP > 4 segundos) recibe un presupuesto de rastreo menor.

✓ Solución

Verifica a través de PageSpeed Insights (pagespeed.web.dev). Métricas clave: LCP (Largest Contentful Paint) menos de 2.5s, FID menos de 100ms, CLS menos de 0.1. Optimiza imágenes, habilita el almacenamiento en caché, conecta un CDN.

Razón 09

No hay enlaces a la página

Googlebot encuentra nuevas páginas principalmente a través de enlaces. Si no hay enlaces internos o externos a una página — puede permanecer "invisible" incluso si está en el sitemap.

✓ Solución

Agrega enlaces internos desde otras páginas populares. Asegúrate de que los nuevos artículos aparezcan en las secciones "Leer también", "Nuevas publicaciones", etc. O utiliza la API de Indexación para notificar directamente a Google.

Razón 10

El renderizado de JavaScript bloquea el contenido

Si tu sitio está construido en React, Vue o Angular y el contenido se renderiza solo en el lado del cliente — Googlebot puede no ver el texto de las páginas. Solo "ve" un marco HTML vacío.

✓ Solución

Configura el Renderizado del Lado del Servidor (SSR) o la Generación de Sitios Estáticos (SSG). Verifica a través de Search Console → Inspección de URL → "Ver página rastreada" — muestra exactamente lo que ve Googlebot.

Razón 11

Dominio joven — solo necesita tiempo

Para dominios nuevos (menos de 6 meses), Google generalmente agrega páginas al índice más lentamente. Esto es normal — los algoritmos verifican la fiabilidad de los nuevos recursos.

✓ Solución

Obtén algunos enlaces externos de calidad (de sitios autorizados en tu nicho). Publica regularmente contenido de calidad. Utiliza la API de Indexación para acelerar el proceso. Registra el sitio en Search Console y agrega un sitemap.

Razón 12

Filtro o penalización de Google

En raras ocasiones, un sitio puede recibir una penalización manual del equipo de Google (por manipulación de enlaces, contenido spam, cloaking, etc.) o una penalización algorítmica automática.

✓ Solución

Verifica Search Console → Seguridad y acciones manuales → Acciones manuales. Si hay una penalización — corrige las violaciones y envía una solicitud de revisión. Para filtros algorítmicos — mejora la calidad del contenido y el perfil de enlaces.

Plan de acción paso a paso

Si tu sitio no está indexado — actúa en este orden:

  1. Verifica robots.txt — asegúrate de que no haya bloqueos
  2. Verifica la etiqueta noindex en las páginas problemáticas
  3. Abre Search Console → Páginas → lee las razones de exclusión
  4. Verifica la accesibilidad del sitio y los códigos de respuesta del servidor
  5. Verifica la velocidad a través de PageSpeed Insights
  6. Elimina los problemas encontrados
  7. Envía URL a través de la API de Indexación de Google para acelerar la indexación
