Cron Jobs para SEO: Automatiza la Rutina

Cron es un programador de tareas en Linux que permite ejecutar scripts según un horario. Para SEO, esto significa actualizaciones automáticas del sitemap, etc.

¿Qué es Cron y Crontab?

Cron es un demonio que ejecuta comandos programados. Crontab es el archivo de configuración.

Cada línea en crontab tiene el formato:

* * * * * comando │ │ │ │ └── día de la semana (0-7, 0 y 7 = domingo) │ │ │ └──── mes (1-12) │ │ └────── día del mes (1-31) │ └──────── hora (0-23) └────────── minuto (0-59)

Ejemplos Prácticos para SEO

Indexación Diaria a través de IndexFast

Si utilizas el script PHP de IndexFast para enviar URLs a través de la API de Indexación de Google:

# Ejecutar diariamente a las 6:00 AM 0 6 * * * php /var/www/html/google_indexing.php >> /var/log/indexing.log 2>&1
💡 >> y 2>&1

El símbolo >> añade la salida al archivo de registro. 2>&1 redirige los errores allí también.

Actualización del Sitemap

# Actualizar el sitemap cada 6 horas 0 */6 * * * php /var/www/html/generate_sitemap.php

Auditoría SEO Semanal

# Cada domingo a las 3:00 — verificar enlaces rotos 0 3 * * 0 python3 /scripts/check_links.py >> /var/log/links_audit.log

Ping a Google después de una actualización

# Hacer ping a Google cada 30 minutos sobre la actualización del sitemap */30 * * * * curl -s "https://www.google.com/ping?sitemap=https://yoursite.com/sitemap.xml" > /dev/null

Cómo Configurar Crontab

  1. Conéctate al servidor a través de SSH
  2. Abre el editor de crontab: crontab -e
  3. Agrega líneas con tareas (formato descrito arriba)
  4. Guarda el archivo (en nano: Ctrl+O, Enter, Ctrl+X)
  5. Verifica que la tarea esté añadida: crontab -l

Si no tienes acceso a SSH

La mayoría de los paneles de hosting tienen una interfaz gráfica para cron jobs.

⚠️ Importante: Rutas Absolutas

Siempre especifica rutas absolutas a los archivos ejecutables en cron.

Monitoreo de Cron Jobs

Por defecto, cron envía la salida al correo electrónico de root. Para recibir correos, añade:

MAILTO="[email protected]"

O visualiza el registro del sistema: grep CRON /var/log/syslog
