Cron Jobs para SEO: Automatiza la Rutina

Cron es un programador de tareas en Linux.

¿Qué es Cron y Crontab?

Cron ejecuta comandos programados. Crontab es la configuración.

Formato:

* * * * * comando │ │ │ │ └── día de la semana (0-7) │ │ │ └──── mes (1-12) │ │ └────── día del mes (1-31) │ └──────── hora (0-23) └────────── minuto (0-59)

Ejemplos para SEO

Indexación diaria vía IndexFast

Si usa IndexFast:

# Ejecutar diario a las 6:00 AM 0 6 * * * php /var/www/html/google_indexing.php >> /var/log/indexing.log 2>&1
💡 >> y 2>&1

Agrega logs y errores.

Actualizar sitemap

# Actualizar cada 6 horas 0 */6 * * * php /var/www/html/generate_sitemap.php

Auditoría SEO semanal

# Revisar enlaces rotos 0 3 * * 0 python3 /scripts/check_links.py >> /var/log/links_audit.log

Hacer ping a Google

# Hacer ping cada 30 mins */30 * * * * curl -s "https://www.google.com/ping?sitemap=https://yoursite.com/sitemap.xml" > /dev/null

Cómo Configurar Crontab

  1. Conectarse por SSH
  2. Abrir editor: crontab -e
  3. Añadir tareas
  4. Guardar archivo
  5. Verificar: crontab -l

Si no tiene SSH

Use paneles como cPanel.
