Indexación del sitio WordPress: Configuración de Yoast SEO y errores comunes en 2026

WordPress es el CMS más popular, pero su configuración predeterminada no está optimizada para SEO. Miles de páginas de adjuntos, etiquetas que duplican contenido, archivos de autores: todo esto perjudica la indexación. Vamos a ver cómo solucionarlo en 30 minutos.

Por qué los sitios de WordPress a menudo tienen problemas de indexación

WordPress es el CMS más popular del mundo, pero su configuración predeterminada no está optimizada para SEO. Cientos de miles de sitios de WordPress tienen los mismos errores comunes: las páginas de etiquetas duplican contenido, los archivos de autores muestran los mismos artículos, la paginación no está configurada.

La buena noticia: la mayoría de los problemas se resuelven en 15–30 minutos a través de los plugins Yoast SEO o RankMath.

Yoast SEO: Configuración básica para la indexación

Yoast SEO → Apariencia de búsqueda → Tipos de contenido:

  • Entradas — index: Sí, Mostrar en resultados: Sí
  • Páginas — index: Sí
  • Medios (Adjuntos) — index: No (debe estar desactivado)
  • Etiquetas — index: No si hay menos de 5 entradas por etiqueta
  • Archivos de autores — index: No si solo hay un autor
⚠ Páginas de medios — El duplicador oculto

Por defecto, WordPress crea una página separada para cada imagen subida (página de adjunto). Estas páginas son contenido casi vacío y desperdician seriamente el presupuesto de rastreo. Desactívelas en Yoast SEO → Apariencia de búsqueda → Medios → desactivar páginas de adjuntos.

Etiquetas y categorías

Las etiquetas de WordPress son una de las trampas de SEO más grandes. Cada etiqueta crea una página de archivo separada que muestra los mismos artículos que la categoría. El resultado: duplicación de contenido y dilución del presupuesto de rastreo.

  • Si una etiqueta se usa en menos de 5 artículos → noindex o elimínela
  • Si la categoría y la etiqueta muestran el mismo contenido → elimine las etiquetas por completo
  • Para etiquetas activas: agregue una descripción única a través de Yoast (mínimo 100 palabras)

Sitemap XML en WordPress

WordPress 5.5+ tiene un sitemap incorporado (/wp-sitemap.xml), pero incluye todo: páginas de adjuntos, archivos vacíos, páginas de autores. Es mejor usar el sitemap de Yoast SEO:

  • Yoast SEO excluye automáticamente las páginas con noindex
  • Permite configurar por separado qué incluir
  • Se actualiza automáticamente al publicar nuevo contenido
https://yoursite.com/sitemap_index.xml ← índice del sitemap de Yoast https://yoursite.com/post-sitemap.xml ← entradas https://yoursite.com/page-sitemap.xml ← páginas https://yoursite.com/category-sitemap.xml ← categorías

Velocidad de WordPress y SEO

Un sitio de WordPress lento obtiene un presupuesto de rastreo más pequeño y se clasifica peor. Principales razones para un rendimiento lento:

  • Demasiados plugins (especialmente constructores visuales)
  • Imágenes no optimizadas sin WebP
  • Falta de caché (WP Super Cache, W3 Total Cache)
  • Alojamiento lento o servidor compartido

Errores comunes de WordPress en Search Console

  • "Descubierto - actualmente no indexado" — generalmente páginas de baja calidad o un problema de presupuesto de rastreo
  • "Duplicado sin canónico seleccionado por el usuario" — versiones www y non-www, o parámetros de URL
  • "Anomalía del rastreador" — plugin o tema genera URLs erróneas
  • "Soft 404" — la página parece vacía pero devuelve un código 200

Lista de verificación de SEO de WordPress para indexación

  • Yoast SEO o RankMath instalado
  • Páginas de adjuntos desactivadas
  • Etiquetas sin contenido cerradas a través de noindex
  • Archivos de autores desactivados (para un blog de un solo autor)
  • Sitemap XML de Yoast registrado en Search Console
  • Velocidad del sitio probada a través de PageSpeed Insights
  • Caché configurada
  • API de indexación de Google conectada a través de IndexFast
