Qué es IndexNow y cómo configurarlo en 2026

Durante años, indexar su sitio web requería paciencia. Enviaba un sitemap y esperaba. IndexNow cambió esto.

¿Qué es IndexNow?

IndexNow es un protocolo de ping de código abierto creado por Microsoft (Bing) y Yandex.

Permite que su sitio envíe datos a los motores de búsqueda inmediatamente.

💡 ¿Usa Google IndexNow?

No. Google utiliza su propia API. Es por eso que necesita una herramienta que admita ambas.

Cómo funciona IndexNow

El protocolo es simple. Cuando publica, su servidor envía una solicitud HTTP.

Un ping básico de IndexNow se ve así:

POST https://api.indexnow.org/indexnow Content-Type: application/json { "host": "your-website.com", "key": "your-api-key", "urlList": [ "https://your-website.com/new-page", "https://your-website.com/updated-page" ] }

El problema: la configuración manual es difícil

Aunque el concepto es brillante, la configuración es técnica.

  1. Generar una clave de API única.
  2. Crear un archivo .txt con su clave.
  3. Configurar su CMS o servidor.
  4. Manejar errores y límites de velocidad.
