Cron Jobs для SEO: Автоматизируем рутину

Cron — это планировщик задач в Linux.

Что такое Cron и Crontab?

Cron запускает команды по расписанию. Crontab — это файл конфигурации.

Формат:

* * * * * команда │ │ │ │ └── день недели │ │ │ └──── месяц │ │ └────── день месяца │ └──────── час └────────── минута

Практические примеры для SEO

Ежедневная индексация через IndexFast

Если вы используете скрипт IndexFast:

# Запускать ежедневно в 6:00 0 6 * * * php /var/www/html/google_indexing.php >> /var/log/indexing.log 2>&1
💡 >> и 2>&1

Для записи логов и ошибок.

Обновление sitemap

# Каждые 6 часов 0 */6 * * * php /var/www/html/generate_sitemap.php

Еженедельный аудит

# Каждое воскресенье в 3:00 0 3 * * 0 python3 /scripts/check_links.py >> /var/log/links_audit.log

Пинг Google

# Пинговать каждые 30 минут */30 * * * * curl -s "https://www.google.com/ping?sitemap=https://yoursite.com/sitemap.xml" > /dev/null

Как настроить crontab

  1. Подключитесь по SSH
  2. Откройте редактор: crontab -e
  3. Добавьте задачи
  4. Сохраните файл
  5. Проверьте: crontab -l

Если нет SSH

Используйте панель управления хостингом.

⚠️ Абсолютные пути

В cron всегда указывайте абсолютные пути.

Cron для IndexFast

PHP-скрипт идеально подходит для cron:

  • Читает URL из sitemap
  • Отправляет их через Google Indexing API
  • Логирует запросы
  • Останавливается при лимите в 200 URL
