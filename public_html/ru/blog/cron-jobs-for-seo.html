Cron Jobs для SEO: Автоматизация рутины

Cron — планировщик задач в Linux, который позволяет запускать скрипты по расписанию. Для SEO это означает автоматическое обновление карты сайта и т.д.

Что такое Cron и Crontab?

Cron — демон, который выполняет запланированные команды. Crontab — это файл конфигурации.

Каждая строка в crontab имеет формат:

* * * * * команда │ │ │ │ └── день недели (0-7, 0 и 7 = воскресенье) │ │ │ └──── месяц (1-12) │ │ └────── день месяца (1-31) │ └──────── час (0-23) └────────── минута (0-59)

Практические примеры для SEO

Ежедневная индексация через IndexFast

Если вы используете PHP-скрипт IndexFast для отправки URL через Google Indexing API:

# Запускать ежедневно в 6:00 утра 0 6 * * * php /var/www/html/google_indexing.php >> /var/log/indexing.log 2>&1
💡 >> и 2>&1

Символ >> добавляет вывод в файл лога. 2>&1 также перенаправляет ошибки туда.

Обновление карты сайта

# Обновлять карту сайта каждые 6 часов 0 */6 * * * php /var/www/html/generate_sitemap.php

Еженедельный SEO-аудит

# Каждое воскресенье в 3:00 — проверка битых ссылок 0 3 * * 0 python3 /scripts/check_links.py >> /var/log/links_audit.log

Пингование Google после обновления

# Пинговать Google каждые 30 минут о обновлении карты сайта */30 * * * * curl -s "https://www.google.com/ping?sitemap=https://yoursite.com/sitemap.xml" > /dev/null

Как настроить Crontab

  1. Подключитесь к серверу по SSH
  2. Откройте редактор crontab: crontab -e
  3. Добавьте строки с задачами (формат описан выше)
  4. Сохраните файл (в nano: Ctrl+O, Enter, Ctrl+X)
  5. Проверьте, что задача добавлена: crontab -l

Если у вас нет доступа к SSH

Большинство панелей хостинга имеют графический интерфейс для cron jobs.

⚠️ Важно: Абсолютные пути

Всегда указывайте абсолютные пути к исполняемым файлам в cron.

Мониторинг Cron Jobs
