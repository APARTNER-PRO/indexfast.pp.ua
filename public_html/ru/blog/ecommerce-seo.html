SEO для электронной коммерции: Индексация товаров и категорий в 2026 году

Тысячи товаров, фильтры, генерирующие тысячи дублирующих URL, новые поступления, которые не появляются в поиске месяцами — у электронной коммерции есть свои уникальные SEO-проблемы. Мы анализируем каждую и предоставляем конкретные решения.

Почему магазины сталкиваются с особыми проблемами индексации

Интернет-магазины — одни из самых сложных сайтов для SEO. Тысячи товарных страниц, категории с фильтрами, пагинация, варианты цветов и размеров — все это создает уникальные вызовы.

Главная проблема: crawl budget. Googlebot не успевает обходить все страницы, поэтому некоторые товары могут никогда не появиться в поиске. Статистически, средний интернет-магазин генерирует в 5–10 раз больше URL, чем на самом деле нужно Google.

Страницы товаров: распространенные ошибки

  • Дубли описаний от производителя — если вы копируете текст, он уже есть на десятках сайтов. Google выберет оригинал, а не вас.
  • Товары, отсутствующие в наличии, возвращающие код 200 — "Нет в наличии" на живой странице вместо 404/410 тратит crawl budget.
  • Варианты без canonical — синяя и красная версия товара на разных URL без тега canonical — дубликаты.
  • Параметры фильтров — /category?color=red&size=M генерирует тысячи дублирующих URL.
💡 Решение для вариантов товаров

Установите тег canonical на всех вариантах, указывающий на основную страницу. Или объедините варианты на одной странице с помощью переключателя JavaScript — лучшее UX и лучшее SEO одновременно.

Категории и фильтры

Страницы категорий имеют наилучшие шансы попасть в топ Google — они получают больше всего внутренних ссылок. Но есть ловушки:

  • Пустые категории (0 товаров) — закройте через noindex или удалите.
  • Категории с 1–2 товарами — объедините или добавьте текстовое описание минимум 200 слов.
  • Пагинация — /category/page/2 должна быть доступна для обхода, но без дублирования title и description.
⚠ Фильтры — главный враг crawl budget

Если в категории 10 фильтров по 5 значений — это 50 комбинаций и потенциально тысячи URL. Закрывайте их через robots.txt или устанавливайте canonical на родительскую категорию. Оставляйте открытыми только комбинации с реальным поисковым спросом.

Schema.org Product — обязательно

Структурированные данные помогают Google показывать ваши товары с рейтингом, ценой и наличием прямо в поиске — CTR увеличивается на 20–35%:

{ "@context": "https://schema.org", "@type": "Product", "name": "Название товара", "offers": { "@type": "Offer", "price": "1999", "priceCurrency": "UAH", "availability": "https://schema.org/InStock" }, "aggregateRating": { "@type": "AggregateRating", "ratingValue": "4.8", "reviewCount": "124" } }

Sitemap для большого магазина

Разделите sitemap на файлы по типам страниц — это помогает Google понимать приоритеты:

  • sitemap-products.xml — товары с описанием и наличием, приоритет 0.8
  • sitemap-categories.xml — активные категории, приоритет 0.9
  • sitemap-pages.xml — статические страницы, приоритет 0.6
  • sitemap-blog.xml — статьи блога, приоритет 0.7

Быстрая индексация новых товаров

Без API новый товар может ждать индексации от 2 недель до 3 месяцев. Для магазина, где конкуренты уже продают аналог — это критично.

Google Indexing API решает проблему: после публикации товара отправьте URL через API — Googlebot посетит страницу в течение нескольких часов. Особенно важно для:

  • Сезонных товаров и акций (цена актуальна только неделю)
  • Товаров, которые вернулись в наличие
  • Обновлений цен перед распродажами
  • Новых коллекций и поступлений

Удаленные товары: что делать

  • Товар временно отсутствует → оставьте страницу, отметьте OutOfStock в Schema.org
  • Удален навсегда, есть аналог → 301-редирект на похожий товар или категорию
  • Удален навсегда, аналога нет → код 410 Gone (лучше, чем 404)

Чеклист SEO для электронной коммерции

  • Уникальные описания для всех товаров (минимум 150 слов, идеально 300+)
  • Canonical теги на вариантах и параметрических URL
  • Noindex для пустых категорий и нерелевантных фильтров
  • Schema.org Product для всех товарных страниц
  • Сегментированный sitemap по типам с правильными приоритетами
  • 301-редиректы или 410 для удаленных товаров
  • Google Indexing API для новых и обновленных товаров
