Что такое sitemap.xml и зачем он нужен

Sitemap.xml — один из важнейших файлов для SEO, о котором часто забывают или настраивают неправильно. Разбираем что это такое, как он выглядит, как его создать и почему он напрямую влияет на скорость индексации вашего сайта.

Что такое sitemap.xml?

Sitemap (карта сайта) — это XML-файл, который содержит список всех важных URL вашего сайта. Он размещается по адресу https://your-site.com/sitemap.xml и является своеобразным «путеводителем» для поисковых роботов.

📌 Официальная позиция Google

Google рекомендует использовать sitemap для любого сайта с более чем 500 страниц, новых сайтов с малым числом внешних ссылок, а также для сайтов с медиаконтентом (видео, изображения).

Структура sitemap.xml

Базовый sitemap выглядит так:

<?xml version="1.0" encoding="UTF-8"?> <urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9"> <url> <loc>https://your-site.com/about</loc> <lastmod>2026-01-20</lastmod> <changefreq>monthly</changefreq> <priority>0.8</priority> </url> </urlset>

Что означают теги:

ТегОбязательныйОписание
<loc>✅ ДаПолный URL-адрес страницы с https://
<lastmod>❌ НетДата последнего обновления (формат YYYY-MM-DD)
<changefreq>❌ НетЧастота изменений: always, hourly, daily, weekly, monthly, yearly, never
<priority>❌ НетПриоритет от 0.0 до 1.0 (по умолчанию 0.5)
⚠️ Важно знать

Google официально заявил, что changefreq и priority в большинстве случаев игнорируются. Зато lastmod реально влияет — Google отдаёт приоритет страницам с недавней датой обновления.

Типы sitemap

Обычный sitemap

Перечень URL в формате XML. Подходит для сайтов до 50 000 страниц.

Sitemap Index

Если у вас более 50 000 URL или файл превышает 50 МБ — используйте sitemap index. Это «файл-родитель», который ссылается на отдельные sitemap-файлы.

Как зарегистрировать sitemap в Google

Иметь sitemap — недостаточно. Google должен знать, где он находится. Есть два способа:

Способ 1: через robots.txt

User-agent: * Allow: / Sitemap: https://your-site.com/sitemap.xml

Спосіб 2: через Google Search Console

  1. Откройте Search Console → выберите ваш сайт.
  2. В левом меню: Индексирование → Файлы Sitemap.
  3. Введите URL вашего sitemap и нажмите «Отправить».

Распространенные ошибки с sitemap

  • URL с noindex — не включайте в sitemap страницы с тегом noindex.
  • Битые ссылки — все URL в sitemap должны возвращать код 200, не 301 или 404.
  • Необновленная дата lastmod — если указываете lastmod, обновляйте её реально при изменениях.
  • Sitemap нет в robots.txt — Google может просто не найти ваш файл.

Sitemap + Indexing API = максимальная скорость

Даже зарегистрированный в Search Console sitemap не гарантирует быстрой индексации. Google может обработать его через неделю, а может через месяц.

Самая эффективная стратегия — это объединение актуального sitemap с активной отправкой URL через Google Indexing API. Вы не ждёте, когда Google сам придёт — вы сами говорите ему «вот новая страница, просканируй сейчас».
