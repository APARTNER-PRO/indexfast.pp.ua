Индексация сайта WordPress: настройки Yoast SEO и распространенные ошибки в 2026 году

WordPress — самая популярная CMS, но ее стандартные настройки не оптимизированы для SEO. Тысячи страниц вложений, теги, дублирующие контент, архивы авторов — все это вредит индексации. Давайте разберемся, как это исправить за 30 минут.

Почему сайты WordPress часто имеют проблемы с индексацией

WordPress — самая популярная CMS в мире, но ее стандартные настройки не оптимизированы для SEO. Сотни тысяч сайтов WordPress имеют одни и те же распространенные ошибки: страницы тегов дублируют контент, архивы авторов выводят одни и те же статьи, пагинация не настроена.

Хорошая новость: большинство проблем решаются за 15–30 минут с помощью плагинов Yoast SEO или RankMath.

Yoast SEO: базовые настройки для индексации

Yoast SEO → Внешний вид поиска → Типы контента:

  • Записи — index: Да, Показать в результатах: Да
  • Страницы — index: Да
  • Медиа (Вложения) — index: Нет (обязательно отключить)
  • Теги — index: Нет, если менее 5 записей на тег
  • Архивы авторов — index: Нет, если только один автор
⚠ Страницы медиа — скрытый дубликатор

По умолчанию WordPress создает отдельную страницу для каждого загруженного изображения (страница вложения). Эти страницы — почти пустой контент и серьезно расходуют бюджет обхода. Отключите их в Yoast SEO → Внешний вид поиска → Медиа → отключить страницы вложений.

Теги и категории

Теги WordPress — одна из самых больших SEO-ловушек. Каждый тег создает отдельную страницу-архив, которая выводит те же статьи, что и категория. Результат: дублирование контента и размывание бюджета обхода.

  • Если тег используется менее чем в 5 статьях → noindex или удалите его
  • Если категория и тег выводят одинаковый контент → удалите теги вообще
  • Для активных тегов: добавьте уникальное описание через Yoast (минимум 100 слов)

XML карта сайта в WordPress

WordPress 5.5+ имеет встроенную карту сайта (/wp-sitemap.xml), но она включает все подряд: страницы вложений, пустые архивы, страницы авторов. Лучше использовать карту сайта Yoast SEO:

  • Yoast SEO автоматически исключает страницы с noindex
  • Позволяет отдельно настраивать, что включать
  • Автоматически обновляется при публикации нового контента
https://yoursite.com/sitemap_index.xml ← индекс карты сайта Yoast https://yoursite.com/post-sitemap.xml ← записи https://yoursite.com/page-sitemap.xml ← страницы https://yoursite.com/category-sitemap.xml ← категории

Скорость WordPress и SEO

Медленный сайт WordPress получает меньший бюджет обхода и хуже ранжируется. Основные причины медленной работы:

  • Слишком много плагинов (особенно визуальных конструкторов)
  • Неоптимизированные изображения без WebP
  • Отсутствие кэширования (WP Super Cache, W3 Total Cache)
  • Медленный хостинг или общий сервер

Распространенные ошибки WordPress в Search Console

  • «Обнаружено - в настоящее время не проиндексировано» — обычно низкокачественные страницы или проблема с бюджетом обхода
  • «Дубликат без выбранного канонического» — www и non-www версии, или параметры URL
  • «Аномалия краулера» — плагин или тема генерирует ошибочные URL
  • «Мягкий 404» — страница выглядит пустой, но возвращает код 200
