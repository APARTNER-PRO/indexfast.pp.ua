SEO аудит сайта: полный чеклист из 50 пунктов в 2026 году

Регулярный SEO аудит — единственный способ заметить проблемы до того, как они значительно повлияют на трафик. 50 конкретных пунктов проверки: от robots.txt и Core Web Vitals до E-E-A-T и качества обратных ссылок.

Что такое SEO аудит и зачем он нужен

SEO аудит — это системная проверка сайта на соответствие требованиям поисковых систем. Он выявляет технические ошибки, проблемы с контентом и упущенные возможности для роста позиций. Регулярный аудит (раз в квартал) позволяет заметить деградацию до того, как она существенно повлияет на трафик.

Этот чеклист состоит из 50 пунктов, сгруппированных по категориям. Проходите их последовательно — каждый невыправленный пункт это риск для видимости сайта в поиске.

Технический SEO (пункты 1–15)

  • 1. HTTPS — сайт должен открываться только через https://. Проверьте редиректы с http://
  • 2. WWW/non-WWW — одна версия должна редиректить на другую (301)
  • 3. robots.txt — файл существует, не блокирует важные разделы, доступен без авторизации
  • 4. Sitemap.xml — существует, актуален, зарегистрирован в Search Console
  • 5. Статусы ответов — нет ошибочных 200 на страницах 404 (soft 404)
  • 6. Редиректы — цепочки редиректов не длиннее 2 шагов
  • 7. Скорость загрузки — LCP менее 2.5с на мобильном (PageSpeed)
  • 8. Core Web Vitals — FID/INP менее 200мс, CLS менее 0.1
  • 9. Мобильная версия — сайт корректно отображается на всех размерах экрана
  • 10. Структурированные данные — Schema.org для основных типов страниц
  • 11. Hreflang — правильно настроен, если есть мультиязычный контент
  • 12. Канонические теги — каждая страница указывает на себя или на основную версию
  • 13. Пагинация — rel="next"/"prev" или канонизация на первую страницу
  • 14. Ошибки обхода — проверьте Search Console на 4xx и 5xx ошибки
  • 15. Лог-файлы — Googlebot регулярно посещает важные страницы
💡 Быстрая техническая проверка

Введите адрес сайта на pagespeed.web.dev — получите оценки Core Web Vitals для мобильной и десктопной версий сразу. Это первый шаг любого технического аудита.

Индексация (пункты 16–22)

  • 16. Количество проиндексированных страниц — сравните site: с реальным числом страниц
  • 17. Noindex на важных страницах — проверьте на случайный noindex
  • 18. Покрытие Search Console — просмотрите категории «Ошибка» и «Исключено»
  • 19. Сиротские страницы — страницы без внутренних ссылок в отчете по обходу
  • 20. Дубликаты в индексе — site: покажет, если есть несколько версий одной страницы
  • 21. Sitemap против индекса — сколько URL из sitemap реально проиндексировано
  • 22. API индексации — настроена ли автоматическая отправка новых URL
⚠ Критический пункт: утечка noindex

Самая дорогая ошибка в SEO — когда noindex попадает в продакшн из тестовой среды. Проверяйте это первым после каждого деплоя. Search Console покажет резкое падение проиндексированных страниц.

On-page SEO (пункты 23–35)

  • 23. Title теги — уникальные, содержат ключевое слово, 50–60 символов
  • 24. Meta description — уникальные, 120–155 символов, содержат CTA
  • 25. H1 — один H1 на странице, содержит ключевое слово
  • 26. Структура заголовков — логическая иерархия H1 → H2 → H3
  • 27. Ключевые слова в контенте — естественное употребление, без переспама
  • 28. Длина контента — минимум 300 слов, для конкурентных запросов 1000+
  • 29. Уникальность контента — нет дубликатов с другими страницами сайта
  • 30. Изображения — alt-теги заполнены, файлы оптимизированы (WebP)
  • 31. Внутренние ссылки — важные страницы имеют ссылки с других страниц
  • 32. Анкорный текст — описательный, не «кликните здесь» или «читайте далее»
  • 33. URL структура — короткая, понятная, содержит ключевое слово
  • 34. Хлебные крошки — навигация Breadcrumb с Schema.org
  • 35. Устаревший контент — статьи старше 2 лет требуют обновления

Контент и E-E-A-T (пункты 36–42)

  • 36. Автор контента — указан автор с биографией и ссылками на соцсети
  • 37. Дата публикации и обновления — видима на странице
  • 38. Источники и ссылки — ссылки на авторитетные источники, где это уместно
  • 39. Страницы «О нас» и «Контакты» — подробная информация о компании
  • 40. Политика конфиденциальности и Условия — актуальные документы
  • 41. Отзывы и социальные доказательства — реальные отзывы на сайте
  • 42. Тонкий контент — страницы с менее чем 300 словами без реальной ценности

Внешние ссылки (пункты 43–47)

  • 43. Количество обратных ссылок — проверьте через Ahrefs или Google Search Console
  • 44. Качество доноров — ссылки с авторитетных тематических сайтов
  • 45. Токсичные ссылки — спамные ссылки с низкокачественных сайтов
  • 46. Анкор-лист — разнообразные анкоры, нет переспама точных вхождений
  • 47. Сломанные обратные ссылки — ссылки на удаленные или измененные страницы вашего сайта

Аналитика и мониторинг (пункты 48–50)

  • 48. Google Analytics 4 — установлен, корректно отслеживает конверсии
  • 49. Search Console — сайт верифицирован, sitemap добавлен, нет сообщений об ошибках
  • 50. Регулярный мониторинг — еженедельный обзор основных метрик: трафик, позиции, индексация

Приоритизация исправлений

Не пытайтесь исправить все сразу. Приоритизируйте задачи:

  • Критично (на этой неделе) — noindex на важных страницах, блокировка robots.txt, массовые ошибки 5xx
  • Важно (в этом месяце) — скорость сайта, дубли контента, отсутствующие канонические теги
  • Желательно (в следующем квартале) — обновление устаревшего контента, наращивание ссылок, Schema.org
