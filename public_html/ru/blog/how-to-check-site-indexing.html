Как проверить индексацию сайта в Google — 7 методов в 2026 году

«Почему мой сайт не появляется в Google?» — один из самых распространенных вопросов владельцев сайтов. Первый шаг к ответу — выяснить, видит ли Google ваши страницы. Мы рассмотрим 7 способов проверки индексации: от простого поиска до детального аудита в Search Console.

Что означает «страница проиндексирована»?

Индексация — это процесс, при котором Googlebot находит вашу страницу, анализирует ее содержимое и добавляет в свою базу данных (индекс). Только проиндексированные страницы могут отображаться в результатах поиска.

Важно различать два понятия: сканирование (Googlebot посетил страницу) и индексация (страница добавлена в индекс и может отображаться в поиске). Страница может быть просканирована, но не проиндексирована — например, из-за низкого качества контента или технических проблем.

1. Оператор site: в Google

Метод 01 · Бесплатно · 30 секунд

Поисковый оператор site:

Откройте Google и введите в строку поиска:

site:yoursite.com

Google покажет все проиндексированные страницы вашего домена. Число в строке «Приблизительно X результатов» — ориентировочное количество проиндексированных страниц.

💡 Полезные варианты оператора

site:yoursite.com/blog/ — только страницы в разделе /blog/
site:yoursite.com -inurl:tag — без страниц тегов
"ключевое слово" site:yoursite.com — есть ли конкретная страница в индексе

⚠ Ограничения метода

Результаты оператора site: являются приблизительными и могут отличаться от реального количества на 20–30%. Для точных данных используйте Google Search Console.

2. Проверка конкретного URL в Search Console

Метод 02 · Бесплатно · Наиболее точно

Инструмент проверки URL

Google Search Console → введите URL в верхнюю строку поиска → нажмите Enter.

Вы увидите один из трех статусов:

  • URL есть в Google — страница проиндексирована, все в порядке
  • URL нет в Google — страница не проиндексирована, есть причина
  • URL есть в Google, но есть проблемы — проиндексирована с ограничениями

Если статус «URL нет в Google», разверните детали — там будет конкретная причина: Обнаружено, но не проиндексировано, Дублирующая страница без канонического тега, Заблокировано robots.txt и т.д.

🚀 Запрос на индексацию

Прямо в инструменте проверки URL нажмите «Запросить индексацию» — Google поставит страницу в очередь на внеочередное сканирование. Но этот метод не срабатывает мгновенно и имеет суточные лимиты.

3. Отчет «Покрытие» в Search Console

Метод 03 · Системный аудит

Полная картина индексации сайта

Search Console → Индексация → Страницы (или «Покрытие» в старом интерфейсе).

Отчет разбивает все URL сайта на четыре категории:

  • Ошибка — страницы не проиндексированы из-за критических проблем (код 404, 500, заблокировано)
  • Действительный с предупреждением — проиндексировано, но есть потенциальные проблемы
  • Действительный — все в порядке, страницы в индексе
  • Исключено — намеренно или автоматически исключено из индекса (noindex, дубликаты и т.д.)

Кликайте на каждую категорию, чтобы увидеть конкретные URL и причины проблем.

4. Проверка через кэш Google

Метод 04 · Быстро

Оператор cache: для проверки кэша

Введите в Google: cache:yoursite.com/page

Если Google сохранил кэш страницы — она точно была проиндексирована. Кэш также показывает дату последнего сканирования — это полезно, чтобы понимать, насколько актуальна информация в Google.

⚠ Важно

Google постепенно ограничивает оператор cache:. В некоторых регионах он уже не работает. Если не срабатывает — используйте Search Console.

5. Поиск по точному заголовку страницы

Метод 05 · Проверка конкретной страницы

Поиск по intitle:

Введите в Google: intitle:"Точный заголовок вашей страницы"

Если ваша страница есть в результатах — она проиндексирована. Дополнительно проверяет, нет ли дубликатов с таким же заголовком на других сайтах.

6. Аудит sitemap в Search Console

Метод 06 · Массовая проверка

Сравнение sitemap и индекса

Search Console → Индексация → Файлы Sitemap → выберите свой sitemap.

Search Console показывает два числа: количество URL в sitemap и количество проиндексированных URL. Если второе число значительно меньше — есть проблемы.

Например: sitemap содержит 500 URL, а проиндексировано только 120 — 380 страниц по какой-то причине Google не захотел индексировать. Причины могут быть: низкое качество контента, дубликаты, медленная загрузка, блокировка в robots.txt.

7. Сторонние SEO-инструменты

Метод 07 · Расширенный анализ

Ahrefs, Semrush, Screaming Frog

Для глубокого аудита крупных сайтов сторонние инструменты предоставляют больше деталей.

  • Ahrefs Site Audit — сканирует сайт и показывает, какие страницы не проиндексированы и почему
  • Screaming Frog SEO Spider — бесплатно до 500 URL, детальный технический аудит
  • Semrush Site Audit — проверяет индексацию и технические проблемы

Почему страницы не индексируются

Если вы обнаружили, что страницы не проиндексированы, вот самые распространенные причины:

  • Тег noindex — в коде страницы стоит <meta name="robots" content="noindex">
  • Заблокировано в robots.txt — правило Disallow блокирует Googlebot
  • Низкий crawl budget — Google не успевает обходить все страницы сайта
  • Низкое качество контента — дубликаты, тонкий контент, автоматически сгенерированные страницы
  • Проблемы с сервером — коды ошибок 4xx, 5xx при запросах Googlebot
  • Отсутствующий или неправильный canonical — Google выбирает другую страницу как основную
  • Новые страницы — просто еще не дошла очередь (может занять от нескольких дней до месяцев)
