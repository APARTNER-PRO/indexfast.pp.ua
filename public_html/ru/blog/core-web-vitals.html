Core Web Vitals: что важно знать

Core Web Vitals — три метрики Google, измеряющие реальный опыт пользователя. В 2024 году INP заменил FID. Разбираем каждую метрику.

Что такое Core Web Vitals

Core Web Vitals (CWV) — подмножество сигналов Page Experience.

Три текущие метрики CWV:

🖼️
LCP
≤ 2.5с
Largest Contentful Paint
Загрузка главного контента
⬜
CLS
≤ 0.1
Cumulative Layout Shift
Стабильность макета
👆
INP
≤ 200мс
Interaction to Next Paint
Отклик на взаимодействие
📌 Хороший vs Плохой

Google ориентируется на 75-й перцентиль.

LCP — Largest Contentful Paint

LCP измеряет время до отображения самого большого элемента.

ЗначениеОценка
≤ 2.5 секунды✅ Хорошо
2.5 – 4.0 секунды⚠️ Требует улучшения
> 4.0 секунди❌ Плохо

Как улучшить LCP

  • Оптимизируйте изображения.
  • Preload LCP-элемент.
  • Используйте CDN — уменьшает TTFB.
  • Уберите блокирующие ресурсы.
  • Server-Side Rendering — SSR улучшает LCP.

CLS — Cumulative Layout Shift

CLS измеряет смещение элементов страницы.

ЗначениеОценка
≤ 0.1✅ Хорошо
0.1 – 0.25⚠️ Требует улучшения
> 0.25❌ Плохо

Как улучшить CLS

  • Указывайте размеры изображений.
  • Резервируйте место для рекламы.
  • Не вставляйте контент над существующим.
  • Preload шрифты.

INP — Interaction to Next Paint

INP заменил FID в 2024 году.

INP отслеживает все взаимодействия.

ЗначениеОценка
≤ 200 мс✅ Хорошо
200 – 500 мс⚠️ Требует улучшения
> 500 мс❌ Плохо

Как улучшить INP

  • Разбейте длинные задачи.
  • Уменьшите размер JS-бандла.
  • Избегайте синхронных операций в обработчиках.
  • Проверьте сторонние скрипты.
⚠️ INP и CWV

INP — самая сложная метрика.

Как измерить Core Web Vitals

Реальные данные (Field Data)

  • Google Search Console → "Удобство страниц".
  • PageSpeed Insights.
  • CrUX Dashboard.

Лабораторные данные (Lab Data)

  • Lighthouse в Chrome DevTools.
  • WebPageTest.
💡 Field Data важнее Lab Data

Google ранжирует на основе реальных данных.

Влияние CWV на SEO

Google подтвердил, что CWV — фактор ранжирования.

Практически: если метрики в зеленой зоне, это не мешает росту.
