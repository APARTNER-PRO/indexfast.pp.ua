ℹ️
What is the Google Indexing API? Google's official tool for notifying the searcher about new or updated pages. Allows to send to 200 URLs per day for free and get a response within 24-48 hours.

⚡ Quick start

To get started with IndexFast you need to complete 3 steps. The whole process takes about 10-15 minutes.

1
Create a Service Account in Google Cloud

Go to console.cloud.google.com, create a new project (or select an existing one) and enable it Web Search Indexing API. Create a Service Account and upload a JSON key.

Detailed instructions are in the section 🔑 Service Account.

2
Add Service Account to Search Console

У Google Search Console add your Service Account email as a delegate the owner site

Detailed instructions are in the section 🔗 Search Console.

3
Connect the site in your personal account

Sign up or sign in IndexFast cabinet. Add the site, insert the Service Account JSON key, and the indexing will start automatically.

✅ Requirements

Before you start, make sure you have:

1
Google account

Required to access Google Cloud Console and Google Search Console.

2
Site verified in Google Search Console

Your domain must be verified at Google Search Console by any available method.

3
The sitemap.xml file

Your site must have publicly available sitemap.xml. IndexFast reads it to get a list of URLs to index.

4
Service Account JSON key

File downloaded from Google Cloud Console .json with rights to the Web Search Indexing API.

💡
If your site is not yet in Search Console, add it first and confirm ownership. Detailed instructions are available at Google website.

☁️ Google Cloud settings

API enablement

Go to Google Cloud Console → APIs & Services → Library. Find it "Web Search Indexing API" and press Enable.

⚠️
Importantly The API must be enabled in the project to which your Service Account is linked. If the API is not activated, you will receive an error 403 accessNotConfigured.

Creating a Service Account

A Service Account is a passwordless technical account that IndexFast uses to authorize Google APIs. To create it, you need a project in Google Cloud.

🛠
Before you begin, enable the Indexing API in your project via tuning tool. Without this step, you will get an error 403 accessNotConfigured.
1
Open the Service Accounts section

Go to Google Cloud Console → IAM & Admin → Service Accounts. If necessary, select the desired project.

2
Click "Create a service account"

Enter a name, for example IndexFast-bot, and description. The identifier can be left automatic. Click "Create and Continue".

Section "Access rights" it is not necessary to fill in - click "Continue", then "Done".

3
Create a JSON key

Open the newly created account → tab Keys → Add Key → Create new key. Choose a format JSON and press "Create".

The file will be automatically downloaded to your computer — this is the only copy of the key. Keep it in a safe place and never publish it to Git or public repositories.

💡
The JSON file should look like this - if the structure is different, the key was generated incorrectly.
JSON service-account.json 
{
  type: "service_account",
  "project_id": "your-project-id",
  "private_key_id": "abc123...",
  "private_key": "-----BEGIN RSA PRIVATE KEY-----\n...",
  "client_email": "[email protected]",
  "client_id": "123456789",
  "auth_uri": "https://accounts.google.com/o/oauth2/auth",
  "token_uri": "https://oauth2.googleapis.com/token"
}

🔗 Search Console connection

Without this step, the API will return an error 403 Forbidden even with the correct key. The Service Account must receive the status of the site owner in Google Search Console.

1
Verify site ownership

Go to Google Search Console and verify that the site is yours - by any means available (DNS record, HTML file, etc.).

2
Copy the Service Account email

Open the downloaded JSON file and locate the field client_email. Email looks like this:

account-name@project-name.iam.gserviceaccount.com

For example: [email protected]

3
Add the Service Account as a delegated owner

In Search Console, select your site → Settings → Verified owners → Add owner. Insert Service Account email and confirm.

⚠️
The role is exactly what is needed Owner (not "Full Access"). Without this, the API will return 403 Forbidden.
4
Wait 1-2 minutes

Rights are not applied instantly. After that, IndexFast will be able to send URLs for indexing through your site.

🗺 sitemap.xml

IndexFast reads your sitemap.xml to get URLs to submit for indexing. All formats are supported.

Supported formats

  • ✅ sitemap.xml — a standard file with a URL
  • ✅ sitemap_index.xml — parent file with links to child Sitemap (any nesting depth)
  • ✅ Sitemap with tags — filtering by update date

Where to find the Sitemap URL

Standard: /sitemap.xml WordPress (Yoast): /sitemap_index.xml Shopify: /sitemap.xml Laravel: /sitemap.xml
⚠️
Importantly The Sitemap must be publicly accessible without authorization. Check that the file opens in a browser without a login. If it is closed, IndexFast will not be able to read it.

⚙️ How the service works

IndexFast automatically reads yours sitemap.xml and sends the URL through the Google Indexing API. No script needs to be installed - all operations are performed on IndexFast servers.

1
You add a site in the cabinet

Specify the domain, sitemap.xml URL and insert the Service Account JSON key. IndexFast checks the availability of the Sitemap and saves the settings.

2
IndexFast reads the Sitemap

The service supports regular Sitemaps and Sitemap Index (attachments of any depth). URLs are automatically queued according to your plan's daily limit.

3
URLs are sent to Google

The service uses your Service Account for authorization and sends the URL through the official Google Indexing API. You see the result in real time in your personal account.

📊
Limits depend on the plan: Start — 10 URLs/day, PRO — 100 URLs/day, Agency — 1000 URLs/day. The limit is updated every day at 00:00.

🤖 Automatic schedule

IndexFast starts indexing automatically — no need to configure cron or maintain a server. The service works around the clock on the IndexFast side.

💡
To start indexing manually, press "▶ Launch" in your personal account next to the desired site. The result will appear in the logs within a minute.

How to manage indexing

1
Active mode

Site with status Active automatically sends URLs within the daily limit. The limit is shared equally between all active sites of the account.

2
Pause

If you need to temporarily stop indexing for the site - click "⏸" in the office The daily limit is not spent. You can restore at any time.

3
Manual start

Click "▶ Launch" — and IndexFast will immediately send the URL from the Sitemap within the remainder of the daily limit. Convenient after publishing new pages.

🖱 Manual indexing

In addition to the automatic mode, IndexFast allows you to start indexing manually at any time - directly from your personal account.

1
Open the cabinet

Go to indexfast.pro/app/dashboard and find the desired site in the list.

2
Click "▶ Start"

IndexFast will instantly read the Sitemap and send the URL within the remaining daily limit.

3
See the results in the logs

Google API responses appear in the Logs tab within 1-2 minutes. You can see the status of each URL: 200 OK, 403, or another answer.

ℹ️
Manual indexing uses the same daily limit as automatic indexing. If the limit is reached, IndexFast will put the URL in the queue for the next day.

📡 API Reference

Authorization

Google Indexing API uses OAuth 2.0 through Service Account. IndexFast handles authorization automatically—you only need the JSON key.

Endpoint to receive a token:

HTTP
POST https://oauth2.googleapis.com/token

Content-Type: application/x-www-form-urlencoded

grant_type=urn:ietf:params:oauth:grant-type:jwt-bearer
&assertion={JWT_TOKEN}

Submitting URLs for indexing

ParameterTypeMandatoryDescription
urlstringrequiredFull URL with https://
typeenumrequiredURL_UPDATED or URL_DELETED
HTTP
POST https://indexing.googleapis.com/v3/urlNotifications:publish

Authorization: Bearer {ACCESS_TOKEN}
Content-Type: application/json

{
  "url": "https://your-site.com/new-page",
  type: "URL_UPDATED"
}

Successful response:

JSON
{
  "urlNotificationMetadata": {
    "url": "https://your-site.com/new-page",
    "latestUpdate": {
      "url": "https://your-site.com/new-page",
      type: "URL_UPDATED",
      "notifyTime": "2026-01-20T10:30:00Z"
    }
  }
}

URL status check

HTTP
GET https://indexing.googleapis.com/v3/urlNotifications/metadata
    ?url=https://your-site.com/page

Authorization: Bearer {ACCESS_TOKEN}

Error codes

CodeReasonSolution
400Invalid URL or typeCheck the URL format and value type
403No rights or API not enabledAdd the Service Account as an owner in Search Console
429Daily limit exceededWait until the next day or contact Google
500Error on Google's sideTry again in a few minutes

❓ FAQ

How long does indexing take after submission?

Google usually processes requests within 24–48 hours. In most cases, pages appear in the search the very next morning after sending.

Is it possible to submit more than 200 URLs per day?

200 URLs is Google's standard free limit. If necessary, you can apply for a limit increase through the Google Cloud Console. IndexFast automatically stops when the limit is reached and resumes the next day.

Is it safe for SEO to use the Indexing API?

Yes, it is official method recommended by Google itself. No risk of penalty or downgrade - on the contrary, faster indexation improves competitiveness.

Sitemap Index or regular Sitemap?

IndexFast supports both types. If you pass the link to sitemap_index.xml — the script will automatically bypass all attached files and save all URLs.
