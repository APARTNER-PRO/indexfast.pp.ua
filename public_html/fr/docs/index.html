ℹ️
Qu'est-ce que l'API d'indexation Google ? L'outil officiel de Google pour informer le chercheur des pages nouvelles ou mises à jour. Permet d'envoyer à 200 URL par jour gratuitement et obtenez une réponse dans les 24 à 48 heures.

⚡ Démarrage rapide

Pour démarrer avec IndexFast, vous devez suivre 3 étapes. L'ensemble du processus prend environ 10 à 15 minutes.

1
Créer un compte de service dans Google Cloud

Aller à console.cloud.google.com, créez un nouveau projet (ou sélectionnez-en un existant) et activez-le API d'indexation de recherche sur le Web. Créez un compte de service et téléchargez une clé JSON.

Des instructions détaillées se trouvent dans la section 🔑 Compte de services.

2
Ajouter un compte de service à la Search Console

У Console de recherche Google ajoutez l'adresse e-mail de votre compte de service en tant que délégué le propriétaire site

Des instructions détaillées se trouvent dans la section 🔗Console de recherche.

3
Connectez le site dans votre compte personnel

Inscrivez-vous ou connectez-vous Armoire IndexFast. Ajoutez le site, insérez la clé JSON du compte de service et l'indexation démarrera automatiquement.

✅ Exigences

Avant de commencer, assurez-vous d'avoir :

1
Compte Google

Requis pour accéder à Google Cloud Console et Google Search Console.

2
Site vérifié dans Google Search Console

Votre domaine doit être vérifié à Console de recherche Google par n'importe quelle méthode disponible.

3
Le fichier sitemap.xml

Votre site doit être accessible au public plan du site.xml. IndexFast le lit pour obtenir une liste d'URL à indexer.

4
Clé JSON du compte de service

Fichier téléchargé depuis Google Cloud Console .json avec des droits sur l'API d'indexation de recherche Web.

💡
Si votre site n'est pas encore dans la Search Console, ajoutez-le d'abord et confirmez la propriété. Des instructions détaillées sont disponibles sur Site Web de Google.

☁️ Paramètres Google Cloud

Activation de l'API

Accédez à Google Cloud Console → API et services → Bibliothèque. Trouvez-le "API d'indexation de recherche sur le Web" et appuyez sur Activer.

⚠️
Surtout L'API doit être activée dans le projet auquel votre compte de service est lié. Si l'API n'est pas activée, vous recevrez une erreur 403 accèsNotConfiguré.

Création d'un compte de service

Un compte de service est un compte technique sans mot de passe qu'IndexFast utilise pour autoriser les API Google. Pour le créer, vous avez besoin d'un projet dans Google Cloud.

🛠
Avant de commencer, activez l'API d'indexation dans votre projet via outil de réglage. Sans cette étape, vous obtiendrez une erreur 403 accèsNotConfiguré.
1
Ouvrez la section Comptes de service

Aller à Google Cloud Console → IAM et administrateur → Comptes de service. Si nécessaire, sélectionnez le projet souhaité.

2
Cliquez sur "Créer un compte de service"

Entrez un nom, par exemple IndexFast-bot, et description. L'identifiant peut être laissé automatique. Cliquez "Créer et continuer".

Section "Droits d'accès" il n'est pas nécessaire de remplir - cliquez "Continuer", alors "Fait".

3
Créer une clé JSON

Ouvrez le compte nouvellement créé → onglet Clés → Ajouter une clé → Créer une nouvelle clé. Choisissez un format JSON et appuyez sur "Créer".

Le fichier sera automatiquement téléchargé sur votre ordinateur — c'est la seule copie de la clé. Conservez-le dans un endroit sûr et ne le publiez jamais sur Git ou dans des référentiels publics.

💡
Le fichier JSON devrait ressembler à ceci : si la structure est différente, la clé n'a pas été générée correctement.
JSON service-account.json 
{
  taper: "compte_service",
  "id_projet": "votre-identifiant-de-projet",
  "private_key_id": "abc123...",
  "clé_privée": "-----DEBUT DE LA CLÉ PRIVÉE RSA-----\n...",
  "client_e-mail": "[email protégé]",
  "ID_client": "123456789",
  "auth_uri": "https://accounts.google.com/o/oauth2/auth",
  "jeton_uri": "https://oauth2.googleapis.com/token"
}

🔗 Connexion à la Search Console

Sans cette étape, l'API renverra une erreur 403 Interdit même avec la bonne clé. Le compte de service doit recevoir le statut de propriétaire du site dans Google Search Console.

1
Vérifier la propriété du site

Aller à Console de recherche Google et vérifiez que le site vous appartient - par tout moyen disponible (enregistrement DNS, fichier HTML, etc.).

2
Copiez l'e-mail du compte de service

Ouvrez le fichier JSON téléchargé et localisez le champ client_email. L'e-mail ressemble à ceci :

nom-du-compte@nom-du-projet.iam.gserviceaccount.com

Par exemple: [email protégé]

3
Ajouter le compte de service en tant que propriétaire délégué

Dans Search Console, sélectionnez votre site → Paramètres → Propriétaires vérifiés → Ajouter un propriétaire. Insérez l'e-mail du compte de service et confirmez.

⚠️
Le rôle est exactement ce dont nous avons besoin Propriétaire (pas « Accès complet »). Sans cela, l'API reviendra 403 Interdit.
4
Attendez 1 à 2 minutes

Les droits ne sont pas appliqués instantanément. Après cela, IndexFast pourra envoyer des URL à indexer via votre site.

🗺 Plan du site.xml

IndexFast lit votre plan du site.xml pour obtenir les URL à soumettre pour indexation. Tous les formats sont pris en charge.

Formats pris en charge

  • ✅ plan du site.xml — un fichier standard avec une URL
  • ✅ sitemap_index.xml — fichier parent avec des liens vers le plan du site enfant (n'importe quelle profondeur d'imbrication)
  • ✅ Plan du site avec balises — filtrage par date de mise à jour

Où trouver l'URL du plan du site

Standard: /sitemap.xml WordPress (Yoast): /sitemap_index.xml Shopify : /sitemap.xml Laravel : /sitemap.xml
⚠️
Surtout Le plan du site doit être accessible au public sans autorisation. Vérifiez que le fichier s'ouvre dans un navigateur sans connexion. S'il est fermé, IndexFast ne pourra pas le lire.

⚙️ Comment fonctionne le service

IndexFast lit automatiquement le vôtre plan du site.xml et envoie l'URL via l'API d'indexation Google. Aucun script n'a besoin d'être installé - toutes les opérations sont effectuées sur les serveurs IndexFast.

1
Vous ajoutez un site dans le cabinet

Spécifiez le domaine, l'URL sitemap.xml et insérez la clé JSON du compte de service. IndexFast vérifie la disponibilité du plan du site et enregistre les paramètres.

2
IndexFast lit le plan du site

Le service prend en charge les plans de site réguliers et Index du plan du site (attachements de toute profondeur). Les URL sont automatiquement mises en file d'attente en fonction de la limite quotidienne de votre forfait.

3
Les URL sont envoyées à Google

Le service utilise votre compte de service pour l'autorisation et envoie l'URL via l'API d'indexation officielle de Google. Vous voyez le résultat en temps réel dans votre compte personnel.

📊
Les limites dépendent du forfait : Début – 10 URL/jour, PRO – 100 URL/jour, Agence – 1000 URL/jour. La limite est mise à jour quotidiennement à 00h00.

🤖 Calendrier automatique

IndexFast démarre l'indexation automatiquement — pas besoin de configurer cron ou de maintenir un serveur. Le service fonctionne 24 heures sur 24 du côté d’IndexFast.

💡
Pour démarrer l'indexation manuellement, appuyez sur "▶ Lancer" dans votre compte personnel à côté du site souhaité. Le résultat apparaîtra dans les journaux dans une minute.

Comment gérer l'indexation

1
Mode actif

Site avec statut Actif envoie automatiquement les URL dans la limite quotidienne. La limite est partagée à parts égales entre tous les sites actifs du compte.

2
Pause

Si vous devez arrêter temporairement l'indexation du site, cliquez sur "⏸" au bureau La limite quotidienne n'est pas dépensée. Vous pouvez restaurer à tout moment.

3
Démarrage manuel

Cliquez "▶ Lancer" - et IndexFast enverra immédiatement l'URL du plan du site dans le reste de la limite quotidienne. Pratique après la publication de nouvelles pages.

🖱 Indexation manuelle

En plus du mode automatique, IndexFast vous permet de lancer l'indexation manuellement à tout moment - directement depuis votre compte personnel.

1
Ouvrez le placard

Aller à indexfast.pro/app/dashboard et recherchez le site souhaité dans la liste.

2
Cliquez sur "▶ Démarrer"

IndexFast lira instantanément le plan du site et enverra l'URL dans la limite quotidienne restante.

3
Voir les résultats dans les logs

Les réponses de l'API Google apparaissent dans l'onglet Journaux dans un délai d'une à deux minutes. Vous pouvez voir l'état de chaque URL : 200 OK, 403, ou une autre réponse.

ℹ️
L'indexation manuelle utilise la même limite quotidienne que l'indexation automatique. Si la limite est atteinte, IndexFast mettra l'URL dans la file d'attente pour le lendemain.

📡 Référence API

Autorisation

Utilisations de l'API d'indexation Google OAuth 2.0 via le compte de service. IndexFast gère automatiquement l'autorisation : vous n'avez besoin que de la clé JSON.

Point de terminaison pour recevoir un jeton :

HTTP
POSTE https://oauth2.googleapis.com/token

Type de contenu : application/x-www-form-urlencoded

type_de_subvention=urn:ietf:params:oauth:grant-type:jwt-bearer
&affirmation={JWT_TOKEN}

Soumission d'URL pour l'indexation

ParamètreTaperObligatoireDescription
URLchaînerequisURL complète avec https://
taperénumérationrequisURL_UPDATED ou URL_DELETED
HTTP
POSTE https://indexing.googleapis.com/v3/urlNotifications:publish

Autorisation : Porteur {ACCESS_TOKEN}
Content-Type: application/json

{
  "url": "https://votre-site.com/nouvelle-page",
  taper: "URL_UPDATED"
}

Réponse réussie :

JSON
{
  "urlNotificationMétadonnées": {
    "url": "https://votre-site.com/nouvelle-page",
    "dernière mise à jour": {
      "url": "https://votre-site.com/nouvelle-page",
      taper: "URL_UPDATED",
      "notifierHeure": "2026-01-20T10:30:00Z"
    }
  }
}

Vérification de l'état de l'URL

HTTP
OBTENIR https://indexing.googleapis.com/v3/urlNotifications/metadata
    ?url=https://votre-site.com/page

❓FAQ

Combien de temps prend l'indexation après la soumission ?

Google traite généralement les demandes dans les délais 24 à 48 heures. Dans la plupart des cas, les pages apparaissent dans la recherche dès le lendemain de l'envoi.

Est-il possible de soumettre plus de 200 URL par jour ?

200 URL est la limite gratuite standard de Google. Si nécessaire, vous pouvez demander une augmentation de limite via Google Cloud Console. IndexFast s'arrête automatiquement lorsque la limite est atteinte et reprend le lendemain.

Est-il sûr pour le référencement d'utiliser l'API d'indexation ?

Oui c'est le cas officiel méthode recommandée par Google lui-même. Aucun risque de pénalité ou de déclassement : au contraire, une indexation plus rapide améliore la compétitivité.

Index du plan du site ou plan du site standard ?

IndexFast prend en charge les deux types. Si vous passez le lien vers sitemap_index.xml — le script contournera automatiquement tous les fichiers joints et enregistrera toutes les URL.
