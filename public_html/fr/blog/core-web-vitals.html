Core Web Vitals : Ce que vous devez savoir

Les Core Web Vitals sont trois métriques de Google qui mesurent l'expérience utilisateur réelle sur un site. Depuis 2021, elles sont un facteur de classement officiel. En 2024, l'INP a remplacé le FID. Décomposons chaque métrique et comment l'améliorer.

Qu'est-ce que les Core Web Vitals

Les Core Web Vitals (CWV) sont un sous-ensemble de signaux d'expérience de page utilisés par Google pour le classement. Contrairement aux tests de laboratoire Lighthouse, les CWV sont mesurés sur de vrais utilisateurs via le rapport d'expérience utilisateur Chrome (CrUX).

Pour chaque métrique : vert = bon, jaune = nécessite une amélioration, rouge = mauvais. Google cible le 75e percentile.

LCP — Largest Contentful Paint

LCP mesure le temps jusqu'à ce que le plus grand élément visible de la page soit affiché — généralement une image héro ou un H1.

ValeurÉvaluation
≤ 2.5 secondes✅ Bon
2.5 – 4.0 secondes⚠️ Nécessite une amélioration
> 4.0 secondes❌ Mauvais

Comment améliorer LCP

  • Optimisez les images — convertissez en WebP ou AVIF, ajoutez loading="eager" pour les images héro.
  • Préchargez l'élément LCP — ajoutez <link rel="preload" as="image">.
  • Utilisez un CDN — réduit le TTFB.
  • Supprimez les ressources bloquantes — déplacez le JS et le CSS non critiques en defer/async.
  • Rendu côté serveur — le SSR améliore considérablement le LCP pour les SPA.

CLS — Cumulative Layout Shift

CLS mesure le déplacement cumulatif des éléments de la page pendant le chargement.

ValeurÉvaluation
≤ 0.1✅ Bon
0.1 – 0.25⚠️ Nécessite une amélioration
> 0.25❌ Mauvais

Comment améliorer CLS

  • Spécifiez les tailles d'image — ajoutez toujours les attributs width et height.
  • Réservez de l'espace pour les publicités — définissez des tailles fixes pour les blocs publicitaires.
  • Ne pas insérer de contenu au-dessus de l'existant — les bannières et les avis de cookies doivent être en bas.
  • Préchargez les polices — le FOUT provoque des déplacements.

INP — Interaction to Next Paint

INP a remplacé le FID en mars 2024. Il mesure le délai entre l'interaction de l'utilisateur et la mise à jour de l'écran.

Contrairement au FID, l'INP suit toutes les interactions et prend la pire valeur.

ValeurÉvaluation
≤ 200 ms✅ Bon
200 – 500 ms⚠️ Nécessite une amélioration
> 500 ms❌ Mauvais

Comment améliorer INP

  • Divisez les longues tâches — tout JS > 50ms bloque le navigateur.
  • Réduisez la taille du bundle JS — découpage de code et tree shaking.
  • Évitez les opérations synchrones dans les gestionnaires d'événements.
  • Vérifiez les scripts tiers — les chatbots et l'analyse causent souvent un mauvais INP.
⚠️ INP et CWV

INP est la métrique la plus difficile à optimiser.

Comment mesurer les Core Web Vitals

Données réelles

  • Google Search Console → "Expérience de page".
  • PageSpeed Insights — combine les données réelles et de laboratoire.
  • Tableau de bord CrUX dans Looker Studio.

Données de laboratoire

  • Lighthouse dans Chrome DevTools.
  • WebPageTest — tests détaillés en cascade.
💡 Les données réelles sont plus importantes que les données de laboratoire

Google classe en fonction des données réelles (utilisateurs réels), pas de Lighthouse.

Impact des CWV sur le SEO

Google a confirmé : les CWV sont un facteur de classement, mais le contenu est toujours plus important.

Pratiquement : si votre site est dans la zone verte, les CWV ne freineront pas la croissance.
