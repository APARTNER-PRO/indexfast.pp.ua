Tâches Cron pour le SEO : Automatiser la Routine

Cron est un planificateur de tâches sous Linux.

Qu'est-ce que Cron et Crontab ?

Cron exécute des commandes. Crontab est le fichier de configuration.

Format :

* * * * * commande │ │ │ │ └── jour de la semaine │ │ │ └──── mois │ │ └────── jour du mois │ └──────── heure └────────── minute

Exemples pratiques pour le SEO

Indexation quotidienne avec IndexFast

Si vous utilisez IndexFast :

# Exécuter tous les jours à 6h00 0 6 * * * php /var/www/html/google_indexing.php >> /var/log/indexing.log 2>&1
💡 >> et 2>&1

Ajoute des logs.

Mise à jour du sitemap

# Toutes les 6 heures 0 */6 * * * php /var/www/html/generate_sitemap.php

Audit SEO hebdomadaire

# Vérifier les liens cassés 0 3 * * 0 python3 /scripts/check_links.py >> /var/log/links_audit.log

Pinger Google

# Pinger toutes les 30 min */30 * * * * curl -s "https://www.google.com/ping?sitemap=https://yoursite.com/sitemap.xml" > /dev/null

Comment configurer Crontab

  1. Connectez-vous via SSH
  2. Ouvrez l'éditeur : crontab -e
  3. Ajoutez des tâches
  4. Enregistrez
  5. Vérifiez : crontab -l
