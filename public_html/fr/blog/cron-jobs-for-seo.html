Cron Jobs pour le SEO : Automatisez la routine

Cron est un planificateur de tâches dans Linux qui vous permet d'exécuter des scripts selon un calendrier. Pour le SEO, cela signifie des mises à jour automatiques du sitemap, etc.

Qu'est-ce que Cron et Crontab ?

Cron est un démon qui exécute des commandes planifiées. Crontab est le fichier de configuration.

Chaque ligne dans crontab a le format :

* * * * * commande │ │ │ │ └── jour de la semaine (0-7, 0 et 7 = dimanche) │ │ │ └──── mois (1-12) │ │ └────── jour du mois (1-31) │ └──────── heure (0-23) └────────── minute (0-59)

Exemples pratiques pour le SEO

Indexation quotidienne via IndexFast

Si vous utilisez le script PHP IndexFast pour envoyer des URL via l'API d'indexation de Google :

# Exécuter quotidiennement à 6h00 0 6 * * * php /var/www/html/google_indexing.php >> /var/log/indexing.log 2>&1
💡 >> et 2>&1

Le symbole >> ajoute la sortie au fichier journal. 2>&1 redirige également les erreurs là-bas.

Mise à jour du Sitemap

# Mettre à jour le sitemap toutes les 6 heures 0 */6 * * * php /var/www/html/generate_sitemap.php

Audit SEO hebdomadaire

# Chaque dimanche à 3h00 — vérifier les liens brisés 0 3 * * 0 python3 /scripts/check_links.py >> /var/log/links_audit.log

Pinger Google après une mise à jour

# Pinger Google toutes les 30 minutes à propos de la mise à jour du sitemap */30 * * * * curl -s "https://www.google.com/ping?sitemap=https://votresite.com/sitemap.xml" > /dev/null

Comment configurer Crontab

  1. Connectez-vous au serveur via SSH
  2. Ouvrez l'éditeur crontab : crontab -e
  3. Ajoutez des lignes avec des tâches (format décrit ci-dessus)
  4. Enregistrez le fichier (dans nano : Ctrl+O, Entrée, Ctrl+X)
  5. Vérifiez que la tâche est ajoutée : crontab -l

Si vous n'avez pas accès à SSH

La plupart des panneaux d'hébergement ont une interface graphique pour les cron jobs.

⚠️ Important : Chemins absolus

Spécifiez toujours des chemins absolus vers les fichiers exécutables dans cron.

Surveillance des Cron Jobs

Par défaut, cron envoie la sortie à l'email root. Pour recevoir des emails, ajoutez :

MAILTO="[email protected]"

Ou consultez le journal système : grep CRON /var/log/syslog
