Website SEO Audit: Complete 50-Point Checklist in 2026

A regular SEO audit is the only way to notice problems before they significantly affect traffic. 50 specific checkpoints: from robots.txt and Core Web Vitals to E-E-A-T and backlink quality.

What is an SEO Audit and Why is it Needed

An SEO audit is a systematic check of a website for compliance with search engine requirements. It reveals technical errors, content problems, and missed opportunities for ranking growth. A regular audit (once a quarter) allows you to notice degradation before it significantly affects traffic.

This checklist consists of 50 items grouped by categories. Go through them sequentially — each uncorrected item is a risk for the site's visibility in search.

Technical SEO (Items 1–15)

  • 1. HTTPS — site must open only via https://. Check redirects from http://
  • 2. WWW/non-WWW — one version should redirect to the other (301)
  • 3. robots.txt — file exists, doesn't block important sections, available without authorization
  • 4. Sitemap.xml — exists, up to date, registered in Search Console
  • 5. Status codes — no erroneous 200s on 404 pages (soft 404)
  • 6. Redirects — redirect chains are no longer than 2 steps
  • 7. Loading speed — LCP under 2.5s on mobile (PageSpeed)
  • 8. Core Web Vitals — FID/INP under 200ms, CLS under 0.1
  • 9. Mobile version — site displays correctly on all screen sizes
  • 10. Structured data — Schema.org for main page types
  • 11. Hreflang — properly configured if there is multilingual content
  • 12. Canonical tags — each page points to itself or the main version
  • 13. Pagination — rel="next"/"prev" or canonical to the first page
  • 14. Crawl errors — check Search Console for 4xx and 5xx errors
  • 15. Log files — Googlebot regularly visits important pages
💡 Quick Technical Check

Enter the site address on pagespeed.web.dev — get Core Web Vitals scores for mobile and desktop immediately. This is the first step of any technical audit.

Indexing (Items 16–22)

  • 16. Number of indexed pages — compare site: with the real number of pages
  • 17. Noindex on important pages — check for accidental noindex
  • 18. Search Console Coverage — review the "Error" and "Excluded" categories
  • 19. Orphan pages — pages without internal links in the crawl report
  • 20. Duplicates in index — site: will show if there are several versions of one page
  • 21. Sitemap vs Index — how many URLs from the sitemap are actually indexed
  • 22. Indexing API — is automatic submission of new URLs configured
⚠ Critical Item: noindex Leak

The most expensive mistake in SEO is when noindex gets into production from the test environment. Check this first after each deploy. Search Console will show a sharp drop in indexed pages.

On-page SEO (Items 23–35)

  • 23. Title tags — unique, contain keyword, 50–60 characters
  • 24. Meta description — unique, 120–155 characters, contains a CTA
  • 25. H1 — one H1 per page, contains keyword
  • 26. Heading structure — logical hierarchy H1 → H2 → H3
  • 27. Keywords in content — natural usage, without keyword stuffing
  • 28. Content length — minimum 300 words, for competitive queries 1000+
  • 29. Content uniqueness — no duplicates with other site pages
  • 30. Images — alt tags filled, files optimized (WebP)
  • 31. Internal linking — important pages have links from other pages
  • 32. Anchor text — descriptive, not "click here" or "read more"
  • 33. URL structure — short, clear, contains keyword
  • 34. Breadcrumbs — Breadcrumb nav with Schema.org
  • 35. Outdated content — articles older than 2 years need updating

Content and E-E-A-T (Items 36–42)

  • 36. Content author — author listed with bio and social links
  • 37. Publication and update date — visible on the page
  • 38. Sources and references — links to authoritative sources where appropriate
  • 39. About and Contact pages — detailed company information
  • 40. Privacy Policy and Terms — up-to-date documents
  • 41. Reviews and social proof — real reviews on the site
  • 42. Thin content — pages with fewer than 300 words without real value

External Links (Items 43–47)

  • 43. Backlink count — check via Ahrefs or Google Search Console
  • 44. Donor quality — links from authoritative topical sites
  • 45. Toxic links — spammy links from low-quality sites
  • 46. Anchor text profile — diverse anchors, no exact match stuffing
  • 47. Broken backlinks — links to deleted or changed pages of your site

Analytics and Monitoring (Items 48–50)

  • 48. Google Analytics 4 — installed, tracks conversions correctly
  • 49. Search Console — site verified, sitemap added, no error messages
  • 50. Regular monitoring — weekly review of core metrics: traffic, rankings, indexing

Prioritizing Fixes

Don't try to fix everything at once. Prioritize tasks:

  • Critical (this week) — noindex on important pages, robots.txt blocks, mass 5xx errors
  • Important (this month) — site speed, content duplicates, missing canonical tags
  • Desirable (next quarter) — updating old content, link building, Schema.org
