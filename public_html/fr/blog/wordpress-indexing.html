Indexation du site WordPress : Paramètres Yoast SEO et erreurs courantes en 2026

WordPress est le CMS le plus populaire, mais ses paramètres par défaut ne sont pas optimisés pour le SEO. Des milliers de pages d'attachement, des balises qui dupliquent le contenu, des archives d'auteurs — tout cela nuit à l'indexation. Voyons comment le corriger en 30 minutes.

Pourquoi les sites WordPress ont souvent des problèmes d'indexation

WordPress est le CMS le plus populaire au monde, mais ses paramètres par défaut ne sont pas optimisés pour le SEO. Des centaines de milliers de sites WordPress ont les mêmes erreurs courantes : les pages de balises dupliquent le contenu, les archives d'auteurs affichent les mêmes articles, la pagination n'est pas configurée.

La bonne nouvelle : la plupart des problèmes se résolvent en 15 à 30 minutes grâce aux plugins Yoast SEO ou RankMath.

Yoast SEO : Paramètres de base pour l'indexation

Yoast SEO → Apparence de recherche → Types de contenu :

  • Articles — index : Oui, Afficher dans les résultats : Oui
  • Pages — index : Oui
  • Médias (Attachements) — index : Non (doit être désactivé)
  • Balises — index : Non si moins de 5 articles par balise
  • Archives d'auteurs — index : Non si un seul auteur
⚠ Pages de médias — Le duplicateur caché

Par défaut, WordPress crée une page séparée pour chaque image téléchargée (page d'attachement). Ces pages contiennent presque du contenu vide et gaspillent sérieusement le budget d'exploration. Désactivez-les dans Yoast SEO → Apparence de recherche → Médias → désactiver les pages d'attachement.

Balises et catégories

Les balises WordPress sont l'un des plus grands pièges SEO. Chaque balise crée une page d'archive séparée qui affiche les mêmes articles que la catégorie. Le résultat : duplication de contenu et dilution du budget d'exploration.

  • Si une balise est utilisée sur moins de 5 articles → noindex ou supprimez-la
  • Si la catégorie et la balise affichent le même contenu → supprimez les balises complètement
  • Pour les balises actives : ajoutez une description unique via Yoast (minimum 100 mots)

Sitemap XML dans WordPress

WordPress 5.5+ a un sitemap intégré (/wp-sitemap.xml), mais il inclut tout : pages d'attachement, archives vides, pages d'auteurs. Il est préférable d'utiliser le sitemap Yoast SEO :

  • Yoast SEO exclut automatiquement les pages avec noindex
  • Permet de configurer séparément ce qu'il faut inclure
  • Se met à jour automatiquement lors de la publication de nouveaux contenus
https://votresite.com/sitemap_index.xml ← Index du sitemap Yoast https://votresite.com/post-sitemap.xml ← articles https://votresite.com/page-sitemap.xml ← pages https://votresite.com/category-sitemap.xml ← catégories

Vitesse de WordPress et SEO

Un site WordPress lent obtient un budget d'exploration plus petit et se classe moins bien. Principales raisons de la lenteur :

  • Trop de plugins (en particulier les constructeurs visuels)
  • Images non optimisées sans WebP
  • Absence de mise en cache (WP Super Cache, W3 Total Cache)
  • Hébergement lent ou serveur partagé

Erreurs courantes de WordPress dans la Search Console

  • "Découvert - actuellement non indexé" — généralement des pages de faible qualité ou un problème de budget d'exploration
  • "Dupliqué sans balise canonique sélectionnée par l'utilisateur" — versions www et non-www, ou paramètres d'URL
  • "Anomalie du crawler" — un plugin ou un thème génère des URL erronées
  • "Soft 404" — la page semble vide mais renvoie un code 200

Liste de contrôle SEO WordPress pour l'indexation

  • Archives d'auteurs désactivées (pour un blog à auteur unique)
  • Sitemap XML Yoast enregistré dans la Search Console
