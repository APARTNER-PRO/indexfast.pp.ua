Comment vérifier l'indexation d'un site dans Google — 7 méthodes en 2026

"Pourquoi mon site n'apparaît-il pas dans Google ?" — l'une des questions les plus courantes des propriétaires de sites. La première étape pour trouver la réponse est de déterminer si Google voit vos pages. Nous couvrons 7 façons de vérifier l'indexation : d'une recherche simple à un audit détaillé dans Search Console.

Que signifie "page indexée" ?

L'indexation est le processus par lequel Googlebot trouve votre page, analyse son contenu et l'ajoute à sa base de données (index). Seules les pages indexées peuvent apparaître dans les résultats de recherche.

Il est important de distinguer deux concepts : exploration (Googlebot a visité la page) et indexation (la page est ajoutée à l'index et peut apparaître dans la recherche). Une page peut être explorée mais non indexée — par exemple, en raison de la faible qualité du contenu ou de problèmes techniques.

1. L'opérateur site: dans Google

Méthode 01 · Gratuit · 30 secondes

L'opérateur de recherche site:

Ouvrez Google et tapez dans la barre de recherche :

site:votresite.com

Google affichera toutes les pages indexées de votre domaine. Le nombre dans la ligne "Environ X résultats" est le nombre approximatif de pages indexées.

💡 Variantes utiles de l'opérateur

site:votresite.com/blog/ — uniquement les pages dans la section /blog/
site:votresite.com -inurl:tag — sans pages de tags
"mot clé" site:votresite.com — si une page spécifique est dans l'index

⚠ Limitations de la méthode

Les résultats de l'opérateur site: sont approximatifs et peuvent différer du nombre réel de 20 à 30 %. Pour des données précises, utilisez Google Search Console.

2. Inspection d'URL dans Search Console

Méthode 02 · Gratuit · La plus précise

Outil d'inspection d'URL

Google Search Console → entrez l'URL dans la barre de recherche en haut → appuyez sur Entrée.

Vous verrez l'un des trois statuts :

  • L'URL est sur Google — la page est indexée, tout va bien
  • L'URL n'est pas sur Google — la page n'est pas indexée, il y a une raison
  • L'URL est sur Google, mais a des problèmes — indexée avec des limitations

Si le statut est "L'URL n'est pas sur Google", développez les détails — il y aura une raison spécifique : Découverte — actuellement non indexée, Dupliquée sans balise canonique, Bloquée par robots.txt, etc.

🚀 Demander l'indexation

Directement dans l'outil d'inspection d'URL, cliquez sur "Demander l'indexation" — Google mettra la page dans la file d'attente pour un crawl hors programme. Mais cette méthode ne fonctionne pas instantanément et a des limites quotidiennes.

3. Rapport de couverture dans Search Console

Méthode 03 · Audit systématique

Vue d'ensemble de l'indexation du site

Search Console → Indexation → Pages (ou "Couverture" dans l'ancienne interface).

Le rapport divise toutes les URL du site en quatre catégories :

  • Erreur — pages non indexées en raison de problèmes critiques (404, 500, bloquées)
  • Valide avec avertissement — indexée, mais il y a des problèmes potentiels
  • Valide — tout va bien, les pages sont dans l'index
  • Exclue — intentionnellement ou automatiquement exclue de l'index (noindex, doublons, etc.)

Cliquez sur chaque catégorie pour voir des URL spécifiques et les raisons des problèmes.

4. Vérification du cache Google

Méthode 04 · Rapide

L'opérateur cache: pour vérifier le cache

Tapez dans Google : cache:votresite.com/page

Si Google a enregistré le cache de la page — elle a certainement été indexée. Le cache montre également la date du dernier scan — utile pour comprendre à quel point l'information dans Google est à jour.

⚠ Important

Google limite progressivement l'opérateur cache:. Dans certaines régions, il ne fonctionne plus. S'il ne fonctionne pas — utilisez Search Console.

5. Recherche par titre exact

Méthode 05 · Vérifier une page spécifique

Recherche en utilisant intitle :

Tapez dans Google : intitle:"Titre exact de votre page"

Si votre page apparaît dans les résultats — elle est indexée. Vérifie également s'il y a des doublons avec le même titre sur d'autres sites.

6. Audit du sitemap dans Search Console

Méthode 06 · Vérification de masse

Comparaison du sitemap et de l'index

Search Console → Indexation → Sitemaps → sélectionnez votre sitemap.

Search Console affiche deux chiffres : nombre d'URL dans le sitemap et nombre d'URL indexées. Si le deuxième chiffre est significativement inférieur — il y a des problèmes.

Par exemple : le sitemap contient 500 URL, mais seulement 120 sont indexées — 380 pages que Google n'a pas voulu indexer. Les raisons peuvent être : faible qualité du contenu, doublons, chargement lent, blocage dans robots.txt.

7. Outils SEO tiers

Méthode 07 · Analyse avancée

Ahrefs, Semrush, Screaming Frog

Pour des audits approfondis de grands sites, les outils tiers fournissent plus de détails.

  • Audit de site Ahrefs — scanne le site et montre quelles pages ne sont pas indexées et pourquoi
  • Screaming Frog SEO Spider — gratuit jusqu'à 500 URL, audit technique détaillé
  • Audit de site Semrush — vérifie l'indexation et les problèmes techniques

Pourquoi les pages ne sont-elles pas indexées ?

Si vous constatez que des pages ne sont pas indexées, voici les raisons les plus courantes :

  • Balise noindex — le code de la page contient <meta name="robots" content="noindex">
  • Bloqué dans robots.txt — une règle Disallow bloque Googlebot
  • Faible budget d'exploration — Google ne peut pas explorer toutes les pages du site
  • Faible qualité du contenu — doublons, contenu mince, pages générées automatiquement
  • Problèmes de serveur — codes d'erreur 4xx, 5xx lors des requêtes de Googlebot
  • Canonical manquant ou incorrect — Google choisit une autre page comme principale
  • Nouvelles pages — simplement pas encore dans la file d'attente (cela peut prendre de quelques jours à plusieurs mois)
