IndexFast ist ein Webdienst, der die Indexierung von Seiten in Google über die offizielle Google Indexing API automatisiert. Verbinden Sie einmal GSC, fügen Sie eine Sitemap hinzu, und IndexFast sendet alle Seiten automatisch zur Indexierung.

Der Dienst erstellt ein Service-Konto in Google Cloud und verwendet den Endpunkt indexing.googleapis.com, um Google über neue oder aktualisierte Seiten zu benachrichtigen.

Nach dem Senden über die Indexing API indexiert Google Seiten normalerweise innerhalb von 24–48 Stunden statt der üblichen 2–8 Wochen.

Einrichtung in ~10 Minuten: Projekt in Google Cloud erstellen, Indexing API aktivieren, Service-Konto erstellen, E-Mail als Eigentümer in GSC hinzufügen, JSON-Schlüssel in IndexFast hochladen. Anleitung: Dokumentation.
