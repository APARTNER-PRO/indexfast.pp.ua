ℹ️
Was ist die Google Indexing API? Das offizielle Tool von Google zur Benachrichtigung des Suchenden über neue oder aktualisierte Seiten. Ermöglicht das Senden an 200 URLs pro Tag kostenlos und erhalten Sie innerhalb von 24–48 Stunden eine Antwort.

⚡ Schnellstart

Um mit IndexFast zu beginnen, müssen Sie drei Schritte ausführen. Der gesamte Vorgang dauert etwa 10-15 Minuten.

1
Erstellen Sie ein Dienstkonto in Google Cloud

Gehe zu console.cloud.google.com, erstellen Sie ein neues Projekt (oder wählen Sie ein vorhandenes aus) und aktivieren Sie es Indexierungs-API für die Websuche. Erstellen Sie ein Dienstkonto und laden Sie einen JSON-Schlüssel hoch.

Detaillierte Anweisungen finden Sie im Abschnitt 🔑 Dienstkonto.

2
Dienstkonto zur Search Console hinzufügen

У Google Search Console Fügen Sie die E-Mail-Adresse Ihres Dienstkontos als Delegierter hinzu der Besitzer Website

Detaillierte Anweisungen finden Sie im Abschnitt 🔗 Suchkonsole.

3
Verbinden Sie die Website mit Ihrem persönlichen Konto

Melden Sie sich an oder melden Sie sich an IndexFast-Schrank. Fügen Sie die Site hinzu, geben Sie den JSON-Schlüssel des Dienstkontos ein und die Indizierung wird automatisch gestartet.

✅ Anforderungen

Bevor Sie beginnen, stellen Sie sicher, dass Sie Folgendes haben:

1
Google-Konto

Erforderlich für den Zugriff auf die Google Cloud Console und die Google Search Console.

2
Website in der Google Search Console überprüft

Ihre Domain muss unter verifiziert werden Google Search Console mit jeder verfügbaren Methode.

3
Die sitemap.xml-Datei

Ihre Website muss öffentlich zugänglich sein sitemap.xml. IndexFast liest es, um eine Liste der zu indizierenden URLs zu erhalten.

4
JSON-Schlüssel des Dienstkontos

Von der Google Cloud Console heruntergeladene Datei .json mit Rechten an der Web Search Indexing API.

💡
Wenn Ihre Website noch nicht in der Search Console vorhanden ist, fügen Sie sie zuerst hinzu und bestätigen Sie den Besitz. Eine ausführliche Anleitung finden Sie unter Google-Website.

☁️ Google Cloud-Einstellungen

API-Aktivierung

Gehen Sie zur Google Cloud Console → APIs & Dienste → Bibliothek. Finden Sie es „Web Search Indexing API“ und drücken Aktivieren.

⚠️
Wichtig Die API muss in dem Projekt aktiviert sein, mit dem Ihr Dienstkonto verknüpft ist. Wenn die API nicht aktiviert ist, erhalten Sie eine Fehlermeldung 403 accessNotConfigured.

Erstellen eines Dienstkontos

Ein Dienstkonto ist ein passwortloses technisches Konto, das IndexFast zur Autorisierung von Google APIs verwendet. Um es zu erstellen, benötigen Sie ein Projekt in Google Cloud.

🛠
Bevor Sie beginnen, aktivieren Sie die Indexierungs-API in Ihrem Projekt über Tuning-Tool. Ohne diesen Schritt erhalten Sie eine Fehlermeldung 403 accessNotConfigured.
1
Öffnen Sie den Abschnitt Dienstkonten

Gehe zu Google Cloud Console → IAM & Admin → Dienstkonten. Wählen Sie ggf. das gewünschte Projekt aus.

2
Klicken Sie auf „Dienstkonto erstellen“

Geben Sie beispielsweise einen Namen ein IndexFast-botund Beschreibung. Die Kennung kann automatisch belassen werden. Klicken „Erstellen und fortfahren“.

Abschnitt „Zugriffsrechte“ Ein Ausfüllen ist nicht erforderlich – klicken Sie "Weitermachen", Dann "Erledigt".

3
Erstellen Sie einen JSON-Schlüssel

Öffnen Sie das neu erstellte Konto → Registerkarte Schlüssel → Schlüssel hinzufügen → Neuen Schlüssel erstellen. Wählen Sie ein Format JSON und drücken "Erstellen".

Die Datei wird automatisch auf Ihren Computer heruntergeladen – dies ist die einzige Kopie des Schlüssels. Bewahren Sie es an einem sicheren Ort auf und veröffentlichen Sie es niemals auf Git oder öffentlichen Repositorys.

💡
Die JSON-Datei sollte so aussehen – wenn die Struktur anders ist, wurde der Schlüssel falsch generiert.
JSON service-account.json 
{
  Typ: „service_account“,
  „Projekt_ID“: „Ihre-Projekt-ID“,
  „private_key_id“: „abc123…“,
  „private_key“: „-----BEGIN RSA PRIVATE KEY-----\n…“,
  „client_email“: "[email protected]",
  „client_id“: „123456789“,
  „auth_uri“: „https://accounts.google.com/o/oauth2/auth“,
  „token_uri“: „https://oauth2.googleapis.com/token“
}

🔗 Search Console-Verbindung

Ohne diesen Schritt gibt die API einen Fehler zurück 403 Verboten auch mit dem richtigen Schlüssel. Das Dienstkonto muss den Status des Websitebesitzers in der Google Search Console erhalten.

1
Bestätigen Sie die Eigentümerschaft der Website

Gehe zu Google Search Console und stellen Sie sicher, dass die Website Ihnen gehört – mit allen verfügbaren Mitteln (DNS-Eintrag, HTML-Datei usw.).

2
Kopieren Sie die E-Mail-Adresse des Dienstkontos

Öffnen Sie die heruntergeladene JSON-Datei und suchen Sie das Feld client_email. E-Mail sieht so aus:

Kontoname@Projektname.iam.gserviceaccount.com

Zum Beispiel: [email protected]

3
Fügen Sie das Dienstkonto als delegierter Eigentümer hinzu

Wählen Sie in der Search Console Ihre Website aus → Einstellungen → Verifizierte Besitzer → Besitzer hinzufügen. Geben Sie die E-Mail-Adresse des Dienstkontos ein und bestätigen Sie.

⚠️
Die Rolle ist genau das, was benötigt wird Eigentümer (nicht „Vollzugriff“). Ohne dies kehrt die API zurück 403 Verboten.
4
Warten Sie 1-2 Minuten

Rechte werden nicht sofort angewendet. Danach kann IndexFast URLs zur Indexierung über Ihre Website senden.

🗺 sitemap.xml

IndexFast liest Ihre sitemap.xml um URLs zu erhalten, die zur Indexierung übermittelt werden sollen. Alle Formate werden unterstützt.

Unterstützte Formate

  • ✅ sitemap.xml – eine Standarddatei mit einer URL
  • ✅ sitemap_index.xml — übergeordnete Datei mit Links zur untergeordneten Sitemap (beliebige Verschachtelungstiefe)
  • ✅ Sitemap mit Tags — Filterung nach Aktualisierungsdatum

Wo finde ich die Sitemap-URL?

Standard: /sitemap.xml WordPress (Yoast): /sitemap_index.xml Shopify: /sitemap.xml Laravel: /sitemap.xml
⚠️
Wichtig Die Sitemap muss ohne Genehmigung öffentlich zugänglich sein. Überprüfen Sie, ob die Datei in einem Browser ohne Anmeldung geöffnet wird. Wenn es geschlossen ist, kann IndexFast es nicht lesen.

⚙️ So funktioniert der Service

IndexFast liest Ihre automatisch sitemap.xml und sendet die URL über die Google Indexing API. Es muss kein Skript installiert werden – alle Vorgänge werden auf IndexFast-Servern ausgeführt.

1
Sie fügen eine Site im Schrank hinzu

Geben Sie die Domäne und die sitemap.xml-URL an und fügen Sie den JSON-Schlüssel des Dienstkontos ein. IndexFast prüft die Verfügbarkeit der Sitemap und speichert die Einstellungen.

2
IndexFast liest die Sitemap

Der Dienst unterstützt reguläre Sitemaps und Sitemap-Index (Anhänge beliebiger Tiefe). URLs werden automatisch entsprechend dem Tageslimit Ihres Plans in die Warteschlange gestellt.

3
URLs werden an Google gesendet

Der Dienst verwendet Ihr Dienstkonto zur Autorisierung und sendet die URL über die offizielle Google Indexing API. Das Ergebnis sehen Sie in Echtzeit in Ihrem persönlichen Konto.

📊
Die Beschränkungen hängen vom Plan ab: Start – 10 URLs/Tag, PRO – 100 URLs/Tag, Agentur – 1000 URLs/Tag. Das Limit wird täglich um 00:00 Uhr aktualisiert.

🤖 Automatischer Zeitplan

IndexFast startet die Indizierung automatisch – keine Notwendigkeit, Cron zu konfigurieren oder einen Server zu warten. Der Dienst ist auf der IndexFast-Seite rund um die Uhr verfügbar.

💡
Um die Indizierung manuell zu starten, drücken Sie „▶ Starten“ in Ihrem persönlichen Konto neben der gewünschten Seite. Das Ergebnis erscheint innerhalb einer Minute in den Protokollen.

So verwalten Sie die Indizierung

1
Aktiver Modus

Site mit Status Aktiv sendet automatisch URLs innerhalb des Tageslimits. Das Limit wird zu gleichen Teilen auf alle aktiven Seiten des Kontos aufgeteilt.

2
Pause

Wenn Sie die Indizierung für die Site vorübergehend stoppen müssen, klicken Sie auf „⏸“ im Büro Das Tageslimit wird nicht ausgegeben. Sie können jederzeit wiederherstellen.

3
Manueller Start

Klicken „▶ Starten“ – und IndexFast sendet innerhalb des verbleibenden Tageslimits sofort die URL aus der Sitemap. Praktisch nach der Veröffentlichung neuer Seiten.

🖱 Manuelle Indizierung

Zusätzlich zum automatischen Modus können Sie mit IndexFast die Indizierung jederzeit manuell starten – direkt von Ihrem persönlichen Konto aus.

1
Öffne den Schrank

Gehe zu IndexFast.pp.ua/app/dashboard und suchen Sie die gewünschte Site in der Liste.

2
Klicken Sie auf „▶ Start“

IndexFast liest die Sitemap sofort und sendet die URL innerhalb des verbleibenden Tageslimits.

3
Sehen Sie sich die Ergebnisse in den Protokollen an

Google API-Antworten werden innerhalb von 1–2 Minuten auf der Registerkarte „Protokolle“ angezeigt. Sie können den Status jeder URL sehen: 200 OK, 403, oder eine andere Antwort.

ℹ️
Bei der manuellen Indizierung gilt dasselbe Tageslimit wie bei der automatischen Indizierung. Wenn das Limit erreicht ist, stellt IndexFast die URL für den nächsten Tag in die Warteschlange.

📊 API-Grenzwerte

Google stellt ein kostenloses Limit von y zur Verfügung 200 URLs pro Tag pro Dienstkonto. IndexFast überwacht automatisch das Limit und stoppt, wenn es erreicht ist.

PlanenURL/TagWebsitesDienstkonten
Start (kostenlos)1011
PRO100bis 51
Agentur1000bis 50unbegrenzt
💡
Das Tageslimit wird täglich aktualisiert 00:00 UTC. Wenn Sie viele Websites haben, wird das Limit automatisch gleichmäßig auf diese verteilt.

📡 API-Referenz

Genehmigung

Google Indexing API verwendet OAuth 2.0 über das Dienstkonto. IndexFast übernimmt die Autorisierung automatisch – Sie benötigen nur den JSON-Schlüssel.

Endpunkt zum Empfangen eines Tokens:

HTTP
POST https://oauth2.googleapis.com/token

Inhaltstyp: application/x-www-form-urlencoded

grant_type=urn:ietf:params:oauth:grant-type:jwt-bearer
&Behauptung={JWT_TOKEN}

Einreichen von URLs zur Indexierung

ParameterTypObligatorischBeschreibung
URLZeichenfolgeerforderlichVollständige URL mit https://
TypAufzählungerforderlichURL_UPDATED oder URL_DELETED
HTTP
POST https://indexing.googleapis.com/v3/urlNotifications:publish

Autorisierung: Inhaber {ACCESS_TOKEN}
Content-Type: application/json

{
  „URL“: „https://your-site.com/new-page“,
  Typ: „URL_UPDATED“

Erfolgreiche Antwort:

❓FAQ

Wie lange dauert die Indizierung nach der Einreichung?

Google verarbeitet Anfragen in der Regel innerhalb von 24–48 Stunden. In den meisten Fällen erscheinen Seiten bereits am nächsten Morgen nach dem Absenden in der Suche.

Ist es möglich, mehr als 200 URLs pro Tag einzureichen?

200 URLs ist das standardmäßige kostenlose Limit von Google. Bei Bedarf können Sie über die Google Cloud Console eine Limiterhöhung beantragen. IndexFast stoppt automatisch, wenn das Limit erreicht ist, und wird am nächsten Tag fortgesetzt.

Ist es für SEO sicher, die Indexierungs-API zu verwenden?

Ja, das ist es offiziell Von Google selbst empfohlene Methode. Es besteht kein Risiko einer Strafe oder Herabstufung – im Gegenteil: Eine schnellere Indexierung verbessert die Wettbewerbsfähigkeit.

Sitemap-Index oder normale Sitemap?

IndexFast unterstützt beide Typen. Wenn Sie den Link an weitergeben sitemap_index.xml — Das Skript umgeht automatisch alle angehängten Dateien und speichert alle URLs.
