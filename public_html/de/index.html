FAQ

Häufig gestellte Fragen

Nach der Übermittlung über IndexFast indiziert Google die Seiten normalerweise innerhalb von 24 bis 48 Stunden. Es ist normal Ein Googlebot-Scan kann zwischen 2 Wochen und mehreren Monaten dauern.

Google stellt über die Indexing API ein Kontingent von 200 URLs pro Tag kostenlos zur Verfügung. Kostenloser IndexFast-Plan verwaltet dieses Kontingent automatisch. Das Kontingent kann auf Pro- und Agency-Tarife erweitert werden.

Für die grundlegende Nutzung müssen Sie lediglich ein Google Search Console-Konto verbinden und eine URL angeben sitemap.xml. Schritt-für-Schritt-Anleitungen sind im Lieferumfang enthalten. Für die Automatisierung durch Cron benötigen Sie die Grundlagen Kenntnisse in Linux.

IndexFast verwendet nur die offizielle Google Indexing API. Dies ist die von Google empfohlene Methode für Beschleunigung der Indizierung. Keine Risiken für Ihre Website.

Ja, IndexFast unterstützt auch das IndexNow-Protokoll vollständig. Das bedeutet, dass Ihre Links automatisch nicht nur an Google, sondern gleichzeitig auch an Bing, Naver, Seznam.cz und Yep gesendet werden.

IndexFast funktioniert mit jeder Site, die über eine sitemap.xml verfügt – WordPress, Webflow, Wix, benutzerdefiniert. Wenn Ihre Website verfügt über eine Sitemap – IndexFast funktioniert damit.

Die Tarife Pro und Agency verfügen über einen integrierten Planer. Im kostenlosen Plan können Sie einen Cron-Task einrichten auf dem Server - detaillierte Anweisungen finden Sie in der Dokumentation.

Ja, wir gewähren Ihnen innerhalb von 14 Tagen nach der Zahlung eine vollständige Rückerstattungsgarantie, wenn Ihnen der Service nicht zusagt. Für Anfragen schreiben Sie an indexfastapp@gmail.com.
