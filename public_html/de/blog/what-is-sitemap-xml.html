Was ist sitemap.xml und warum brauchen Sie sie

Sitemap.xml ist eine der wichtigsten Dateien für SEO, die oft vergessen oder falsch konfiguriert wird. Lassen Sie uns analysieren, was es ist, wie es aussieht, wie man es erstellt und warum es sich direkt auf die Indexierungsgeschwindigkeit Ihrer Website auswirkt.

Was ist sitemap.xml?

Eine Sitemap ist eine XML-Datei, die eine Liste aller wichtigen URLs Ihrer Website enthält. Sie befindet sich unter https://your-site.com/sitemap.xml und fungiert als "Reiseführer" für Suchmaschinen-Crawler.

📌 Offizielle Position von Google

Google empfiehlt die Verwendung einer Sitemap für jede Website mit mehr als 500 Seiten, für neue Websites mit wenigen externen Links und für Websites mit Medieninhalten (Videos, Bilder).

Struktur von sitemap.xml

Eine grundlegende Sitemap sieht so aus:

<?xml version="1.0" encoding="UTF-8"?> <urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9"> <url> <loc>https://your-site.com/about</loc> <lastmod>2026-01-20</lastmod> <changefreq>monthly</changefreq> <priority>0.8</priority> </url> </urlset>

Was die Tags bedeuten:

TagErforderlichBeschreibung
<loc>✅ JaVollständige URL der Seite beginnend mit https://
<lastmod>❌ NeinDatum der letzten Änderung (Format YYYY-MM-DD)
<changefreq>❌ NeinHäufigkeit der Änderungen: always, hourly, daily, weekly, monthly, yearly, never
<priority>❌ NeinPriorität von 0,0 bis 1,0 (Standard ist 0,5)
⚠️ Gut zu wissen

Google hat offiziell erklärt, dass changefreq und priority meist ignoriert werden. lastmod ist jedoch wirklich wichtig - Google priorisiert Seiten mit einem aktuellen Änderungsdatum.

Arten von Sitemaps

Reguläre Sitemap

Eine Liste von URLs im XML-Format. Geeignet für Websites mit bis zu 50.000 Seiten.

Sitemap-Index

Wenn Sie mehr als 50.000 URLs haben oder die Datei 50 MB überschreitet, verwenden Sie einen Sitemap-Index. Dies ist eine "übergeordnete Datei", die auf separate Sitemap-Dateien verweist.

Wie man eine sitemap.xml erstellt

1
WordPress

Plugins wie Yoast SEO oder Rank Math generieren automatisch eine Sitemap unter /sitemap_index.xml.

2
Webflow / Shopify

Sitemaps werden automatisch generiert und sind unter /sitemap.xml verfügbar.

3
Eigene Entwicklung (PHP/Node)

Generieren Sie dynamisch aus der Datenbank mit Hilfe von Paketen oder schreiben Sie ein einfaches Skript.

So registrieren Sie Ihre Sitemap bei Google

Eine Sitemap zu haben, reicht nicht aus. Google muss wissen, wo sie ist. Es gibt zwei Möglichkeiten:

Methode 1: über robots.txt

User-agent: * Allow: / Sitemap: https://your-site.com/sitemap.xml

Methode 2: über Google Search Console

  1. Öffnen Sie die Search Console → wählen Sie Ihre Property aus.
  2. Im linken Menü: Indexierung → Sitemaps.
  3. Geben Sie Ihre Sitemap-URL ein und klicken Sie auf "Senden".

Häufige Sitemap-Fehler

  • URLs mit noindex - Schließen Sie keine Seiten mit einem noindex-Tag ein.
  • Defekte Links - Alle URLs in der Sitemap müssen den Statuscode 200 zurückgeben, nicht 301 oder 404.
  • Veraltete lastmod - Wenn Sie lastmod angeben, aktualisieren Sie es nur bei echten Änderungen.
  • Fehlende Sitemap in robots.txt - Google könnte Ihre Datei einfach nicht finden.

Sitemap + Indexing API = maximale Geschwindigkeit

Auch eine in der Search Console registrierte Sitemap garantiert keine schnelle Indexierung. Google verarbeitet sie möglicherweise in einer Woche oder vielleicht in einem Monat.

Die effektivste Strategie ist die Kombination einer aktuellen Sitemap mit der aktiven Übermittlung von URLs über die Google Indexing API. Sie warten nicht, bis Google von selbst kommt - Sie sagen ihm: "Hier ist eine neue Seite, crawle sie jetzt".
