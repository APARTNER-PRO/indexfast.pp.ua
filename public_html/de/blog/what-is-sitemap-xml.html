Was ist sitemap.xml und warum benötigen Sie es

Sitemap.xml ist eine der wichtigsten Dateien für SEO, die oft vergessen oder falsch konfiguriert wird. Lassen Sie uns analysieren, was es ist, wie es aussieht, wie man es erstellt und warum es die Indexierungsgeschwindigkeit Ihrer Website direkt beeinflusst.

Was ist sitemap.xml?

Eine Sitemap ist eine XML-Datei, die eine Liste aller wichtigen URLs Ihrer Website enthält. Sie befindet sich unter https://your-site.com/sitemap.xml und fungiert als "Leitfaden" für Suchmaschinen-Crawler.

Stellen Sie sich vor, Ihre Website ist ein großes Bürogebäude. Ohne einen Grundriss würde der Reinigungskraft (Googlebot) durch die Flure irren, möglicherweise einige Räume nie finden. Eine Sitemap ist genau dieser Plan, der zeigt, wo alles zu finden ist.

📌 Offizielle Position von Google

Google empfiehlt die Verwendung einer Sitemap für jede Website mit mehr als 500 Seiten, neue Websites mit wenigen externen Links und Websites mit Medieninhalten (Videos, Bilder).

Struktur von sitemap.xml

Eine grundlegende Sitemap sieht so aus:

<?xml version="1.0" encoding="UTF-8"?> <urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9"> <url> <loc>https://your-site.com/about</loc> <lastmod>2026-01-20</lastmod> <changefreq>monatlich</changefreq> <priority>0.8</priority> </url> </urlset>

Was die Tags bedeuten:

TagErforderlichBeschreibung
<loc>✅ JaVollständige URL der Seite, die mit https:// beginnt
<lastmod>❌ NeinDatum der letzten Änderung (Format YYYY-MM-DD)
<changefreq>❌ NeinÄnderungshäufigkeit: immer, stündlich, täglich, wöchentlich, monatlich, jährlich, nie
<priority>❌ NeinPriorität von 0.0 bis 1.0 (Standard ist 0.5)
⚠️ Gut zu wissen

Google hat offiziell erklärt, dass changefreq und priority größtenteils ignoriert werden. lastmod ist jedoch wirklich wichtig — Google priorisiert Seiten mit einem aktuellen Änderungsdatum.

Arten von Sitemaps

Reguläre Sitemap

Eine Liste von URLs im XML-Format. Geeignet für Websites mit bis zu 50.000 Seiten.

Sitemap-Index

Wenn Sie mehr als 50.000 URLs haben oder die Datei 50 MB überschreitet — verwenden Sie einen Sitemap-Index. Dies ist eine "Eltern-Datei", die auf separate Sitemap-Dateien verweist.

Sitemaps werden automatisch generiert und sind unter /sitemap.xml verfügbar.

3
Eigene Entwicklung (PHP/Node)

Generieren Sie dynamisch aus der Datenbank oder verwenden Sie Pakete.

Wie man seine Sitemap bei Google registriert

Eine Sitemap zu haben, reicht nicht aus. Google muss wissen, wo sie sich befindet. Es gibt zwei Möglichkeiten:

Methode 1: über robots.txt

User-agent: * Allow: / Sitemap: https://your-site.com/sitemap.xml

Methode 2: über die Google Search Console

  1. Öffnen Sie die Search Console → wählen Sie Ihr Eigentum aus.
  2. Im linken Menü: Indizierung → Sitemaps.
  3. Geben Sie Ihre Sitemap-URL ein und klicken Sie auf "Einreichen".

Häufige Fehler bei Sitemaps

  • URLs mit noindex — schließen Sie Seiten mit einem noindex-Tag nicht in die Sitemap ein.
  • Defekte Links — alle URLs in der Sitemap müssen einen Statuscode 200 zurückgeben, nicht 301 oder 404.
  • Veraltetes lastmod — wenn Sie lastmod angeben, aktualisieren Sie es nur bei tatsächlichen Änderungen.
  • Sitemap fehlt in robots.txt — Google könnte Ihre Datei einfach nicht finden.

Sitemap + Indexing API = maximale Geschwindigkeit

Selbst eine registrierte Sitemap in der Search Console garantiert keine schnelle Indizierung. Google könnte sie in einer Woche oder vielleicht in einem Monat verarbeiten.

Die effektivste Strategie besteht darin, eine aktuelle Sitemap mit aktiver URL-Einreichung über die Google Indexing API zu kombinieren. Sie warten nicht darauf, dass Google selbst kommt — Sie sagen ihm "hier ist eine neue Seite, crawle sie jetzt".
