Warum wird meine Seite nicht in Google indexiert — 12 Gründe und wie man sie behebt

Sie haben Ihre Seite gestartet, einige Wochen gewartet — und nichts in Google. Oder einige Seiten erscheinen in der Suche, während andere scheinbar nicht existieren. Wir behandeln die 12 häufigsten Gründe, warum Google eine Seite oder einzelne Seiten ignoriert — und was genau in jedem Fall zu tun ist.

Zuerst: Überprüfen Sie, ob es ein Problem gibt

Bevor Sie nach der Ursache suchen, stellen Sie sicher, dass das Problem tatsächlich besteht. Geben Sie in Google ein:

site:yoursite.com

Wenn es keine Ergebnisse gibt oder deutlich weniger als die Anzahl der Seiten auf der Seite — lesen Sie weiter.

Öffnen Sie auch die Google Search Console → Indexierung → Seiten. Dort erklärt Google selbst, warum jede Seite nicht indexiert ist.

12 Gründe und Lösungen

Grund 01

noindex-Tag auf der Seite

Der häufigste Grund für die "Unsichtbarkeit" in Google. Der Seiten-Code enthält ein Tag, das die Indizierung direkt verbietet:

<meta name="robots" content="noindex">

Ein solches Tag könnte versehentlich während der Entwicklung aufgetaucht sein oder wenn das CMS automatisch noindex für bestimmte Arten von Seiten (Tags, Kategorien, Suchseiten) festlegt.

✓ Lösung

Überprüfen Sie den Code jeder Seite (Strg+U im Browser, suchen Sie nach "noindex"). In WordPress — überprüfen Sie Yoast SEO oder RankMath, Sichtbarkeitseinstellungen für jeden Beitragstyp.

Grund 02

In robots.txt blockiert

Die robots.txt-Datei kann Googlebot daran hindern, ganze Abschnitte der Seite zu crawlen. Öffnen Sie yoursite.com/robots.txt und suchen Sie nach Zeilen wie:

Disallow: / Disallow: /blog/
✓ Lösung

Wenn die Zeile Disallow: / — blockiert dies die gesamte Seite. Löschen oder ersetzen Sie sie durch Disallow: (leerer Wert — erlaubt alles). Überprüfen Sie dies über das Testtool für robots.txt in der Search Console.

Grund 03

Seite ist passwortgeschützt oder in Wartung

Wenn die Seite eine Autorisierung erfordert oder einen 503-Code zurückgibt — kann Googlebot nicht auf den Inhalt zugreifen. Dies ist typisch für neue Seiten, die "leise" gestartet werden.

✓ Lösung

Stellen Sie sicher, dass die Seite ohne Autorisierung zugänglich ist. Überprüfen Sie dies über die Google Search Console → URL-Inspektion → "Live-URL testen".

Grund 04

Niedriges Crawl-Budget — Googlebot kann nicht mithalten

Google weist jeder Seite ein bestimmtes "Crawl-Budget" zu — die Anzahl der Seiten, die es bereit ist, in einer bestimmten Zeit zu crawlen. Für neue und kleine Seiten ist dieses Budget minimal.

Wenn die Seite Tausende von Seiten hat oder sich häufig ändert — kann Googlebot einfach nicht alle URLs crawlen.

✓ Lösung

Verwenden Sie die Google Indexing API für priorisierte Seiten. Entfernen Sie "Müll"-URLs aus der Sitemap (Tags mit 1 Artikel, leere Kategorien, Suchanfragen). Überprüfen Sie die Geschwindigkeit der Seite — eine langsame Seite erhält ein kleineres Crawl-Budget.

Grund 05

Doppelter Inhalt und kanonisch

Wenn mehrere URLs denselben oder sehr ähnlichen Inhalt haben, wählt Google eine "kanonische" URL aus und kann die anderen ignorieren. Häufige Probleme:

  • HTTP- und HTTPS-Versionen der Seite ohne Weiterleitung
  • www- und non-www-Versionen
  • Seiten mit und ohne abschließendem Schrägstrich: /page und /page/
  • URL-Parameter: /page?utm_source=... anstelle von /page
✓ Lösung

Setzen Sie das kanonische Tag auf allen Seiten, das auf die "primäre" Version verweist. Konfigurieren Sie 301-Weiterleitungen. Überprüfen Sie in der Search Console den Bericht "Entdeckt — derzeit nicht indexiert" — dort sind oft Informationen über Duplikate enthalten.

Grund 06

Dünner oder minderwertiger Inhalt

Google kann die Indizierung von Seiten mit wenig einzigartigem Text ablehnen. Gefährdet sind:

  • Seiten mit weniger als 300–500 Wörtern
  • Automatisch generierter Inhalt
  • Vorlagenseiten mit minimalem einzigartigem Inhalt (Tags, Monate)
  • Inhalt, der von anderen Seiten kopiert wurde
✓ Lösung

Verbessern Sie den Inhalt erheblich oder schließen Sie solche Seiten mit dem noindex-Tag. Es ist besser, 50 qualitativ hochwertige indexierte Seiten zu haben als 500 "unsichtbare".

Grund 07

Serverfehler — 4xx- und 5xx-Codes

Wenn Googlebot beim Anfordern von Seiten Fehler erhält — hört er auf, sie zu besuchen und entfernt sie aus dem Index. Codes 404 (nicht gefunden), 500 (Serverfehler), 503 (Dienst nicht verfügbar) — all dies reduziert die Crawling-Aktivität.

✓ Lösung

Search Console → Indexierung → Seiten → "Nicht gefunden (404)" und "Serverfehler (5xx)". Beheben Sie die Fehler oder konfigurieren Sie 301-Weiterleitungen für gelöschte Seiten. Überprüfen Sie die Serverprotokolle auf massenhafte Fehler.

Grund 08

Langsame Ladegeschwindigkeit der Seite

Google berücksichtigt Core Web Vitals bei der Bewertung und bei der Bestimmung des Crawl-Budgets. Eine sehr langsame Seite (LCP > 4 Sekunden) erhält ein kleineres Crawl-Budget.

✓ Lösung

Überprüfen Sie dies über PageSpeed Insights (pagespeed.web.dev). Wichtige Kennzahlen: LCP (Largest Contentful Paint) unter 2,5 s, FID unter 100 ms, CLS unter 0,1. Optimieren Sie Bilder, aktivieren Sie das Caching, verbinden Sie ein CDN.

Grund 09

Keine Links zur Seite

Googlebot findet neue Seiten hauptsächlich über Links. Wenn es keine internen oder externen Links zu einer Seite gibt — kann sie "unsichtbar" bleiben, selbst wenn sie in der Sitemap ist.

✓ Lösung

Fügen Sie interne Links von anderen beliebten Seiten hinzu. Stellen Sie sicher, dass neue Artikel in den Abschnitten "Auch lesen", "Neue Veröffentlichungen" usw. erscheinen. Oder verwenden Sie die Indexing API, um Google direkt zu benachrichtigen.

Grund 10

JavaScript-Rendering blockiert Inhalte

Wenn Ihre Seite auf React, Vue oder Angular basiert und der Inhalt nur auf der Client-Seite gerendert wird — kann Googlebot den Text der Seiten möglicherweise nicht sehen. Er "sieht" nur ein leeres HTML-Gerüst.

✓ Lösung

Konfigurieren Sie Server-Side Rendering (SSR) oder Static Site Generation (SSG). Überprüfen Sie dies über die Search Console → URL-Inspektion → "Gecrawlte Seite anzeigen" — dort wird genau angezeigt, was Googlebot sieht.

Grund 11

Junger Domain — braucht einfach Zeit

Für neue Domains (weniger als 6 Monate alt) fügt Google normalerweise Seiten langsamer zum Index hinzu. Das ist normal — Algorithmen überprüfen die Zuverlässigkeit neuer Ressourcen.

✓ Lösung

Erhalten Sie einige qualitativ hochwertige externe Links (von autoritativen Seiten in Ihrer Nische). Veröffentlichen Sie regelmäßig qualitativ hochwertige Inhalte. Verwenden Sie die Indexing API, um den Prozess zu beschleunigen. Registrieren Sie die Seite in der Search Console und fügen Sie eine Sitemap hinzu.

Grund 12

Google-Filter oder Strafe

In seltenen Fällen kann eine Seite eine manuelle Strafe vom Google-Team erhalten (für Linkmanipulation, Spam-Inhalte, Cloaking usw.) oder eine automatische algorithmische Strafe.

✓ Lösung

Überprüfen Sie die Search Console → Sicherheit & manuelle Maßnahmen → Manuelle Maßnahmen. Wenn es eine Strafe gibt — beheben Sie die Verstöße und reichen Sie einen Überprüfungsantrag ein. Bei algorithmischen Filtern — verbessern Sie die Inhaltsqualität und das Linkprofil.

Schritt-für-Schritt-Aktionsplan

Wenn Ihre Seite nicht indexiert ist — handeln Sie in dieser Reihenfolge:

  1. Überprüfen Sie robots.txt — stellen Sie sicher, dass es keine Blockierungen gibt
  2. Überprüfen Sie den noindex-Tag auf problematischen Seiten
  3. Öffnen Sie die Search Console → Seiten → lesen Sie die Ausschlussgründe
  4. Überprüfen Sie die Zugänglichkeit der Seite und die Serverantwortcodes
  5. Überprüfen Sie die Geschwindigkeit über PageSpeed Insights
  6. Beseitigen Sie die gefundenen Probleme
  7. Sendet URLs über die Google Indexing API, um die Indizierung zu beschleunigen
