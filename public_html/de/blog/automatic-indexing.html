Automatische Google-Indexierung: Einmal einrichten — funktioniert immer

Warten jeden Tag neue Seiten wochenlang darauf, dass Google sie findet? Die automatische Indexierung über die Google Indexing API löst das Problem ein für alle Mal. Wir stellen drei Einrichtungsmethoden vor – vom eigenen Skript bis zur No-Code-Lösung.

Das Problem der manuellen Indexierung

Jeden Tag veröffentlichen Sie neue Inhalte. Neue Produkte, Artikel, Landingpages, aktualisierte Preise. Und jeden Tag die gleiche Frage: „Warum zeigt Google die neuen Seiten noch nicht an?“

Die manuelle Einreichung über die Search Console ist auf 10-15 URLs pro Tag begrenzt. Wenn Sie einen Onlineshop mit dutzenden neuen Produkten täglich oder einen aktiven Blog haben, skaliert die manuelle Arbeit einfach nicht.

Die Automatisierung der Indexierung löst dieses Problem ein für alle Mal.

Was ist automatische Indexierung?

Automatische Indexierung ist ein konfigurierter Prozess, bei dem jede neue oder aktualisierte Seite ohne Ihr Zutun automatisch über die Indexing API an Google gesendet wird.

Der Ablauf sieht so aus:

  1. Sie veröffentlichen neuen Content oder aktualisieren bestehenden
  2. Das System erkennt die Änderung (über Sitemap oder CMS-Webhook)
  3. Die URL wird automatisch über die Google Indexing API gesendet
  4. Googlebot crawlt die Seite innerhalb weniger Stunden
  5. Die Seite erscheint noch am selben Tag in den Suchergebnissen
💡 Ansätze im Vergleich

Ohne Automatisierung wartet ein neuer Artikel 14-60 Tage auf die Indexierung. Mit der automatischen Übermittlung über die Indexing API sind es 2-24 Stunden. Für eine Nachrichtenseite oder einen aktiven Shop ist dies der Unterschied zwischen dem ersten und dem letzten Platz im Rennen um den Traffic.

Möglichkeiten zur Einrichtung der automatischen Indexierung

Option 1: Selbst über Google Cloud + Skript

Ein technischer Ansatz, der Programmierkenntnisse erfordert:

  • Ein Projekt in der Google Cloud Console erstellen
  • Die Google Indexing API aktivieren
  • Ein Dienstkonto mit Inhaberrechten in der Search Console erstellen
  • Ein Skript (Python, PHP, Node.js) zum Senden von Anfragen schreiben
  • Einen Cronjob für die automatische Ausführung einrichten
  • Protokollierung und Fehlerbehandlung hinzufügen

Einrichtungszeit: 4-8 Stunden für einen erfahrenen Entwickler. Erfordert Wartung und Überwachung.

Option 2: WordPress-Plugins

Es gibt Plugins (Rank Math, IndexNow, Instant Indexing), die neue Beiträge automatisch übermitteln. Einschränkungen: nur für WordPress, die Einrichtung kann komplex sein, nicht alle unterstützen die offizielle Google Indexing API.

Option 3: IndexFast — ohne Code

IndexFast automatisiert den gesamten Prozess ohne Code zu schreiben:

  • Sie verbinden die Website und die Sitemap – einmalig
  • Sie legen einen Zeitplan fest: täglich, stündlich oder nach jeder Sitemap-Aktualisierung
  • IndexFast liest die Sitemap selbständig, findet neue URLs und sendet sie über die API
  • Alle Ergebnisse finden Sie in einem übersichtlichen Dashboard mit Protokollen

Einrichtungszeit: 5-10 Minuten. Unterstützt jedes CMS.

Google Indexing API Limits und wie man sie umgeht

Die Google Indexing API hat standardmäßig ein Limit von 200 Anfragen pro Tag und Website. Für die meisten Seiten reicht das aus, aber es gibt Ausnahmen:

  • Große Shops mit hunderten neuen Produkten täglich – Sie müssen in der Google Cloud Console eine Erhöhung des Kontingents beantragen
  • Nachrichtenseiten mit dutzenden Publikationen pro Tag – IndexFast verteilt die Übermittlung gleichmäßig über den Tag
  • Bei der ersten Verbindung – senden Sie in den ersten Tagen vorrangige Seiten, dann den Rest
⚠ Senden Sie nicht alles wahllos

Das Limit von 200 URLs pro Tag gilt nicht für alle Seiten der Website gleichzeitig. Senden Sie nur Seiten mit hochwertigen Inhalten. Tags, Filter- und Paginierungsseiten verschwenden das Limit ohne wirklichen Nutzen.

Automatisierung für verschiedene CMS

WordPress

Einrichtung in IndexFast: Geben Sie die Sitemap-URL an (normalerweise /sitemap_index.xml oder /post-sitemap.xml). IndexFast prüft die Sitemap stündlich und sendet neue URLs automatisch.

OpenCart / PrestaShop

Generieren Sie eine Sitemap über ein integriertes Tool oder Plugin. Verbinden Sie die Sitemap-URL mit IndexFast – alles weitere geschieht automatisch.

Benutzerdefinierte Website

Generieren oder aktualisieren Sie die sitemap.xml bei jeder Veröffentlichung. Oder nutzen Sie einen Webhook: bei Veröffentlichung → POST-Anfrage an die IndexFast API → automatische Übermittlung.

Echte Automatisierungsergebnisse

IndexFast-Kunden berichten:

  • Neuer Content erscheint noch am Tag der Veröffentlichung bei Google
  • Die Anzahl der indexierten Seiten wächst im ersten Monat um 40-80%
  • Der organische Traffic beginnt 2-4 Wochen nach vollständiger Indexierung zu steigen
  • Null manuelle Arbeit mit der URL-Übermittlung – das System arbeitet selbstständig
