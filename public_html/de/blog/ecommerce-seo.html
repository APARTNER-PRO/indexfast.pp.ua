E-Commerce SEO: Indizierung von Produkten und Kategorien im Jahr 2026

Tausende von Produkten, Filter, die Tausende von doppelten URLs generieren, neue Artikel, die monatelang nicht in der Suche erscheinen — E-Commerce hat seine einzigartigen SEO-Herausforderungen. Wir analysieren jede und bieten spezifische Lösungen.

Warum Geschäfte besondere Indizierungsprobleme haben

Online-Shops gehören zu den komplexesten Seiten für SEO. Tausende von Produktseiten, Kategorien mit Filtern, Paginierung, Farb- und Größenvarianten — all dies schafft einzigartige Herausforderungen.

Das Hauptproblem: Crawl-Budget. Googlebot hat nicht genug Zeit, um alle Seiten zu crawlen, sodass einige Produkte möglicherweise nie in der Suche erscheinen. Statistisch gesehen generiert ein durchschnittlicher Online-Shop 5–10 Mal mehr URLs, als Google tatsächlich benötigt.

Produktseiten: Häufige Fehler

  • Doppelte Herstellerbeschreibungen — wenn Sie Text kopieren, ist er bereits auf Dutzenden von Seiten vorhanden. Google wählt das Original, nicht Sie.
  • Artikel, die mit dem Code 200 zurückgegeben werden, sind nicht auf Lager — "Nicht auf Lager" auf einer Live-Seite anstelle von 404/410 verschwendet Crawl-Budget.
  • Varianten ohne Canonical — blaue und rote Version eines Produkts auf verschiedenen URLs ohne Canonical-Tag — Duplikate.
  • Filterparameter — /category?color=red&size=M generiert Tausende von doppelten URLs.
💡 Lösung für Produktvarianten

Setzen Sie ein Canonical-Tag auf alle Varianten, das auf die Hauptseite verweist. Oder kombinieren Sie Varianten auf einer Seite mit einem JavaScript-Umschalter — besseres UX und besseres SEO gleichzeitig.

Kategorien und Filter

Kategorieseiten haben die besten Chancen, an die Spitze von Google zu gelangen — sie erhalten die meisten internen Links. Aber es gibt Fallen:

  • Leere Kategorien (0 Produkte) — schließen Sie sie über noindex oder löschen Sie sie.
  • Kategorien mit 1–2 Produkten — kombinieren oder fügen Sie eine Textbeschreibung von mindestens 200 Wörtern hinzu.
  • Paginierung — /category/page/2 muss crawlbar sein, jedoch ohne doppelte Titel und Beschreibungen.
⚠ Filter — Der Hauptfeind des Crawl-Budgets

Wenn eine Kategorie 10 Filter mit jeweils 5 Werten hat — das sind 50 Kombinationen und potenziell Tausende von URLs. Schließen Sie sie über robots.txt oder setzen Sie Canonical auf die übergeordnete Kategorie. Lassen Sie nur Kombinationen offen, die eine echte Suchnachfrage haben.

Schema.org Produkt — Pflicht

Strukturierte Daten helfen Google, Ihre Produkte mit Bewertung, Preis und Verfügbarkeit direkt in der Suche anzuzeigen — CTR steigt um 20–35%:

{ "@context": "https://schema.org", "@type": "Product", "name": "Produktname", "offers": { "@type": "Offer", "price": "1999", "priceCurrency": "UAH", "availability": "https://schema.org/InStock" }, "aggregateRating": { "@type": "AggregateRating", "ratingValue": "4.8", "reviewCount": "124" } }

Sitemap für einen großen Shop

Teilen Sie die Sitemap in Dateien nach Seitentyp auf — dies hilft Google, Prioritäten zu verstehen:

  • sitemap-products.xml — Produkte mit Beschreibung und Verfügbarkeit, Priorität 0.8
  • sitemap-categories.xml — aktive Kategorien, Priorität 0.9
  • sitemap-pages.xml — statische Seiten, Priorität 0.6
  • sitemap-blog.xml — Blogartikel, Priorität 0.7

Schnelle Indizierung neuer Produkte

Ohne API kann ein neues Produkt 2 Wochen bis 3 Monate auf die Indizierung warten. Für einen Shop, in dem Wettbewerber bereits ein Analog verkaufen — ist das kritisch.

Die Google Indexing API löst das Problem: Nach der Veröffentlichung eines Produkts senden Sie die URL über die API — Googlebot besucht die Seite innerhalb weniger Stunden. Besonders wichtig für:

  • Saisonale Artikel und Aktionen (Preis nur eine Woche gültig)
  • Produkte, die wieder auf Lager sind
  • Preisaktualisierungen vor Verkäufen
  • Neue Kollektionen und Neuheiten

Gelöschte Produkte: Was zu tun ist

  • Produkt vorübergehend nicht auf Lager → Seite lassen, OutOfStock in Schema.org markieren
  • Permanently deleted, has analog → 301-Redirect zu einem ähnlichen Produkt oder Kategorie
  • Permanently deleted, no analog → 410 Gone-Code (besser als 404)

E-Commerce SEO-Checkliste

  • Einzigartige Beschreibungen für alle Produkte (mindestens 150 Wörter, idealerweise 300+)
  • Canonical-Tags auf Varianten und parametrischen URLs
  • Noindex für leere Kategorien und irrelevante Filter
  • Schema.org Produkt für alle Produktseiten
  • Segmentierte Sitemap nach Typen mit korrekten Prioritäten
  • 301-Redirects oder 410 für gelöschte Produkte
  • Google Indexing API für neue und aktualisierte Produkte
