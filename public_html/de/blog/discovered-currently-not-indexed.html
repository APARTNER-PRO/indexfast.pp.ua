"Entdeckt — Derzeit nicht indiziert": Warum Google Ihre Seiten ignoriert und wie Sie es beheben können

Sie öffnen die Google Search Console und sehen eine Liste von Seiten mit dem Status "Entdeckt — derzeit nicht indiziert". Tage vergehen, Wochen vergehen — die Seiten sind immer noch nicht bei Google. Dies ist eines der frustrierendsten Probleme für Website-Besitzer. Wir erklären genau, warum das passiert und wie Sie es ein für alle Mal beheben können.

Was "Entdeckt — derzeit nicht indiziert" tatsächlich bedeutet

Dieser Status bedeutet, dass Google die URL gefunden hat — sie erschien in Ihrer Sitemap oder jemand hat darauf verlinkt — aber Google hat beschlossen, sie noch nicht zu crawlen. Mit anderen Worten: Google weiß, dass die Seite existiert, hat sich aber entschieden, sie nicht zu besuchen.

Das Schlüsselwort hier ist "gewählt". Dies ist kein technischer Fehler. Dies ist eine Planungsentscheidung von Google, die auf dem Crawl-Budget Ihrer Website und der wahrgenommenen Priorität dieser Seite basiert.

💡 Schnelle Analogie

Stellen Sie sich einen Postboten vor, der 1.000 Briefe auszuliefern hat. Er weiß, dass Ihre Adresse existiert, aber wenn er denkt, dass es sich um eine niedrigpriorisierte Lieferung handelt, legt er sie ans Ende der Warteschlange. Ihre Seite wartet monatelang — während die Seiten Ihrer Wettbewerber am selben Tag indiziert werden.

Die echten Gründe, warum Google Ihre Seiten überspringt

Viele SEO-Leitfäden geben vage Antworten wie "Verbessern Sie die Qualität des Inhalts." Die Wahrheit ist spezifischer:

  • Crawl-Budget erschöpft. Google weist pro Tag und pro Website eine begrenzte Anzahl von Crawls zu. Große Websites mit Tausenden von Seiten erschöpfen oft das Budget — neue Seiten bleiben in der Warteschlange.
  • Niedrige Domain-Autorität. Neue Websites oder Websites mit wenigen Backlinks erhalten ein kleineres Crawl-Budget. Google vertraut ihnen nicht genug, um aggressiv zu crawlen.
  • Langsame Server-Antwortzeiten. Wenn Ihr Server langsam antwortet (über 500 ms), verlangsamt sich der Crawler von Google oder stoppt, um eine Überlastung zu vermeiden.
  • Zu viele Seiten mit geringem Wert. Wenn Ihre Sitemap paginierte Filterseiten, Tag-Seiten oder doppelte Inhalte enthält, "verschwendet" Google sein Budget auf diese anstelle Ihres wichtigen Inhalts.
  • Keine interne Verlinkung. Seiten, die nur in der Sitemap existieren, aber keine internen Links haben, die auf sie verweisen, werden als niedrigpriorisiert angesehen.
  • Neu veröffentlicht. Neue Seiten auf etablierten Websites sind manchmal mehrere Tage in der Warteschlange "entdeckt", bevor sie verarbeitet werden. Bei Websites mit niedriger Autorität kann dies Monate dauern.

Was man NICHT tun sollte (häufige Fehler)

Wenn Website-Besitzer diesen Status sehen, verschlimmern sie oft die Situation:

  • Ständig eine erneute Indizierung über die "URL-Überprüfung" in der Search Console anfordern (das Limit ist sehr niedrig — nur 10-15 URLs pro Tag manuell)
  • Seiten im robots.txt blockieren und wieder aktivieren, in der Hoffnung, dass Google sie erneut crawlt
  • Seiten aus der Sitemap entfernen, in der Annahme, dass das helfen wird
  • Unendlich warten, ohne zu handeln — das kann Monate dauern
⚠ Die Falle der manuellen URL-Überprüfung

Die Schaltfläche "Indizierung anfordern" in der Google Search Console sieht wie eine Lösung aus, ist aber stark limitiert. Sie können auf diese Weise vielleicht 10-15 URLs pro Tag senden. Für eine Website mit Hunderten betroffener Seiten ist das praktisch nutzlos.

Die echte Lösung: Google über die offizielle API zur Indizierung zwingen

Google stellt die Indexing API speziell zur Verfügung, damit Websites Google über wichtige Seiten informieren können, die sofort gecrawlt werden müssen. Wenn Sie eine Anfrage über die API senden, priorisiert Google das Crawlen dieser URL — typischerweise innerhalb von 24-48 Stunden.

Dies ist kein Workaround oder eine Graubereich-Technik. Dies ist die offiziell empfohlene Methode von Google zur Beschleunigung der Indizierung.

Schritt 1: Google Search Console richtig einrichten

Überprüfen Sie Ihre Website in der Google Search Console, falls Sie dies noch nicht getan haben. Stellen Sie sicher, dass Sie eine gut strukturierte Sitemap eingereicht haben. Überprüfen Sie auf manuelle Strafen unter "Manuelle Maßnahmen" — diese können die Indizierung vollständig verhindern.

Schritt 2: Zuerst technische Probleme beheben

Bevor Sie die Indizierung erzwingen, beheben Sie, was kaputt ist: Stellen Sie sicher, dass Seiten unter 3 Sekunden laden, fügen Sie internen Links zu verwaisten Seiten hinzu, entfernen Sie wirklich wertlose Seiten aus Ihrer Sitemap und beheben Sie alle Crawling-Fehler, die in der Search Console sichtbar sind.

Schritt 3: Verwenden Sie die Google Indexing API, um Seiten zu pushen

Hier findet die echte Beschleunigung statt. Über die Indexing API können Sie Google über 200 URLs pro Tag informieren — Google sendet dann Googlebot, um diese spezifischen URLs mit hoher Priorität zu crawlen. Der Unterschied im Vergleich zum Warten:

❌
Ohne API: 2-8 Wochen
✅
Mit API: 24-48 Stunden

So machen Sie das, ohne Code zu schreiben

Die manuelle Einrichtung der Google Indexing API erfordert die Erstellung eines Google Cloud-Projekts, eines Dienstkontos, das Herunterladen von JSON-Anmeldeinformationen, das Schreiben von API-Aufrufen und die Einrichtung von Automatisierungen. Für Nicht-Entwickler ist dies eine erhebliche technische Hürde.

Welche Seiten zuerst priorisieren

Versuchen Sie nicht, alles auf einmal zu indizieren. Mit einem Kontingent von 200 URLs/Tag seien Sie strategisch:

  1. Ertragsbringende Seiten zuerst — Produktseiten, Dienstleistungsseiten, Landingpages
  2. Frischer Inhalt — neue Blogbeiträge, Nachrichtenartikel
  3. Neu aktualisierte Seiten — wenn Sie bestehende Inhalte erheblich geändert haben
  4. Überspringen Sie dünne Inhaltsseiten — paginierte Ergebnisse, Tag-Seiten, Filterkombinationen

Langfristig: Verhindern, dass der Status "Entdeckt" erneut auftritt

Sobald Sie Ihren bestehenden Rückstand behoben haben, richten Sie ein System ein, damit neue Seiten nie feststecken:

  • Automatisierte tägliche Indizierung: Stellen Sie IndexFast so ein, dass es Ihre Sitemap täglich überprüft und automatisch neue URLs einreicht. Jede Seite, die Sie veröffentlichen, wird am selben Tag indiziert.
  • Interne Verlinkung: Verlinken Sie bei der Veröffentlichung neuer Inhalte von 2-3 bestehenden beliebten Seiten auf diese. Dies signalisiert Google die Wichtigkeit.
  • Sitemap-Hygiene: Entfernen Sie Seiten, die Sie nicht indiziert haben möchten (dünner Inhalt, Duplikate) aus Ihrer Sitemap. Dies gibt dem Crawler von Google mehr Budget für Ihre wichtigen Seiten.
  • Überwachung der Search Console: Überprüfen Sie wöchentlich die Abdeckung > "Entdeckt — derzeit nicht indiziert". Wenn die Zahlen steigen, untersuchen Sie sofort.

Zusammenfassung: Was Sie jetzt tun sollten

  1. Gehen Sie zur Google Search Console → Seiten → "Entdeckt — derzeit nicht indiziert"
  2. Notieren Sie, wie viele Seiten betroffen sind und welche am wichtigsten sind
  3. Beheben Sie offensichtliche technische Probleme (langsame Ladezeiten, keine internen Links)
  4. Verbinden Sie IndexFast und reichen Sie Ihre betroffenen Seiten über die Indexing API ein
