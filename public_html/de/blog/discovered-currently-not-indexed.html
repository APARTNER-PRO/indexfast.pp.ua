"Entdeckt – derzeit nicht indexiert": Warum Google Ihre Seiten ignoriert und wie Sie es beheben

Sie öffnen die Google Search Console und sehen eine Liste von Seiten mit dem Status "Entdeckt – derzeit nicht indexiert". Tage vergehen, Wochen vergehen — die Seiten sind immer noch nicht in Google. Dies ist eines der frustrierendsten Probleme für Website-Betreiber. Wir erklären genau, warum das passiert und wie Sie es ein für alle Mal beheben.

Was "Entdeckt – derzeit nicht indexiert" wirklich bedeutet

Dieser Status bedeutet, dass Google die URL gefunden hat — über Ihre Sitemap oder einen Link — aber entschieden hat, sie noch nicht zu crawlen. Mit anderen Worten: Google weiß, dass die Seite existiert, hat aber gewählt, sie nicht zu besuchen.

Das Schlüsselwort hier ist "gewählt". Das ist kein technischer Fehler. Das ist eine Planungsentscheidung von Google basierend auf Ihrem Crawl-Budget und der wahrgenommenen Priorität dieser Seite.

💡 Einfache Analogie

Stellen Sie sich einen Postboten vor, der 1.000 Briefe zustellen muss. Er kennt Ihre Adresse, aber wenn er die Zustellung für niedrig priorisiert hält, legt er den Brief ans Ende der Warteschlange. Ihre Seite wartet monatelang, während Konkurrenzseiten am selben Tag indexiert werden.

Die eigentlichen Gründe, warum Google Ihre Seiten überspringt

Die meisten SEO-Guides geben vage Antworten wie "verbessern Sie die Inhaltsqualität". Die Wahrheit ist spezifischer:

  • Crawl-Budget erschöpft. Google weist eine begrenzte Anzahl von Crawls pro Seite und Tag zu. Große Websites mit Tausenden von Seiten erschöpfen oft das Budget.
  • Geringe Domain-Autorität. Neue Websites oder Websites mit wenigen Backlinks erhalten ein kleineres Crawl-Budget.
  • Langsame Serverantwortzeiten. Wenn Ihr Server langsam antwortet (über 500ms), verlangsamt sich Googles Crawler oder hört auf.
  • Zu viele minderwertige Seiten. Paginierte Filterseiten, Tag-Seiten oder doppelter Inhalt "verschwenden" Googles Budget.
  • Keine internen Links. Seiten, die nur in der Sitemap existieren, aber keine internen Links haben, gelten als niedrig priorisiert.
  • Kürzlich veröffentlicht. Neue Seiten auf schwachen Websites können monatelang in der "Entdeckt"-Warteschlange warten.

Was man NICHT tun sollte (häufige Fehler)

Wenn Website-Betreiber diesen Status sehen, machen sie oft die Dinge schlimmer:

  • Ständig Re-Indexierung über "URL-Prüfung" in Search Console anfordern (Limit: nur 10-15 URLs pro Tag manuell)
  • Seiten in robots.txt sperren und entsperren in der Hoffnung auf erneutes Crawlen
  • Seiten aus der Sitemap entfernen, weil man denkt, das würde helfen
  • Unbegrenzt warten ohne Maßnahmen — das kann Monate dauern
⚠ Die Falle der manuellen URL-Prüfung

Der Button "Indexierung anfragen" in Search Console sieht aus wie eine Lösung, ist aber stark ratenbegrenzt. Sie können damit täglich vielleicht 10-15 URLs senden. Für eine Website mit Hunderten betroffener Seiten ist das praktisch nutzlos.

Die echte Lösung: Google zur Indexierung über die offizielle API zwingen

Google stellt die Indexing API speziell bereit, damit Websites Google über wichtige Seiten informieren können, die sofortiges Crawlen benötigen. Wenn Sie eine Anfrage über die API senden, priorisiert Google das Crawlen dieser URL — typischerweise innerhalb von 24-48 Stunden.

Das ist keine Umgehungslösung oder eine Gray-Hat-Technik. Das ist Googles offiziell empfohlene Methode zur Beschleunigung der Indexierung.

Schritt 1: Richten Sie die Google Search Console korrekt ein

Verifizieren Sie Ihre Website in Google Search Console. Stellen Sie sicher, dass Sie eine gut strukturierte Sitemap eingereicht haben. Prüfen Sie auf manuelle Strafen unter "Manuelle Maßnahmen".

Schritt 2: Technische Probleme zuerst beheben

Bevor Sie die Indexierung erzwingen, beheben Sie Probleme: Seiten laden unter 3 Sekunden, fügen Sie interne Links zu verwaisten Seiten hinzu, entfernen Sie wirklich minderwertige Seiten aus Ihrer Sitemap.

Schritt 3: Nutzen Sie die Google Indexing API um Seiten einzureichen

Hier geschieht die echte Beschleunigung. Über die Indexing API können Sie Google über 200 URLs pro Tag informieren — Google sendet dann Googlebot mit hoher Priorität zu diesen URLs. Der Unterschied:

❌
Ohne API: 2-8 Wochen
✅
Mit API: 24-48 Stunden

Wie man das ohne Code macht

Die manuelle Einrichtung der Google Indexing API erfordert: Erstellen eines Google Cloud-Projekts, eines Service Accounts, Herunterladen von JSON-Credentials, Schreiben von API-Aufrufen und Einrichten der Automatisierung. Für Nicht-Entwickler ist das eine erhebliche technische Hürde.

  • Liest Ihre Sitemap und erkennt neue oder aktualisierte URLs
  • Sendet sie über die Google Indexing API in Ihrem Namen
  • Verwaltet das tägliche Kontingent automatisch (200 URLs/Tag)
  • Zeigt ein detailliertes Protokoll welche Seiten wann eingereicht wurden
  • Läuft nach einem Zeitplan, sodass jede neue Seite indexiert wird ohne dass Sie etwas tun müssen

Für Seiten, die bereits im "Entdeckt"-Status feststecken, können Sie sie sofort in großen Mengen einreichen. Die meisten Nutzer sehen diese Seiten innerhalb von 24-48 Stunden in Google erscheinen.

Welche Seiten zuerst priorisieren

Versuchen Sie nicht, alles auf einmal zu indexieren. Mit einem Kontingent von 200 URLs/Tag seien Sie strategisch:

  1. Zuerst umsatzgenerierende Seiten — Produktseiten, Serviceseiten, Landing Pages
  2. Frische Inhalte — neue Blogbeiträge, Nachrichtenartikel
  3. Kürzlich aktualisierte Seiten — wenn Sie bestehende Inhalte wesentlich geändert haben
  4. Dünne Inhaltsseiten überspringen — paginierte Ergebnisse, Tag-Seiten, Filterkombinationen

Langfristig: Verhindern Sie, dass der "Entdeckt"-Status erneut auftritt

Sobald Sie Ihren bestehenden Rückstand behoben haben, richten Sie ein System ein, damit neue Seiten nie wieder steckenbleiben:

  • Automatische tägliche Indexierung: Richten Sie IndexFast ein, Ihre Sitemap täglich zu überprüfen und neue URLs automatisch einzureichen.
  • Internes Verlinken: Wenn Sie neue Inhalte veröffentlichen, verlinken Sie von 2-3 bestehenden populären Seiten darauf.
  • Sitemap-Hygiene: Entfernen Sie Seiten, die Sie nicht indexiert haben möchten (dünne Inhalte, Duplikate) aus Ihrer Sitemap.
  • Search Console überwachen: Überprüfen Sie wöchentlich Abdeckung > "Entdeckt – derzeit nicht indexiert". Wenn die Zahlen steigen, untersuchen Sie sofort.

Zusammenfassung: Was jetzt sofort zu tun ist

  1. Gehen Sie zu Google Search Console → Seiten → "Entdeckt – derzeit nicht indexiert"
  2. Notieren Sie, wie viele Seiten betroffen sind und welche am wichtigsten sind
  3. Beheben Sie offensichtliche technische Probleme (langsames Laden, keine internen Links)
