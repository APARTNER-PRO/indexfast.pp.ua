Core Web Vitals: Was Sie wissen müssen

Core Web Vitals sind drei Google-Metriken, die die tatsächliche Benutzererfahrung auf einer Website messen. Seit 2021 sind sie ein offizieller Rankingfaktor. 2024 wurde INP durch FID ersetzt. Lassen Sie uns jede Metrik aufschlüsseln und wie man sie verbessert.

Was sind Core Web Vitals

Core Web Vitals (CWV) sind eine Teilmenge von Page Experience-Signalen, die Google für das Ranking verwendet. Im Gegensatz zu Lighthouse-Labortests werden CWV bei echten Nutzern über den Chrome User Experience Report (CrUX) gemessen.

Für jede Metrik: grün = gut, gelb = muss verbessert werden, rot = schlecht. Google zielt auf das 75. Perzentil ab.

LCP — Largest Contentful Paint

LCP misst die Zeit bis das größte sichtbare Element auf der Seite angezeigt wird — normalerweise ein Hero-Bild oder H1.

WertBewertung
≤ 2.5 Sekunden✅ Gut
2.5 – 4.0 Sekunden⚠️ Muss verbessert werden
> 4.0 Sekunden❌ Schlecht

Wie man LCP verbessert

  • Bilder optimieren — in WebP oder AVIF konvertieren, loading="eager" für Hero-Bilder hinzufügen.
  • LCP-Element vorladen — <link rel="preload" as="image"> hinzufügen.
  • CDN verwenden — reduziert TTFB.
  • Blockierende Ressourcen entfernen — nicht-kritisches JS und CSS auf defer/async verschieben.
  • Server-Side Rendering — SSR verbessert LCP drastisch für SPAs.

CLS — Cumulative Layout Shift

CLS misst die kumulative Verschiebung von Seitenelementen während des Ladens.

WertBewertung
≤ 0.1✅ Gut
0.1 – 0.25⚠️ Muss verbessert werden
> 0.25❌ Schlecht

Wie man CLS verbessert

  • Bildgrößen angeben — immer width und height hinzufügen.
  • Platz für Werbung reservieren — feste Größen für Werbeblöcke festlegen.
  • Keinen Inhalt über bestehenden einfügen — Banner und Cookie-Hinweise sollten unten sein.
  • Schriften vorladen — FOUT verursacht Verschiebungen.

INP — Interaction to Next Paint

INP ersetzte FID im März 2024. Es misst die Verzögerung zwischen Benutzerinteraktion und Bildschirmaktualisierung.

Im Gegensatz zu FID verfolgt INP alle Interaktionen und nimmt den schlechtesten Wert.

WertBewertung
≤ 200 ms✅ Gut
200 – 500 ms⚠️ Muss verbessert werden
> 500 ms❌ Schlecht

Wie man INP verbessert

  • Lange Aufgaben aufteilen — jedes JS > 50ms blockiert den Browser.
  • JS-Bundles verkleinern — Code-Splitting und Tree-Shaking.
  • Synchronisierte Operationen in Ereignis-Handlern vermeiden.
  • Drittanbieter-Skripte überprüfen — Chatbots und Analysen verursachen oft schlechtes INP.
⚠️ INP und CWV

INP ist die schwierigste Metrik zu optimieren.

Wie man Core Web Vitals misst

Felddaten

  • Google Search Console → "Seiten-Erfahrung".
  • PageSpeed Insights — kombiniert Feld- und Labordaten.
  • CrUX-Dashboard in Looker Studio.

Labordaten

  • Lighthouse in Chrome DevTools.
  • WebPageTest — detaillierte Wasserfall-Tests.
💡 Felddaten sind wichtiger als Labordaten

Google bewertet basierend auf Felddaten (echte Nutzer), nicht Lighthouse.

Auswirkungen von CWV auf SEO

Google hat bestätigt: CWV ist ein Rankingfaktor, aber Inhalte sind immer noch wichtiger.

Praktisch: Wenn Ihre Website im grünen Bereich ist, wird CWV das Wachstum nicht behindern.

Möchten Sie, dass korrigierte Seiten schneller indexiert werden?

Nach technischen Verbesserungen ist es wichtig, dass Google die Seiten schnell neu indexiert.
