On-Page SEO: Kompletter Leitfaden 2026

On-Page SEO ist das Fundament.

Was ist On-Page SEO?

Es sind Optimierungen innerhalb der Seite.

Optimierung steigert Conversions um 40%.

1. Title und Meta Description

Machen Sie Titel attraktiv.

Titel-Formel:

Keyword | Marke

Beispiele:

  • Matratze kaufen | SleepWell
  • Wohnungssanierung | Budmaster
  • E-Commerce SEO | IndexFast
💡 SEO-Geheimnis

Keyword in die ersten 60 Zeichen.

Meta description

160 Zeichen. CTA hinzufügen.

2. H1-H6 Hierarchie

Regeln für Überschriften:

  • H1: nur eine.
  • H2: Hauptbereiche.
  • H3-H6: Unterbereiche.
  • Keine Ebenen überspringen.

3. Content-Optimierung

Themenrelevanz ist entscheidend.

So prüfen Sie:

  • Surfer SEO / NeuronWriter.
  • LSI-Keywords.
  • TF-IDF.

4. Interne Verlinkung

Interne Links verteilen Kraft.

  • Beschreibender Ankertext.
  • Link im ersten Absatz.
  • 3-5 interne Links.
  • "Lesen Sie auch"-Modul.

5. Bilder: alt, WebP, lazy load

Bilder optimieren:

  • Alt-Text.
  • WebP/AVIF.
  • Lazy loading.
  • Responsive Bilder.
  • Dateinamen.

6. Core Web Vitals: UX = Ranking

Die wichtigsten Metriken:

  • LCP < 2.5s.
  • INP < 200ms.
  • CLS < 0.1.

So verbessern Sie: Lazy Load, CDN.

7. Schema.org

Erhöhen Sie CTR mit Schema.

Pflicht für:

  • Product.
  • Article.
  • FAQPage.
  • LocalBusiness.
  • BreadcrumbList.

8. On-Page SEO Checkliste

  1. ✅ Title < 60 Zeichen
  2. ✅ Meta description < 160 Zeichen
  3. ✅ Ein H1
  4. ✅ H2/H3 Struktur
  5. ✅ Keyword im ersten Absatz
  6. ✅ Alt-Tags für Bilder
  7. ✅ Interne Links (3+)
  8. ✅ Canonical URL
  9. ✅ Open Graph
  10. ✅ Ladezeit < 3s
  11. ✅ Mobile friendly
  12. ✅ Schema.org

9. Häufige Fehler

  • Keyword im Title, nicht in H1.
  • Doppelte Titel.
  • Content nur für SEO.
  • Featured Snippets ignorieren.
  • Google Search Console ignorieren.
