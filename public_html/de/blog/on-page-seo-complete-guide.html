On-Page SEO: Vollständiger Leitfaden 2026 — So optimieren Sie jede Seite

On-Page SEO ist die Grundlage für allen Suchverkehr. In diesem Leitfaden finden Sie praktische Vorlagen und eine 15-minütige Checkliste.

Was ist On-Page SEO und warum ist es nicht nur "Titel ändern"

On-Page SEO ist eine Reihe von Optimierungen innerhalb der Seite selbst: Struktur, Inhalt, Meta-Tags, Bilder, Geschwindigkeit.

Laut Ahrefs konvertiert eine optimierte Seite 40% mehr Verkehr.

1. Titel und Meta-Beschreibung: Erste Klicks in SERP

Es ist das einzige, was Google nicht vollständig kontrolliert — aber Sie können es attraktiv machen.

Die ideale Titel-Formel:

Schlüsselwort | Marke

Beispiele:

  • Kaufe eine Matratze in NY - ab 150 $ | SleepWell
  • Schlüsselfertige Wohnungsrenovierung in London | BuildMaster
  • SEO für E-Commerce - 150% Wachstum | IndexFast
💡 SEO-Geheimnis

Platzieren Sie das Schlüsselwort in den ersten 60 Zeichen. Google kürzt den Titel nach 600px.

Meta-Beschreibung — Seitenflyer

160 Zeichen. Heben Sie Vorteile hervor, nicht Schlüsselwörter. Fügen Sie einen CTA hinzu: "bestellen", "herunterladen", "mehr erfahren".

2. H1-H6: Semantische Hierarchie für Menschen und Bots

Google verwendet Überschriften, um die Struktur des Inhalts zu verstehen. Regeln:

  • H1 — einmal pro Seite. Thema der Seite. Enthält das Hauptschlüsselwort.
  • H2 — Abschnitte. Unterüberschriften erster Ebene.
  • H3-H6 — Unterabschnitte. Überladen Sie nicht: 2-3 Ebenen sind ausreichend.
  • Überspringen Sie keine Ebenen: H1 → H2 → H3, nicht H1 → H4.

3. Inhaltsoptimierung: TF-IDF, LSI und nichts Überflüssiges

Im Jahr 2026 bewertet Google themenbezogene Vollständigkeit anstelle von Schlüsselwortdichte.

So überprüfen Sie:

  • Surfer SEO / NeuronWriter — vergleichen Sie die Top 10 Wettbewerber.
  • LSI-Schlüsselwörter — Synonyme und verwandte Begriffe.
  • TF-IDF — Termhäufigkeit. 1,5-2,5% sind ausreichend.

4. Interne Verlinkung: Kraft zwischen Seiten weitergeben

Interne Links helfen Google, die Architektur der Website zu verstehen.

  • Anchor = Kontext. Verwenden Sie anstelle von "hier" einen beschreibenden Anker.
  • Hypertext im ersten Absatz.
  • 3-5 interne Links pro Seite mit 1500+ Wörtern.
  • "Auch lesen"-Modul am Ende des Artikels.

5. Bilder: alt, WebP, Lazy Load

Bilder machen bis zu 60% des Seitengewichts aus. Optimierung:

  • Alt-Text — beschreiben Sie das Bild.
  • WebP/AVIF Format.
  • Lazy Loading.
  • Responsive Bilder.
  • Dateiname — beschreibende Namen.

6. Core Web Vitals: UX = Rang

Google hat bestätigt: Core Web Vitals ist ein Rankingfaktor.

  • LCP < 2,5s.
  • INP < 200ms.
  • CLS < 0,1.

So verbessern Sie: Lazy Load, minimieren Sie JS/CSS, verwenden Sie CDN.

7. Schema.org: Rich Snippets

Strukturierte Daten erhöhen die CTR um 15-30%.

Erforderlich für:

  • Produkt — Preis, Verfügbarkeit, Bewertung.
  • Artikel — für Blogbeiträge.
  • FAQPage — für FAQ-Bereiche.
  • LocalBusiness.
  • BreadcrumbList.

8. On-Page SEO Checkliste

  1. ✅ Titel < 60 Zeichen, enthält Schlüsselwort
  2. ✅ Meta-Beschreibung < 160 Zeichen
  3. ✅ Ein H1
  4. ✅ H2/H3 Struktur
  5. ✅ Die ersten 100 Wörter enthalten Schlüsselwort
  6. ✅ Alt-Tags für Bilder
  7. ✅ Interne Links (3+)
  8. ✅ Kanonische URL
  9. ✅ Open Graph-Tags
  10. ✅ Ladegeschwindigkeit < 3s
  11. ✅ Mobilfreundlich
  12. ✅ Schema.org Markup

9. Häufige Fehler, die den Rang zerstören

  • Schlüsselwort im Titel, aber nicht in H1.
  • Duplizierter Titel/Beschreibung.
  • Zu langer "SEO"-Inhalt. Schreiben Sie nützlichen Inhalt.
  • Featured Snippets ignorieren.
  • Google Search Console nicht überprüfen.
