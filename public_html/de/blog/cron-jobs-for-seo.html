Cron Jobs für SEO: Routine automatisieren

Cron ist ein Aufgabenplaner unter Linux.

Was sind Cron und Crontab?

Cron führt geplante Befehle aus. Crontab ist die Konfigurationsdatei.

Format:

* * * * * Befehl │ │ │ │ └── Wochentag │ │ │ └──── Monat │ │ └────── Tag des Monats │ └──────── Stunde └────────── Minute

Praktische Beispiele für SEO

Tägliche Indexierung mit IndexFast

Wenn Sie IndexFast nutzen:

# Täglich um 6:00 Uhr ausführen 0 6 * * * php /var/www/html/google_indexing.php >> /var/log/indexing.log 2>&1
💡 >> und 2>&1

Nutzen Sie Logs.

Sitemap aktualisieren

# Alle 6 Stunden aktualisieren 0 */6 * * * php /var/www/html/generate_sitemap.php

Wöchentliches SEO-Audit

# Jeden Sonntag fehlerhafte Links prüfen 0 3 * * 0 python3 /scripts/check_links.py >> /var/log/links_audit.log

Google anpingen

# Google alle 30 Minuten anpingen */30 * * * * curl -s "https://www.google.com/ping?sitemap=https://yoursite.com/sitemap.xml" > /dev/null

Wie man Crontab konfiguriert

  1. Verbinden Sie sich per SSH
  2. Editor öffnen: crontab -e
  3. Aufgaben hinzufügen
  4. Datei speichern
  5. Aufgaben prüfen: crontab -l

Wenn kein SSH vorhanden ist

Die meisten Hosting-Panels haben ein Interface.

⚠️ Wichtig: Absolute Pfade

Verwenden Sie absolute Pfade.
