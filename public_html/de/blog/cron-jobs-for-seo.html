Cron-Jobs für SEO: Automatisieren Sie die Routine

Cron ist ein Aufgabenplaner in Linux, der es ermöglicht, Skripte nach einem Zeitplan auszuführen. Für SEO bedeutet dies automatische Updates der Sitemap usw.

Was ist Cron und Crontab?

Cron ist ein Daemon, der geplante Befehle ausführt. Crontab ist die Konfigurationsdatei.

Jede Zeile in crontab hat das Format:

* * * * * Befehl │ │ │ │ └── Wochentag (0-7, wobei 0 und 7 = Sonntag) │ │ │ └──── Monat (1-12) │ │ └────── Tag des Monats (1-31) │ └──────── Stunde (0-23) └────────── Minute (0-59)

Praktische Beispiele für SEO

Tägliche Indizierung über IndexFast

Wenn Sie das IndexFast-PHP-Skript verwenden, um URLs über die Google Indexing API zu senden:

# Täglich um 6:00 Uhr ausführen 0 6 * * * php /var/www/html/google_indexing.php >> /var/log/indexing.log 2>&1
💡 >> und 2>&1

Das Symbol >> fügt die Ausgabe an die Protokolldatei an. 2>&1 leitet auch Fehler dorthin um.

Aktualisierung der Sitemap

# Sitemap alle 6 Stunden aktualisieren 0 */6 * * * php /var/www/html/generate_sitemap.php

Wöchentlicher SEO-Audit

# Jeden Sonntag um 3:00 — Überprüfung defekter Links 0 3 * * 0 python3 /scripts/check_links.py >> /var/log/links_audit.log

Google nach einem Update anpingen

# Google alle 30 Minuten über die Sitemap-Aktualisierung anpingen */30 * * * * curl -s "https://www.google.com/ping?sitemap=https://yoursite.com/sitemap.xml" > /dev/null

Wie man Crontab konfiguriert

  1. Verbinden Sie sich über SSH mit dem Server
  2. Öffnen Sie den Crontab-Editor: crontab -e
  3. Fügen Sie Zeilen mit Aufgaben hinzu (Format wie oben beschrieben)
  4. Speichern Sie die Datei (in nano: Ctrl+O, Enter, Ctrl+X)
  5. Überprüfen Sie, ob die Aufgabe hinzugefügt wurde: crontab -l

Wenn Sie keinen SSH-Zugang haben

Die meisten Hosting-Panels haben eine grafische Benutzeroberfläche für Cron-Jobs.

⚠️ Wichtig: Absolute Pfade

Geben Sie immer absolute Pfade zu ausführbaren Dateien in Cron an.

Cron für automatische Indizierung mit IndexFast

Das IndexFast-PHP-Skript eignet sich perfekt für Cron. Es:

  • liest URLs aus sitemap.xml
  • sendet sie über die Google Indexing API
  • protokolliert die Ergebnisse jeder Anfrage
  • stoppt, wenn das tägliche Kontingent (200 URLs) erreicht ist

Überwachung von Cron-Jobs

Standardmäßig sendet Cron die Ausgabe an die Root-E-Mail. Um E-Mails zu erhalten, fügen Sie hinzu:

MAILTO="[email protected]"

Oder sehen Sie sich das Systemprotokoll an: grep CRON /var/log/syslog
