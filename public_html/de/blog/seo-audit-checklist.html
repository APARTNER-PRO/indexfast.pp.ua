Website SEO Audit: Vollständige 50-Punkte-Checkliste 2026

Ein regelmäßiger SEO-Audit ist der einzige Weg, um Probleme zu erkennen, bevor sie den Verkehr erheblich beeinträchtigen. 50 spezifische Prüfpunkte: von robots.txt und Core Web Vitals bis hin zu E-E-A-T und der Qualität von Backlinks.

Was ist ein SEO-Audit und warum wird es benötigt

Ein SEO-Audit ist eine systematische Überprüfung einer Website auf die Einhaltung der Anforderungen von Suchmaschinen. Es deckt technische Fehler, Inhaltsprobleme und verpasste Chancen für das Ranking-Wachstum auf. Ein regelmäßiger Audit (einmal pro Quartal) ermöglicht es Ihnen, eine Degradierung zu bemerken, bevor sie den Verkehr erheblich beeinträchtigt.

Diese Checkliste besteht aus 50 Punkten, die nach Kategorien gruppiert sind. Gehen Sie sie der Reihe nach durch — jeder unkorrektierte Punkt ist ein Risiko für die Sichtbarkeit der Website in der Suche.

Technisches SEO (Punkte 1–15)

  • 1. HTTPS — die Website muss nur über https:// geöffnet werden. Überprüfen Sie Weiterleitungen von http://
  • 2. WWW/non-WWW — eine Version sollte auf die andere weiterleiten (301)
  • 3. robots.txt — Datei existiert, blockiert keine wichtigen Abschnitte, ohne Autorisierung verfügbar
  • 4. Sitemap.xml — existiert, aktuell, in der Search Console registriert
  • 5. Statuscodes — keine fehlerhaften 200s auf 404-Seiten (soft 404)
  • 6. Weiterleitungen — Weiterleitungsketten sind nicht länger als 2 Schritte
  • 7. Ladegeschwindigkeit — LCP unter 2,5s auf Mobilgeräten (PageSpeed)
  • 8. Core Web Vitals — FID/INP unter 200ms, CLS unter 0,1
  • 9. Mobile Version — die Website wird auf allen Bildschirmgrößen korrekt angezeigt
  • 10. Strukturierte Daten — Schema.org für die wichtigsten Seitentypen
  • 11. Hreflang — richtig konfiguriert, wenn mehrsprachiger Inhalt vorhanden ist
  • 12. Kanonische Tags — jede Seite verweist auf sich selbst oder die Hauptversion
  • 13. Paginierung — rel="next"/"prev" oder kanonisch zur ersten Seite
  • 14. Crawl-Fehler — überprüfen Sie die Search Console auf 4xx- und 5xx-Fehler
  • 15. Protokolldateien — Googlebot besucht regelmäßig wichtige Seiten
💡 Schnelle technische Überprüfung

Geben Sie die Website-Adresse auf pagespeed.web.dev ein — erhalten Sie sofort Core Web Vitals-Werte für mobile und Desktop-Versionen. Dies ist der erste Schritt eines jeden technischen Audits.

Indizierung (Punkte 16–22)

  • 16. Anzahl der indizierten Seiten — vergleichen Sie site: mit der tatsächlichen Anzahl der Seiten
  • 17. Noindex auf wichtigen Seiten — überprüfen Sie auf versehentliches noindex
  • 18. Search Console Coverage — überprüfen Sie die Kategorien "Fehler" und "Ausgeschlossen"
  • 19. Verwaiste Seiten — Seiten ohne interne Links im Crawl-Bericht
  • 20. Duplikate im Index — site: zeigt, ob es mehrere Versionen einer Seite gibt
  • 21. Sitemap vs Index — wie viele URLs aus der Sitemap tatsächlich indiziert sind
  • 22. Indexing API — ist die automatische Übermittlung neuer URLs konfiguriert
⚠ Kritischer Punkt: noindex-Leck

Der teuerste Fehler im SEO ist, wenn noindex aus der Testumgebung in die Produktion gelangt. Überprüfen Sie dies zuerst nach jedem Deployment. Die Search Console zeigt einen drastischen Rückgang der indizierten Seiten.

On-Page SEO (Punkte 23–35)

  • 23. Title-Tags — einzigartig, enthalten Schlüsselwort, 50–60 Zeichen
  • 24. Meta-Beschreibung — einzigartig, 120–155 Zeichen, enthält einen CTA
  • 25. H1 — eine H1 pro Seite, enthält Schlüsselwort
  • 26. Überschriftenstruktur — logische Hierarchie H1 → H2 → H3
  • 27. Schlüsselwörter im Inhalt — natürliche Verwendung, ohne Keyword-Stuffing
  • 28. Inhaltslänge — mindestens 300 Wörter, für wettbewerbsfähige Anfragen 1000+
  • 29. Inhalts-Einzigartigkeit — keine Duplikate mit anderen Seiten der Website
  • 30. Bilder — alt-Tags ausgefüllt, Dateien optimiert (WebP)
  • 31. Interne Verlinkung — wichtige Seiten haben Links von anderen Seiten
  • 32. Ankertext — beschreibend, nicht "hier klicken" oder "weiterlesen"
  • 33. URL-Struktur — kurz, klar, enthält Schlüsselwort
  • 34. Breadcrumbs — Breadcrumb-Navigation mit Schema.org
  • 35. Veralteter Inhalt — Artikel älter als 2 Jahre müssen aktualisiert werden

Inhalt und E-E-A-T (Punkte 36–42)

  • 36. Inhaltsautor — Autor mit Biografie und sozialen Links angegeben
  • 37. Veröffentlichungs- und Aktualisierungsdatum — auf der Seite sichtbar
  • 38. Quellen und Referenzen — Links zu autoritativen Quellen, wo es angebracht ist
  • 39. Über- und Kontaktseiten — detaillierte Unternehmensinformationen
  • 40. Datenschutzrichtlinie und Bedingungen — aktuelle Dokumente
  • 41. Bewertungen und soziale Beweise — echte Bewertungen auf der Website
  • 42. Dünner Inhalt — Seiten mit weniger als 300 Wörtern ohne echten Wert

Nach dem Audit — Reindexierung beschleunigen

Nach der Behebung von Fehlern, starten Sie die Reindexierung über IndexFast. Google wird aktualisierte Seiten in wenigen Stunden sehen, nicht in Wochen.

Externe Links (Punkte 43–47)

  • 43. Anzahl der Backlinks — überprüfen Sie über Ahrefs oder Google Search Console
  • 44. Qualität der Spender — Links von autoritativen thematischen Websites
  • 45. Toxische Links — Spam-Links von minderwertigen Websites
  • 46. Ankertextprofil — vielfältige Anker, kein exaktes Match-Stuffing
  • 47. Defekte Backlinks — Links zu gelöschten oder geänderten Seiten Ihrer Website

Analytik und Überwachung (Punkte 48–50)

  • 48. Google Analytics 4 — installiert, verfolgt Konversionen korrekt
  • 49. Search Console — Website verifiziert, Sitemap hinzugefügt, keine Fehlermeldungen
  • 50. Regelmäßige Überwachung — wöchentliche Überprüfung der wichtigsten Kennzahlen: Verkehr, Rankings, Indizierung

Priorisierung von Korrekturen

Versuchen Sie nicht, alles auf einmal zu beheben. Priorisieren Sie die Aufgaben:

  • Kritisch (diese Woche) — noindex auf wichtigen Seiten, robots.txt-Blockierungen, massenhaft 5xx-Fehler
  • Wichtig (diesen Monat) — Website-Geschwindigkeit, Inhaltsduplikate, fehlende kanonische Tags
  • Wünschenswert (nächstes Quartal) — Aktualisierung von veraltetem Inhalt, Linkaufbau, Schema.org
