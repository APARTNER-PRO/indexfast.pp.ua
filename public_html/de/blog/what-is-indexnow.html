Was ist IndexNow und wie richtet man es ein

IndexNow verändert die Indizierungsgeschwindigkeit.

Was ist IndexNow?

IndexNow ist ein Ping-Protokoll von Microsoft und Yandex.

Senden Sie Daten sofort an Suchmaschinen.

💡 Nutzt Google IndexNow?

Nein. Google nutzt die Google Indexing API.

Wie IndexNow funktioniert

Ihr Server sendet eine HTTP-Anfrage.

Ein einfacher Ping sieht so aus:

POST https://api.indexnow.org/indexnow Content-Type: application/json { "host": "your-website.com", "key": "your-api-key", "urlList": [ "https://your-website.com/new-page", "https://your-website.com/updated-page" ] }

Problem: Die manuelle Einrichtung ist schwer

Die Einrichtung ist sehr technisch.

  1. Erstellen Sie einen API-Schlüssel.
  2. Erstellen Sie eine .txt Datei.
  3. Konfigurieren Sie Ihren Server.
  4. Behandeln Sie Fehler.
⚠️ Häufiger Fehler

Ping-Anfragen bei Updates nicht vergessen.

Lösung: Automatisiert mit IndexFast

IndexFast automatisiert den gesamten Prozess.

Das automatisiert IndexFast:

  • Automatische API-Keys.
  • Sitemap-Monitoring.
  • Pings an alle Suchmaschinen.
  • Automatische Wiederholungen.
🚀 Ergebnis

Seiten werden in 2-24 Stunden indiziert.

Wer unterstützt IndexNow?

Diese Suchmaschinen unterstützen es:

  • Bing (Microsoft).
  • Yandex.
  • Seznam.cz.
  • Naver.
  • DuckDuckGo.

Suchmaschinen reduzieren ihr Crawl-Budget.
