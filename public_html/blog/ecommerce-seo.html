E-commerce SEO: Indexing Products and Categories in 2026

Thousands of products, filters generating thousands of duplicate URLs, new arrivals not in search for months — e-commerce has its unique SEO challenges. We analyze each and provide specific solutions.

Why Stores Have Special Indexing Problems

Online stores are some of the most complex sites for SEO. Thousands of product pages, categories with filters, pagination, color and size variants — all this creates unique challenges.

The main problem: crawl budget. Googlebot doesn't have time to crawl all pages, so some products may never appear in search. Statistically, an average online store generates 5–10 times more URLs than Google actually needs.

Product Pages: Common Mistakes

  • Duplicate manufacturer descriptions — if you copy text, it's already on dozens of sites. Google will choose the original, not you.
  • Out of stock items returning 200 code — "Out of stock" on a live page instead of 404/410 wastes crawl budget.
  • Variants without canonical — blue and red version of a product on different URLs without a canonical tag — duplicates.
  • Filter parameters — /category?color=red&size=M generates thousands of duplicate URLs.
💡 Solution for Product Variants

Set a canonical tag on all variants pointing to the main page. Or combine variants on one page with a JavaScript switcher — better UX and better SEO at the same time.

Categories and Filters

Category pages have the best chances of getting to the top of Google — they receive the most internal links. But there are traps:

  • Empty categories (0 products) — close via noindex or delete.
  • Categories with 1–2 products — combine or add a text description of at least 200 words.
  • Pagination — /category/page/2 must be crawlable, but without duplicate title and description.
⚠ Filters — The Main Enemy of Crawl Budget

If a category has 10 filters with 5 values each — that's 50 combinations and potentially thousands of URLs. Close them via robots.txt or set canonical to the parent category. Leave open only combinations with real search demand.

Schema.org Product — Mandatory

Structured data helps Google show your products with rating, price and availability right in search — CTR increases by 20–35%:

{ "@context": "https://schema.org", "@type": "Product", "name": "Product Name", "offers": { "@type": "Offer", "price": "1999", "priceCurrency": "UAH", "availability": "https://schema.org/InStock" }, "aggregateRating": { "@type": "AggregateRating", "ratingValue": "4.8", "reviewCount": "124" } }

Sitemap for a Large Store

Divide the sitemap into files by page type — this helps Google understand priorities:

  • sitemap-products.xml — products with description and availability, priority 0.8
  • sitemap-categories.xml — active categories, priority 0.9
  • sitemap-pages.xml — static pages, priority 0.6
  • sitemap-blog.xml — blog articles, priority 0.7

Fast Indexing of New Products

Without API, a new product can wait for indexing from 2 weeks to 3 months. For a store where competitors are already selling an analog — this is critical.

Google Indexing API solves the problem: after publishing a product, send the URL via API — Googlebot will visit the page within a few hours. Especially important for:

  • Seasonal items and promotions (price valid for a week only)
  • Products back in stock
  • Price updates before sales
  • New collections and arrivals

Deleted Products: What to Do

  • Product temporarily out of stock → leave the page, mark OutOfStock in Schema.org
  • Permanently deleted, has analog → 301 redirect to a similar product or category
  • Permanently deleted, no analog → 410 Gone code (better than 404)

E-commerce SEO Checklist

  • Unique descriptions for all products (minimum 150 words, ideally 300+)
  • Canonical tags on variants and parametric URLs
  • Noindex for empty categories and irrelevant filters
  • Schema.org Product for all product pages
  • Segmented sitemap by types with correct priorities
  • 301 redirects or 410 for deleted products
  • Google Indexing API for new and updated products
