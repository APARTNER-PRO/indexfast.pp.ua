Core Web Vitals: O que você precisa saber

Core Web Vitals são três métricas do Google que medem a experiência real do usuário em um site. Desde 2021, elas são um fator oficial de classificação. Em 2024, o INP substituiu o FID. Vamos analisar cada métrica e como melhorá-la.

O que são Core Web Vitals

Core Web Vitals (CWV) é um subconjunto de sinais de Experiência de Página usados pelo Google para classificação. Ao contrário dos testes de laboratório do Lighthouse, os CWV são medidos em usuários reais através do Chrome User Experience Report (CrUX).

📌 Bom vs Ruim

Para cada métrica: verde = bom, amarelo = precisa de melhoria, vermelho = ruim. O Google visa o percentil 75.

LCP — Largest Contentful Paint

LCP mede o tempo até que o maior elemento visível na página seja exibido — geralmente uma imagem principal ou H1.

ValorAvaliação
≤ 2.5 segundos✅ Bom
2.5 – 4.0 segundos⚠️ Precisa de melhoria
> 4.0 segundos❌ Ruim

Como melhorar o LCP

  • Otimize imagens — converta para WebP ou AVIF, adicione loading="eager" para imagens principais.
  • Pré-carregue o elemento LCP — adicione <link rel="preload" as="image">.
  • Use CDN — reduz o TTFB.
  • Remova recursos bloqueadores — mova JS e CSS não críticos para defer/async.
  • Renderização do lado do servidor — SSR melhora drasticamente o LCP para SPA.

CLS — Cumulative Layout Shift

CLS mede o deslocamento cumulativo dos elementos da página durante o carregamento.

ValorAvaliação
≤ 0.1✅ Bom
0.1 – 0.25⚠️ Precisa de melhoria
> 0.25❌ Ruim

Como melhorar o CLS

  • Especifique tamanhos de imagens — sempre adicione width e height.
  • Reserve espaço para anúncios — defina tamanhos fixos para blocos de anúncios.
  • Não insira conteúdo acima do existente — banners e avisos de cookies devem estar na parte inferior.
  • Pré-carregue fontes — FOUT causa deslocamentos.

INP — Interaction to Next Paint

INP substituiu o FID em março de 2024. Mede o atraso entre a interação do usuário e a atualização da tela.

Ao contrário do FID, o INP rastreia todas as interações e pega o pior valor.

ValorAvaliação
≤ 200 ms✅ Bom
200 – 500 ms⚠️ Precisa de melhoria
> 500 ms❌ Ruim

Como melhorar o INP

  • Divida tarefas longas — qualquer JS > 50ms bloqueia o navegador.
  • Reduza o tamanho do pacote JS — divisão de código e tree shaking.
  • Evite operações síncronas em manipuladores de eventos.
  • Verifique scripts de terceiros — chatbots e análises frequentemente causam um INP ruim.
⚠️ INP e CWV

INP é a métrica mais difícil de otimizar.

Como medir os Core Web Vitals

Dados de Campo

  • Google Search Console → "Experiência da Página".
  • PageSpeed Insights — combina Dados de Campo e Dados de Laboratório.
  • CrUX Dashboard no Looker Studio.

Dados de Laboratório

  • Lighthouse no Chrome DevTools.
  • WebPageTest — testes detalhados de waterfall.
💡 Dados de Campo são mais importantes que Dados de Laboratório

O Google classifica com base em Dados de Campo (usuários reais), não no Lighthouse.

Impacto dos CWV no SEO

O Google confirmou: CWV é um fator de classificação, mas o conteúdo ainda é mais importante.

Na prática: se seu site está na zona verde, os CWV não impedirão o crescimento.

Quer que as páginas corrigidas sejam indexadas mais rápido?

Após melhorias técnicas, é importante que o Google reindexe as páginas rapidamente.
