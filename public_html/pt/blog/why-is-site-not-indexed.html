Por que meu site não está indexado no Google — 12 razões e como corrigi-las

Você lançou seu site, esperou algumas semanas — e nada no Google. Ou algumas páginas aparecem na busca, enquanto outras parecem não existir. Abordamos as 12 razões mais comuns pelas quais o Google ignora um site ou páginas individuais — e o que exatamente fazer em cada caso.

Primeiro: Verifique se há um problema

Antes de procurar a causa, certifique-se de que o problema realmente existe. Digite no Google:

site:seusite.com

Se não houver resultados ou significativamente menos do que o número de páginas no site — continue lendo.

Abra também o Google Search Console → Indexação → Páginas. Lá, o Google explica por que cada página não está indexada.

12 Razões e Soluções

Razão 01

Tag noindex na página

A razão mais comum para a "invisibilidade" no Google. O código da página contém uma tag que proíbe diretamente a indexação:

<meta name="robots" content="noindex">

Essa tag pode ter aparecido por engano durante o desenvolvimento, ou se o CMS define automaticamente noindex para certos tipos de páginas (tags, categorias, páginas de busca).

✓ Solução

Verifique o código de cada página (Ctrl+U no navegador, procure por "noindex"). No WordPress — verifique Yoast SEO ou RankMath, configurações de visibilidade para cada tipo de post.

Razão 02

Bloqueado no robots.txt

O arquivo robots.txt pode bloquear o Googlebot de rastrear seções inteiras do site. Abra seusite.com/robots.txt e procure linhas como:

Disallow: / Disallow: /blog/
✓ Solução

Se a linha Disallow: / — isso bloqueia todo o site. Exclua ou substitua por Disallow: (valor vazio — permite tudo). Verifique através da ferramenta de teste do robots.txt no Search Console.

Razão 03

Site protegido por senha ou em manutenção

Se o site requer autorização ou retorna um código 503 — o Googlebot não pode acessar o conteúdo. Isso é típico para novos sites lançados "silenciosamente".

✓ Solução

Certifique-se de que o site é acessível sem autorização. Verifique através do Google Search Console → Inspeção de URL → "Testar URL ao vivo".

Razão 04

Baixo orçamento de rastreamento — Googlebot não consegue acompanhar

O Google aloca um certo "orçamento de rastreamento" para cada site — o número de páginas que ele está pronto para rastrear em um determinado tempo. Para sites novos e pequenos, esse orçamento é mínimo.

Se o site tem milhares de páginas ou muda com frequência — o Googlebot simplesmente não consegue rastrear todas as URLs.

✓ Solução

Use a API de Indexação do Google para páginas prioritárias. Remova URLs "lixo" do sitemap (tags com 1 artigo, categorias vazias, consultas de busca). Verifique a velocidade do site — um site lento recebe um orçamento de rastreamento menor.

Razão 05

Conteúdo duplicado e canonical

Se várias URLs têm o mesmo ou conteúdo muito semelhante, o Google escolhe uma URL "canônica" e pode ignorar as outras. Problemas comuns:

  • Versões HTTP e HTTPS do site sem redirecionamento
  • versões www e não-www
  • Páginas com e sem barra final: /pagina e /pagina/
  • Parâmetros de URL: /pagina?utm_source=... em vez de /pagina
✓ Solução

Defina a tag canônica em todas as páginas apontando para a versão "primária". Configure redirecionamentos 301. No Search Console, verifique o relatório "Descoberto — atualmente não indexado" — ele frequentemente contém informações sobre duplicatas.

Razão 06

Conteúdo raso ou de baixa qualidade

O Google pode se recusar a indexar páginas com pouco texto único. Em risco:

  • Páginas com menos de 300–500 palavras
  • Conteúdo gerado automaticamente
  • Páginas de modelo com conteúdo único mínimo (tags, meses)
  • Conteúdo copiado de outros sites
✓ Solução

Ou melhore significativamente o conteúdo, ou feche essas páginas com a tag noindex. É melhor ter 50 páginas indexadas de qualidade do que 500 "invisíveis".

Razão 07

Erros de servidor — códigos 4xx e 5xx

Se o Googlebot recebe erros ao solicitar páginas — ele para de visitá-las e as remove do índice. Códigos 404 (não encontrado), 500 (erro de servidor), 503 (serviço indisponível) — tudo isso reduz a atividade de rastreamento.

✓ Solução

Search Console → Indexação → Páginas → "Não encontrado (404)" e "Erro de servidor (5xx)". Corrija ou configure redirecionamentos 301 para páginas excluídas. Verifique os logs do servidor em busca de erros em massa.

Razão 08

Velocidade de carregamento lenta

O Google considera os Core Web Vitals ao classificar e ao determinar o orçamento de rastreamento. Um site muito lento (LCP > 4 segundos) recebe um orçamento de rastreamento menor.

✓ Solução

Verifique através do PageSpeed Insights (pagespeed.web.dev). Métricas-chave: LCP (Largest Contentful Paint) abaixo de 2,5s, FID abaixo de 100ms, CLS abaixo de 0,1. Otimize imagens, ative o cache, conecte um CDN.

Razão 09

Sem links para a página

O Googlebot encontra novas páginas principalmente através de links. Se não houver links internos ou externos para uma página — ela pode permanecer "invisível" mesmo que esteja no sitemap.

✓ Solução

Adicione links internos de outras páginas populares. Certifique-se de que novos artigos apareçam nas seções "Leia também", "Novas publicações", etc. Ou use a API de Indexação para notificar diretamente o Google.

Razão 10

Renderização JavaScript bloqueia conteúdo

Se seu site é construído em React, Vue ou Angular e o conteúdo é renderizado apenas no lado do cliente — o Googlebot pode não ver o texto das páginas. Ele "vê" apenas uma estrutura HTML vazia.

✓ Solução

Configure a Renderização do Lado do Servidor (SSR) ou Geração de Site Estático (SSG). Verifique através do Search Console → Inspeção de URL → "Ver Página Rastreadas" — isso mostra exatamente o que o Googlebot vê.

Razão 11

Domínio jovem — apenas precisa de tempo

Para domínios novos (menos de 6 meses), o Google geralmente adiciona páginas ao índice mais lentamente. Isso é normal — os algoritmos verificam a confiabilidade de novos recursos.

✓ Solução

Obtenha alguns links externos de qualidade (de sites autoritários em seu nicho). Publique regularmente conteúdo de qualidade. Use a API de Indexação para acelerar as coisas. Registre o site no Search Console e adicione um sitemap.

Razão 12

Filtro ou penalidade do Google

Em casos raros, um site pode receber uma penalidade manual da equipe do Google (por manipulação de links, conteúdo spam, cloaking, etc.) ou uma penalidade algorítmica automática.

✓ Solução

Verifique o Search Console → Segurança e Ações Manuais → Ações Manuais. Se houver uma penalidade — corrija as violações e envie um pedido de revisão. Para filtros algorítmicos — melhore a qualidade do conteúdo e o perfil de links.

Plano de Ação Passo a Passo

Se seu site não está indexado — aja nesta ordem:

  1. Verifique o robots.txt — certifique-se de que não há bloqueios
  2. Verifique a tag noindex nas páginas problemáticas
  3. Abra o Search Console → Páginas → leia os motivos da exclusão
  4. Verifique a acessibilidade do site e os códigos de resposta do servidor
  5. Verifique a velocidade através do PageSpeed Insights
  6. Elimine os problemas encontrados
  7. Envie URLs através da API de Indexação do Google para acelerar a indexação
