Como Verificar a Indexação do Site no Google — 7 Métodos em 2026

"Por que meu site não aparece no Google?" — uma das perguntas mais comuns dos proprietários de sites. O primeiro passo para encontrar a resposta é descobrir se o Google vê suas páginas. Abordamos 7 maneiras de verificar a indexação: desde uma busca simples até uma auditoria detalhada no Search Console.

O que significa "página indexada"?

A indexação é o processo pelo qual o Googlebot encontra sua página, analisa seu conteúdo e a adiciona ao seu banco de dados (índice). Apenas páginas indexadas podem aparecer nos resultados de busca.

É importante distinguir entre dois conceitos: rastreamento (o Googlebot visitou a página) e indexação (a página foi adicionada ao índice e pode aparecer na busca). Uma página pode ser rastreada, mas não indexada — por exemplo, devido à baixa qualidade do conteúdo ou problemas técnicos.

1. O operador site: no Google

Método 01 · Grátis · 30 segundos

O operador de busca site:

Abra o Google e digite na barra de busca:

site:yoursite.com

O Google mostrará todas as páginas indexadas do seu domínio. O número na linha "Aproximadamente X resultados" é o número aproximado de páginas indexadas.

💡 Variantes úteis do operador

site:yoursite.com/blog/ — apenas páginas na seção /blog/
site:yoursite.com -inurl:tag — sem páginas de tags
"palavra-chave" site:yoursite.com — se uma página específica está no índice

⚠ Limitações do método

Os resultados do operador site: são aproximados e podem diferir da contagem real em 20–30%. Para dados precisos, use o Google Search Console.

2. Inspeção de URL no Search Console

Método 02 · Grátis · Mais preciso

Ferramenta de Inspeção de URL

Google Search Console → insira a URL na barra de busca superior → pressione Enter.

Você verá um dos três status:

  • URL está no Google — a página está indexada, tudo certo
  • URL não está no Google — a página não está indexada, há uma razão
  • URL está no Google, mas tem problemas — indexada com limitações

Se o status for "URL não está no Google", expanda os detalhes — haverá uma razão específica: Descoberta — atualmente não indexada, Duplicada sem tag canônica, Bloqueada por robots.txt, etc.

🚀 Solicitar indexação

Diretamente na ferramenta de inspeção de URL, clique em "Solicitar indexação" — o Google colocará a página na fila para rastreamento fora do cronograma. Mas esse método não funciona instantaneamente e tem limites diários.

3. Relatório de Cobertura no Search Console

Método 03 · Auditoria sistemática

Visão completa da indexação do site

Search Console → Indexação → Páginas (ou "Cobertura" na interface antiga).

O relatório divide todas as URLs do site em quatro categorias:

  • Erro — páginas não indexadas devido a problemas críticos (404, 500, bloqueadas)
  • Válido com aviso — indexado, mas há problemas potenciais
  • Válido — tudo certo, páginas estão no índice
  • Excluído — intencionalmente ou automaticamente excluído do índice (noindex, duplicatas, etc.)

Clique em cada categoria para ver URLs específicas e as razões para os problemas.

4. Verificação de cache do Google

Método 04 · Rápido

O operador cache: para verificação de cache

Digite no Google: cache:yoursite.com/page

Se o Google salvou o cache da página — ela foi definitivamente indexada. O cache também mostra a data da última varredura — útil para entender quão atual é a informação no Google.

⚠ Importante

O Google está gradualmente limitando o operador cache:. Em algumas regiões, ele já não funciona. Se não funcionar — use o Search Console.

5. Busca pelo título exato

Método 05 · Verificar uma página específica

Busca usando intitle:

Digite no Google: intitle:"Título exato da sua página"

Se sua página aparecer nos resultados — ela está indexada. Além disso, verifica se há duplicatas com o mesmo título em outros sites.

6. Auditoria do sitemap no Search Console

Método 06 · Verificação em massa

Comparando sitemap e índice

Search Console → Indexação → Sitemaps → selecione seu sitemap.

O Search Console mostra dois números: número de URLs no sitemap e número de URLs indexadas. Se o segundo número for significativamente menor — há problemas.

Por exemplo: o sitemap contém 500 URLs, mas apenas 120 estão indexadas — 380 páginas o Google não quis indexar. As razões podem ser: baixa qualidade do conteúdo, duplicatas, carregamento lento, bloqueio no robots.txt.

7. Ferramentas de SEO de terceiros

Método 07 · Análise avançada

Ahrefs, Semrush, Screaming Frog

Para auditorias detalhadas de grandes sites, ferramentas de terceiros fornecem mais detalhes.

  • Ahrefs Site Audit — escaneia o site e mostra quais páginas não estão indexadas e por quê
  • Screaming Frog SEO Spider — grátis até 500 URLs, auditoria técnica detalhada
  • Semrush Site Audit — verifica a indexação e problemas técnicos

Por que as páginas não estão indexadas

Se você descobrir que as páginas não estão indexadas, aqui estão as razões mais comuns:

  • tag noindex — o código da página contém <meta name="robots" content="noindex">
  • Bloqueado no robots.txt — uma regra Disallow bloqueia o Googlebot
  • Baixo orçamento de rastreamento — o Google não consegue rastrear todas as páginas do site
  • Baixa qualidade do conteúdo — duplicatas, conteúdo raso, páginas geradas automaticamente
  • Problemas no servidor — códigos de erro 4xx, 5xx quando o Googlebot faz solicitações
  • Faltando ou incorreto canônico — o Google escolhe outra página como a principal
  • Páginas novas — simplesmente ainda não estão na fila (pode levar de alguns dias a meses)

Conclusão: qual método escolher?

Para uma verificação rápida de uma página específica — o operador site: ou a ferramenta de inspeção de URL no Search Console.

Para uma auditoria sistemática de todo o site — o relatório "Cobertura" e a auditoria do sitemap no Search Console.

Para resolver problemas com a indexação — Google Indexing API via IndexFast. Em vez de esperar meses para o Googlebot encontrar suas páginas, você envia URLs diretamente e obtém indexação em poucas horas.
