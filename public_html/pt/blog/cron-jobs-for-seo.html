Cron Jobs para SEO: Automatizar a Rotina

Cron é um agendador de tarefas no Linux.

O que é Cron e Crontab?

Cron executa comandos. Crontab é a configuração.

Formato:

* * * * * comando │ │ │ │ └── dia da semana │ │ │ └──── mês │ │ └────── dia do mês │ └──────── hora └────────── minuto

Exemplos Práticos para SEO

Indexação Diária com IndexFast

Se usar o script PHP do IndexFast:

# Executar diariamente às 6:00 0 6 * * * php /var/www/html/google_indexing.php >> /var/log/indexing.log 2>&1
💡 >> e 2>&1

Use para logs.

Atualizar sitemap

# Atualizar a cada 6 horas 0 */6 * * * php /var/www/html/generate_sitemap.php

Auditoria SEO semanal

# Todo domingo às 3:00 0 3 * * 0 python3 /scripts/check_links.py >> /var/log/links_audit.log

Fazer ping no Google

# Fazer ping a cada 30 min */30 * * * * curl -s "https://www.google.com/ping?sitemap=https://yoursite.com/sitemap.xml" > /dev/null

Como configurar o crontab

  1. Conecte via SSH
  2. Abra o editor: crontab -e
  3. Adicione tarefas
  4. Salve o arquivo
  5. Verifique: crontab -l

Sem acesso SSH?

Painéis como cPanel têm interface para isso.
