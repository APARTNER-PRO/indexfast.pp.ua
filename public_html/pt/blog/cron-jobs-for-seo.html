Cron Jobs para SEO: Automatizando a Rotina

Cron é um agendador de tarefas no Linux que permite executar scripts em um cronograma. Para SEO, isso significa atualizações automáticas do sitemap, etc.

O que é Cron e Crontab?

Cron é um daemon que executa comandos agendados. Crontab é o arquivo de configuração.

Cada linha no crontab tem o formato:

* * * * * comando │ │ │ │ └── dia da semana (0-7, 0 e 7 = domingo) │ │ │ └──── mês (1-12) │ │ └────── dia do mês (1-31) │ └──────── hora (0-23) └────────── minuto (0-59)

Exemplos Práticos para SEO

Indexação Diária via IndexFast

Se você usar o script PHP do IndexFast para enviar URLs via Google Indexing API:

# Executar diariamente às 6:00 AM 0 6 * * * php /var/www/html/google_indexing.php >> /var/log/indexing.log 2>&1
💡 >> e 2>&1

O símbolo >> anexa a saída ao arquivo de log. 2>&1 redireciona erros para lá também.

Atualizando o Sitemap

# Atualizar sitemap a cada 6 horas 0 */6 * * * php /var/www/html/generate_sitemap.php

Auditoria Semanal de SEO

# Todo domingo às 3:00 — verificar links quebrados 0 3 * * 0 python3 /scripts/check_links.py >> /var/log/links_audit.log

Pinging Google após uma atualização

# Pingar o Google a cada 30 minutos sobre a atualização do sitemap */30 * * * * curl -s "https://www.google.com/ping?sitemap=https://yoursite.com/sitemap.xml" > /dev/null

Como Configurar o Crontab

  1. Conecte-se ao servidor via SSH
  2. Abra o editor do crontab: crontab -e
  3. Adicione linhas com tarefas (formato descrito acima)
  4. Salve o arquivo (no nano: Ctrl+O, Enter, Ctrl+X)
  5. Verifique se a tarefa foi adicionada: crontab -l

Se você não tiver acesso SSH

A maioria dos painéis de hospedagem tem uma interface gráfica para cron jobs.

⚠️ Importante: Caminhos Absolutos

Monitorando Cron Jobs

Por padrão, o cron envia a saída para o e-mail root. Para receber e-mails, adicione:

MAILTO="[email protected]"

Ou visualize o log do sistema: grep CRON /var/log/syslog
