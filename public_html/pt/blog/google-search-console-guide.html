Google Search Console: Guia Completo 2026

O Google Search Console é uma ferramenta gratuita do Google que mostra como seu site aparece na pesquisa. Neste guia — desde o registro até recursos avançados de indexação.

O que é o Google Search Console e por que você precisa dele

O Google Search Console (GSC) é uma interface web gratuita do Google que permite aos proprietários de sites monitorar a presença na pesquisa, detectar problemas de indexação e melhorar a visibilidade no Google.

Diferente do Google Analytics, que mostra o que os usuários fazem no site, o GSC mostra o que acontece antes da visita.

💡 Principal vantagem do GSC

É a única ferramenta que mostra consultas de pesquisa reais, posições no Google e problemas vistos pelo Google.

Como configurar o Google Search Console

Passo 1. Adicionar Propriedade

  1. Vá para search.google.com/search-console e faça login com sua conta do Google.
  2. Clique em "Adicionar Propriedade" no canto superior esquerdo.
  3. Escolha o tipo de propriedade: "Domínio" (recomendado) ou "Prefixo de URL".
  4. Insira o endereço do site sem www e protocolo (para o tipo Domínio) ou URL completo.
⚠️ Domínio vs Prefixo de URL

O tipo Domínio cobre todos os protocolos (http/https) e subdomínios simultaneamente. Para novos recursos, sempre escolha Domínio.

Passo 2. Verificar Propriedade

O GSC oferece vários métodos de verificação:

MétodoDificuldadeQuando usar
Registro TXT DNSMédiaMais confiável, recomendado para o tipo Domínio
Arquivo HTMLFácilSe você tiver acesso ao FTP/arquivos do site
Meta tagFácilSe você tiver acesso ao código da página
Google AnalyticsMuito fácilSe o GA já estiver instalado
Google Tag ManagerMuito fácilSe o GTM já estiver configurado

Relatórios principais do GSC

Desempenho

O relatório mais importante. Ele mostra:

  • Cliques — quantas vezes os usuários clicaram no site a partir da pesquisa.
  • Impressões — quantas vezes o site apareceu nos resultados.
  • CTR — a relação de cliques para impressões.
  • Posição — posição média no Google para o período selecionado.

Filtre por consultas, páginas, dispositivos e países para encontrar pontos de crescimento.

Cobertura / Indexação

Mostra o status de indexação de todas as páginas do site. Quatro categorias:

  • ✅ Válidas — páginas indexadas pelo Google
  • ⚠️ Válidas com avisos — indexadas, mas com problemas
  • ❌ Erros — páginas não indexadas devido a erros
  • ℹ️ Excluídas — intencionalmente excluídas (noindex, duplicatas, etc.)
🔍 Erros de indexação mais comuns

"Descoberta - atualmente não indexada" — o Google sabe sobre a página, mas não a considera importante o suficiente. Solução: melhorar o conteúdo, adicionar links internos ou usar o IndexFast.

Sitemaps

Seção para adicionar e monitorar sitemap.xml. Uma discrepância significativa entre URLs descobertas e indexadas é um sinal de problemas.

Inspeção de URL

A ferramenta mais útil para trabalhar com páginas individuais. Ela permite:

  • Ver como o Google vê uma página específica
  • Verificar se a página está indexada
  • Solicitar indexação manualmente (o botão "Solicitar Indexação")
  • Visualizar renderização — como o HTML aparece após a execução do JS

Usando o GSC para acelerar a indexação

A solicitação de indexação manual via "Inspeção de URL" é o método padrão, mas tem limites.

Para indexação sistemática de centenas de páginas, você precisa da API de Indexação do Google.

Dicas Práticas

Monitore os Core Web Vitals

A seção "Experiência da Página" mostra CWV com base em dados reais de usuários.

Configure notificações

O GSC envia um e-mail quando problemas críticos são detectados. Certifique-se de que as notificações estão ativadas.

Compare períodos

No relatório "Desempenho", use o recurso de comparação de datas.

Veja o mobile separadamente

Filtre relatórios por dispositivo. Classificações móveis ruins sinalizam problemas com a versão móvel.
