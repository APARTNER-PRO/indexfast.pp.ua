Indexação do Site WordPress: Configurações do Yoast SEO e Erros Comuns em 2026

WordPress é o CMS mais popular, mas suas configurações padrão não são otimizadas para SEO. Milhares de páginas de anexo, tags que duplicam conteúdo, arquivos de autor — tudo isso prejudica a indexação. Vamos descobrir como corrigir isso em 30 minutos.

Por que os Sites WordPress Frequentemente Têm Problemas de Indexação

WordPress é o CMS mais popular do mundo, mas suas configurações padrão não são otimizadas para SEO. Centenas de milhares de sites WordPress têm os mesmos erros comuns: páginas de tags duplicam conteúdo, arquivos de autor exibem os mesmos artigos, a paginação não está configurada.

A boa notícia: a maioria dos problemas é resolvida em 15–30 minutos através dos plugins Yoast SEO ou RankMath.

Yoast SEO: Configurações Básicas para Indexação

Yoast SEO → Aparência de Pesquisa → Tipos de Conteúdo:

  • Posts — index: Sim, Mostrar nos resultados: Sim
  • Páginas — index: Sim
  • Mídia (Anexos) — index: Não (deve ser desativado)
  • Tags — index: Não se houver menos de 5 posts por tag
  • Arquivos de Autor — index: Não se houver apenas um autor
⚠ Páginas de Mídia — O Duplicador Oculto

Por padrão, o WordPress cria uma página separada para cada imagem carregada (página de anexo). Essas páginas têm conteúdo quase vazio e desperdiçam seriamente o orçamento de rastreamento. Desative-as em Yoast SEO → Aparência de Pesquisa → Mídia → desativar páginas de anexo.

Tags e Categorias

As tags do WordPress são uma das maiores armadilhas de SEO. Cada tag cria uma página de arquivo separada que exibe os mesmos artigos que a categoria. O resultado: duplicação de conteúdo e diluição do orçamento de rastreamento.

  • Se uma tag for usada em menos de 5 artigos → noindex ou exclua-a
  • Se a categoria e a tag exibirem o mesmo conteúdo → exclua as tags completamente
  • Para tags ativas: adicione uma descrição única via Yoast (mínimo 100 palavras)

Sitemap XML no WordPress

O WordPress 5.5+ possui um sitemap embutido (/wp-sitemap.xml), mas inclui tudo: páginas de anexo, arquivos vazios, páginas de autor. É melhor usar o sitemap do Yoast SEO:

  • O Yoast SEO exclui automaticamente páginas com noindex
  • Permite configurar separadamente o que incluir
  • Atualiza automaticamente ao publicar novo conteúdo
https://yoursite.com/sitemap_index.xml ← índice do sitemap do Yoast https://yoursite.com/post-sitemap.xml ← posts https://yoursite.com/page-sitemap.xml ← páginas https://yoursite.com/category-sitemap.xml ← categorias

Velocidade do WordPress e SEO

Um site WordPress lento recebe um orçamento de rastreamento menor e tem um desempenho pior. Principais razões para um desempenho lento:

  • Demais plugins (especialmente construtores visuais)
  • Imagens não otimizadas sem WebP
  • Falta de cache (WP Super Cache, W3 Total Cache)
  • Hospedagem lenta ou servidor compartilhado

Erros Comuns do WordPress no Search Console

  • "Descoberto - atualmente não indexado" — geralmente páginas de baixa qualidade ou um problema de orçamento de rastreamento
  • "Duplicado sem canônico selecionado pelo usuário" — versões www e non-www, ou parâmetros de URL
  • "Anomalia do crawler" — plugin ou tema gera URLs errôneas
  • "Soft 404" — página parece vazia, mas retorna um código 200

Checklist de SEO do WordPress para Indexação

  • Yoast SEO ou RankMath instalado
  • Páginas de anexo desativadas
  • Tags sem conteúdo estão fechadas via noindex
  • Arquivos de autor desativados (para um blog de autor único)

  • Velocidade do site testada via PageSpeed Insights
  • Cache configurado
