SEO de E-commerce: Indexação de Produtos e Categorias em 2026

Milhares de produtos, filtros gerando milhares de URLs duplicadas, novos produtos que não aparecem na busca por meses — o e-commerce tem seus desafios únicos de SEO. Analisamos cada um e fornecemos soluções específicas.

Por que as Lojas Têm Problemas Especiais de Indexação

Lojas online são alguns dos sites mais complexos para SEO. Milhares de páginas de produtos, categorias com filtros, paginação, variantes de cor e tamanho — tudo isso cria desafios únicos.

O principal problema: crawl budget. O Googlebot não tem tempo para rastrear todas as páginas, então alguns produtos podem nunca aparecer na busca. Estatisticamente, uma loja online média gera de 5 a 10 vezes mais URLs do que o Google realmente precisa.

Páginas de Produtos: Erros Comuns

  • Descrições duplicadas do fabricante — se você copiar o texto, ele já está em dezenas de sites. O Google escolherá o original, não você.
  • Itens fora de estoque retornando código 200 — "Fora de estoque" em uma página ativa em vez de 404/410 desperdiça o crawl budget.
  • Variantes sem canonical — versão azul e vermelha de um produto em URLs diferentes sem uma tag canonical — duplicatas.
  • Parâmetros de filtro — /category?color=red&size=M gera milhares de URLs duplicadas.
💡 Solução para Variantes de Produtos

Defina uma tag canonical em todas as variantes apontando para a página principal. Ou combine variantes em uma única página com um seletor JavaScript — melhor UX e melhor SEO ao mesmo tempo.

Categorias e Filtros

Páginas de categorias têm as melhores chances de chegar ao topo do Google — elas recebem a maioria dos links internos. Mas há armadilhas:

  • Categorias vazias (0 produtos) — feche via noindex ou exclua.
  • Categorias com 1–2 produtos — combine ou adicione uma descrição textual de pelo menos 200 palavras.
  • Paginação — /category/page/2 deve ser rastreável, mas sem duplicação de título e descrição.
⚠ Filtros — O Principal Inimigo do Crawl Budget

Se uma categoria tem 10 filtros com 5 valores cada — isso são 50 combinações e potencialmente milhares de URLs. Feche-os via robots.txt ou defina canonical para a categoria pai. Deixe abertas apenas combinações com demanda real de busca.

Schema.org Product — Obrigatório

Dados estruturados ajudam o Google a mostrar seus produtos com classificação, preço e disponibilidade diretamente na busca — CTR aumenta de 20 a 35%:

{ "@context": "https://schema.org", "@type": "Product", "name": "Nome do Produto", "offers": { "@type": "Offer", "price": "1999", "priceCurrency": "BRL", "availability": "https://schema.org/InStock" }, "aggregateRating": { "@type": "AggregateRating", "ratingValue": "4.8", "reviewCount": "124" } }

Sitemap para uma Grande Loja

Divida o sitemap em arquivos por tipo de página — isso ajuda o Google a entender as prioridades:

  • sitemap-products.xml — produtos com descrição e disponibilidade, prioridade 0.8
  • sitemap-categories.xml — categorias ativas, prioridade 0.9
  • sitemap-pages.xml — páginas estáticas, prioridade 0.6
  • sitemap-blog.xml — artigos do blog, prioridade 0.7

Indexação Rápida de Novos Produtos

Sem API, um novo produto pode esperar pela indexação de 2 semanas a 3 meses. Para uma loja onde concorrentes já estão vendendo um análogo — isso é crítico.

Google Indexing API resolve o problema: após publicar um produto, envie a URL via API — o Googlebot visitará a página dentro de algumas horas. Especialmente importante para:

  • Itens sazonais e promoções (preço válido apenas por uma semana)
  • Produtos que voltaram ao estoque
  • Atualizações de preços antes das vendas
  • Novas coleções e chegadas

Produtos Excluídos: O Que Fazer

  • Produto temporariamente fora de estoque → deixe a página, marque OutOfStock em Schema.org
  • Excluído permanentemente, tem análogo → redirecionamento 301 para um produto ou categoria semelhante
  • Excluído permanentemente, sem análogo → código 410 Gone (melhor que 404)

Checklist de SEO para E-commerce

  • Descrições únicas para todos os produtos (mínimo 150 palavras, idealmente 300+)
  • Tags canonical em variantes e URLs paramétricas
  • Noindex para categorias vazias e filtros irrelevantes
  • Schema.org Product para todas as páginas de produtos
  • Sitemap segmentado por tipos com prioridades corretas
  • Redirecionamentos 301 ou 410 para produtos excluídos
  • Google Indexing API para produtos novos e atualizados
