Auditoria de SEO do Site: Checklist Completo de 50 Pontos em 2026

Uma auditoria de SEO regular é a única maneira de notar problemas antes que eles afetem significativamente o tráfego. 50 pontos de verificação específicos: desde robots.txt e Core Web Vitals até E-E-A-T e qualidade de backlinks.

O que é uma Auditoria de SEO e por que é necessária

Uma auditoria de SEO é uma verificação sistemática de um site para conformidade com os requisitos dos motores de busca. Ela revela erros técnicos, problemas de conteúdo e oportunidades perdidas para crescimento de classificação. Uma auditoria regular (uma vez por trimestre) permite que você note a degradação antes que ela afete significativamente o tráfego.

Este checklist consiste em 50 itens agrupados por categorias. Passe por eles sequencialmente — cada item não corrigido é um risco para a visibilidade do site na busca.

SEO Técnico (Itens 1–15)

  • 1. HTTPS — o site deve abrir apenas via https://. Verifique os redirecionamentos de http://
  • 2. WWW/non-WWW — uma versão deve redirecionar para a outra (301)
  • 3. robots.txt — o arquivo existe, não bloqueia seções importantes, disponível sem autorização
  • 4. Sitemap.xml — existe, atualizado, registrado no Search Console
  • 5. Códigos de status — sem 200s errôneos em páginas 404 (soft 404)
  • 6. Redirecionamentos — cadeias de redirecionamento não devem ter mais de 2 etapas
  • 7. Velocidade de carregamento — LCP abaixo de 2.5s em dispositivos móveis (PageSpeed)
  • 8. Core Web Vitals — FID/INP abaixo de 200ms, CLS abaixo de 0.1
  • 9. Versão móvel — o site é exibido corretamente em todos os tamanhos de tela
  • 10. Dados estruturados — Schema.org para os principais tipos de páginas
  • 11. Hreflang — configurado corretamente se houver conteúdo multilíngue
  • 12. Tags canônicas — cada página aponta para si mesma ou para a versão principal
  • 13. Paginação — rel="next"/"prev" ou canônica para a primeira página
  • 14. Erros de rastreamento — verifique o Search Console para erros 4xx e 5xx
  • 15. Arquivos de log — Googlebot visita regularmente páginas importantes
💡 Verificação Técnica Rápida

Insira o endereço do site em pagespeed.web.dev — obtenha as pontuações do Core Web Vitals para dispositivos móveis e desktop imediatamente. Este é o primeiro passo de qualquer auditoria técnica.

Indexação (Itens 16–22)

  • 16. Número de páginas indexadas — compare site: com o número real de páginas
  • 17. Noindex em páginas importantes — verifique se há noindex acidental
  • 18. Cobertura do Search Console — revise as categorias "Erro" e "Excluído"
  • 19. Páginas órfãs — páginas sem links internos no relatório de rastreamento
  • 20. Duplicatas no índice — site: mostrará se há várias versões de uma página
  • 21. Sitemap vs Índice — quantos URLs do sitemap estão realmente indexados
  • 22. API de Indexação — a submissão automática de novos URLs está configurada
⚠ Item Crítico: Vazamento de noindex

O erro mais caro em SEO é quando noindex vai para produção a partir do ambiente de teste. Verifique isso primeiro após cada implantação. O Search Console mostrará uma queda acentuada nas páginas indexadas.

SEO On-page (Itens 23–35)

  • 23. Tags de título — únicas, contêm palavra-chave, 50–60 caracteres
  • 24. Meta descrição — únicas, 120–155 caracteres, contém um CTA
  • 25. H1 — um H1 por página, contém palavra-chave
  • 26. Estrutura de cabeçalhos — hierarquia lógica H1 → H2 → H3
  • 27. Palavras-chave no conteúdo — uso natural, sem excesso de palavras-chave
  • 28. Comprimento do conteúdo — mínimo de 300 palavras, para consultas competitivas 1000+
  • 29. Exclusividade do conteúdo — sem duplicatas com outras páginas do site
  • 30. Imagens — tags alt preenchidas, arquivos otimizados (WebP)
  • 31. Links internos — páginas importantes têm links de outras páginas
  • 32. Texto âncora — descritivo, não "clique aqui" ou "leia mais"
  • 33. Estrutura de URL — curta, clara, contém palavra-chave
  • 34. Breadcrumbs — navegação Breadcrumb com Schema.org
  • 35. Conteúdo desatualizado — artigos com mais de 2 anos precisam de atualização

Conteúdo e E-E-A-T (Itens 36–42)

  • 36. Autor do conteúdo — autor listado com biografia e links sociais
  • 37. Data de publicação e atualização — visível na página
  • 38. Fontes e referências — links para fontes autorizadas onde apropriado
  • 39. Páginas Sobre e Contato — informações detalhadas sobre a empresa
  • 40. Política de Privacidade e Termos — documentos atualizados
  • 41. Avaliações e provas sociais — avaliações reais no site
  • 42. Conteúdo raso — páginas com menos de 300 palavras sem valor real

Após a Auditoria — Acelere a Reindexação

Após corrigir erros, acione a reindexação através do IndexFast. O Google verá as páginas atualizadas em algumas horas, não semanas.

Links Externos (Itens 43–47)

  • 43. Contagem de backlinks — verifique via Ahrefs ou Google Search Console
  • 44. Qualidade dos doadores — links de sites temáticos autorizados
  • 45. Links tóxicos — links de spam de sites de baixa qualidade
  • 46. Perfil de texto âncora — âncoras diversas, sem excesso de correspondência exata
  • 47. Backlinks quebrados — links para páginas excluídas ou alteradas do seu site

Análises e Monitoramento (Itens 48–50)

  • 48. Google Analytics 4 — instalado, rastreia conversões corretamente
  • 49. Search Console — site verificado, sitemap adicionado, sem mensagens de erro
  • 50. Monitoramento regular — revisão semanal das métricas principais: tráfego, classificações, indexação

Priorizando Correções

Não tente corrigir tudo de uma vez. Priorize as tarefas:

  • Crítico (esta semana) — noindex em páginas importantes, bloqueios no robots.txt, erros 5xx em massa
  • Importante (este mês) — velocidade do site, duplicatas de conteúdo, tags canônicas ausentes
  • Desejável (próximo trimestre) — atualização de conteúdo antigo, construção de links, Schema.org
