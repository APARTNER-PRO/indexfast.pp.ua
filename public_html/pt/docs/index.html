ℹ️
O que é a API de indexação do Google? Ferramenta oficial do Google para notificar o usuário sobre páginas novas ou atualizadas. Permite enviar para 200 URLs por dia gratuitamente e receba uma resposta dentro de 24 a 48 horas.

⚡ Início rápido

Para começar a usar o IndexFast, você precisa concluir 3 etapas. Todo o processo leva cerca de 10 a 15 minutos.

1
Crie uma conta de serviço no Google Cloud

Vá para console.cloud.google.com, crie um novo projeto (ou selecione um existente) e ative-o API de indexação de pesquisa na Web. Crie uma conta de serviço e carregue uma chave JSON.

Instruções detalhadas estão na seção 🔑 Conta de serviço.

2
Adicionar conta de serviço ao Search Console

У Console de pesquisa do Google adicione o e-mail da sua conta de serviço como delegado o proprietário site

Instruções detalhadas estão na seção 🔗Console de pesquisa.

3
Conecte o site em sua conta pessoal

Cadastre-se ou faça login Gabinete IndexFast. Adicione o site, insira a chave JSON da conta de serviço e a indexação começará automaticamente.

✅ Requisitos

Antes de começar, certifique-se de ter:

1
Conta do Google

Necessário para acessar o Google Cloud Console e o Google Search Console.

2
Site verificado no Google Search Console

Seu domínio deve ser verificado em Console de pesquisa do Google por qualquer método disponível.

3
O arquivo sitemap.xml

Seu site deve ter disponível publicamente mapa do site.xml. IndexFast lê para obter uma lista de URLs para indexar.

4
Chave JSON da conta de serviço

Arquivo baixado do Console do Google Cloud .json com direitos para a API de indexação de pesquisa na Web.

💡
Se o seu site ainda não estiver no Search Console, adicione-o primeiro e confirme a propriedade. Instruções detalhadas estão disponíveis em Site do Google.

☁️ Configurações do Google Cloud

Ativação de API

Acesse o Console do Google Cloud → APIs e serviços → Biblioteca. Encontre "API de indexação de pesquisa na Web" e pressione Habilitar.

⚠️
Importante A API deve estar habilitada no projeto ao qual sua conta de serviço está vinculada. Se a API não estiver ativada, você receberá um erro 403 acessoNãoConfigurado.

Criando uma conta de serviço

Uma conta de serviço é uma conta técnica sem senha que IndexFast usa para autorizar APIs do Google. Para criá-lo, você precisa de um projeto no Google Cloud.

🛠
Antes de começar, habilite a API Indexing em seu projeto via ferramenta de ajuste. Sem esta etapa, você receberá um erro 403 acessoNãoConfigurado.
1
Abra a seção Contas de serviço

Vá para Console do Google Cloud → IAM e administrador → Contas de serviço. Se necessário, selecione o projeto desejado.

2
Clique em "Criar uma conta de serviço"

Digite um nome, por exemplo IndexFast-bote descrição. O identificador pode ser deixado automático. Clique "Criar e continuar".

Seção "Direitos de acesso" não é necessário preencher - clique "Continuar", então "Feito".

3
Crie uma chave JSON

Abra a conta recém-criada → guia Chaves → Adicionar chave → Criar nova chave. Escolha um formato JSON e pressione "Criar".

O arquivo será baixado automaticamente para o seu computador – esta é a única cópia da chave. Mantenha-o em um local seguro e nunca publique-o no Git ou em repositórios públicos.

💡
O arquivo JSON deve ficar assim - se a estrutura for diferente, a chave foi gerada incorretamente.
JSON conta de serviço.json 
{
  tipo: "conta_de_serviço",
  "projeto_id": "seu-id-do-projeto",
  "private_key_id": "abc123...",
  "chave_privada": "-----INICIAR CHAVE PRIVADA RSA-----\n...",
  "cliente_e-mail": "[e-mail protegido]",
  "id_cliente": "123456789",
  "auth_uri": "https://accounts.google.com/o/oauth2/auth",
  "token_uri": "https://oauth2.googleapis.com/token"
}

🔗 Conexão do Search Console

Sem esta etapa, a API retornará um erro 403 Proibido mesmo com a chave correta. A conta de serviço deve receber o status de proprietário do site no Google Search Console.

1
Verifique a propriedade do site

Vá para Console de pesquisa do Google e verifique se o site é seu - por qualquer meio disponível (registro DNS, arquivo HTML, etc.).

2
Copie o e-mail da conta de serviço

Abra o arquivo JSON baixado e localize o campo email_cliente. O e-mail é assim:

nome-da-conta@nome-do-projeto.iam.gserviceaccount.com

Por exemplo: [e-mail protegido]

3
Adicione a conta de serviço como proprietária delegada

No Search Console, selecione seu site → Configurações → Proprietários verificados → Adicionar proprietário. Insira o e-mail da conta de serviço e confirme.

⚠️
A função é exatamente o que é necessário Proprietário (não "Acesso total"). Sem isso, a API retornará 403 Proibido.
4
Aguarde 1-2 minutos

Os direitos não são aplicados instantaneamente. Depois disso, IndexFast poderá enviar URLs para indexação através do seu site.

🗺 sitemap.xml

IndexFast lê seu mapa do site.xml para obter URLs para enviar para indexação. Todos os formatos são suportados.

Formatos suportados

  • ✅ mapa do site.xml — um arquivo padrão com uma URL
  • ✅ sitemap_index.xml — arquivo pai com links para o mapa do site filho (qualquer profundidade de aninhamento)
  • ✅ Mapa do site com tags <último mod> — filtragem por data de atualização

Onde encontrar o URL do mapa do site

Padrão: /sitemap.xml WordPress (Yoast): /sitemap_index.xml Comprar: /sitemap.xml Laravel: /sitemap.xml
⚠️
Importante O mapa do site deve ser acessível publicamente sem autorização. Verifique se o arquivo abre em um navegador sem login. Se estiver fechado, IndexFast não poderá lê-lo.

⚙️ Como funciona o serviço

IndexFast lê automaticamente o seu mapa do site.xml e envia o URL por meio da API de indexação do Google. Nenhum script precisa ser instalado – todas as operações são executadas em servidores IndexFast.

1
Você adiciona um site ao gabinete

Especifique o domínio, URL sitemap.xml e insira a chave JSON da conta de serviço. IndexFast verifica a disponibilidade do mapa do site e salva as configurações.

2
IndexFast lê o mapa do site

O serviço oferece suporte a mapas de sites regulares e Índice do mapa do site (anexos de qualquer profundidade). Os URLs são enfileirados automaticamente de acordo com o limite diário do seu plano.

3
URLs são enviados ao Google

O serviço usa sua conta de serviço para autorização e envia o URL por meio da API oficial de indexação do Google. Você vê o resultado em tempo real na sua conta pessoal.

📊
Os limites dependem do plano: Início — 10 URLs/dia, PRO — 100 URLs/dia, Agência — 1000 URLs/dia. O limite é atualizado todos os dias às 00h00.

🤖 Agendamento automático

IndexFast inicia a indexação automaticamente — não há necessidade de configurar o cron ou manter um servidor. O serviço funciona 24 horas por dia no lado IndexFast.

💡
Para iniciar a indexação manualmente, pressione "▶ Lançamento" em sua conta pessoal ao lado do site desejado. O resultado aparecerá nos logs em um minuto.

Como gerenciar a indexação

1
Modo ativo

Site com status Ativo envia URLs automaticamente dentro do limite diário. O limite é dividido igualmente entre todos os sites ativos da conta.

2
Pausa

Se você precisar interromper temporariamente a indexação do site - clique "⏸" no escritório O limite diário não é gasto. Você pode restaurar a qualquer momento.

3
Início manual

Clique "▶ Lançamento" – e IndexFast enviará imediatamente o URL do mapa do site dentro do restante do limite diário. Conveniente após a publicação de novas páginas.

🖱 Indexação manual

Além do modo automático, IndexFast permite iniciar a indexação manualmente a qualquer momento - diretamente de sua conta pessoal.

1
Abra o gabinete

Vá para indexfast.pro/app/dashboard e encontre o site desejado na lista.

2
Clique em "▶ Iniciar"

IndexFast lerá instantaneamente o mapa do site e enviará o URL dentro do limite diário restante.

3
Veja os resultados nos registros

As respostas da API do Google aparecem na guia Logs dentro de 1 a 2 minutos. Você pode ver o status de cada URL: 200 OK, 403, ou outra resposta.

ℹ️
A indexação manual usa o mesmo limite diário da indexação automática. Se o limite for atingido, o IndexFast colocará a URL na fila para o dia seguinte.

📡 Referência da API

Autorização

A API de indexação do Google usa OAuth 2.0 através da conta de serviço. IndexFast lida com a autorização automaticamente – você só precisa da chave JSON.

Endpoint para receber um token:

HTTP
PUBLICAR https://oauth2.googleapis.com/token

Tipo de conteúdo: aplicativo/x-www-form-urlencoded

tipo_de_concessão=urna:ietf:params:oauth:grant-type:jwt-bearer
&afirmação={JWT_TOKEN}

Envio de URLs para indexação

ParâmetroTipoObrigatórioDescrição
urlcordaobrigatórioURL completo com https://
tipoenumeraçãoobrigatórioURL_ATUALIZADO ou URL_DELETED
HTTP
PUBLICAR https://indexing.googleapis.com/v3/urlNotifications:publicar

Autorização: Portador {ACCESS_TOKEN}
Content-Type: application/json

{
  "URL": "https://seu-site.com/new-page",
  tipo: "URL_ATUALIZADO"
}

Resposta bem sucedida:

JSON
{
  "urlNotificaçãoMetadados": {
    "URL": "https://seu-site.com/new-page",
    "última atualização": {
      "URL": "https://seu-site.com/new-page",
      tipo: "URL_ATUALIZADO",
      "notificarHora": "2026-01-20T10:30:00Z"
    }
  }
}

Verificação do status do URL

HTTP
PEGAR https://indexing.googleapis.com/v3/urlNotifications/metadata
    ?url=https://seu-site.com/page

Autorização: Portador {ACCESS_TOKEN}

❓ Perguntas frequentes

Quanto tempo leva a indexação após o envio?

O Google geralmente processa solicitações dentro 24–48 horas. Na maioria dos casos, as páginas aparecem na pesquisa na manhã seguinte ao envio.

É possível enviar mais de 200 URLs por dia?

200 URLs é o limite gratuito padrão do Google. Se necessário, você pode solicitar um aumento de limite por meio do Console do Google Cloud. IndexFast para automaticamente quando o limite é atingido e retoma no dia seguinte.

É seguro para SEO usar a API de indexação?

É sim oficial método recomendado pelo próprio Google. Não há risco de penalização ou rebaixamento – pelo contrário, uma indexação mais rápida melhora a competitividade.

Índice do Sitemap ou Sitemap normal?

IndexFast oferece suporte a ambos os tipos. Se você passar o link para sitemap_index.xml — o script ignorará automaticamente todos os arquivos anexados e salvará todos os URLs.
