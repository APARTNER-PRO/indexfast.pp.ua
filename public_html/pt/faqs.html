IndexFast é um serviço web que automatiza a indexação de páginas no Google através da API de Indexação oficial. Conecte seu GSC uma vez, adicione o sitemap, e IndexFast envia automaticamente todas as páginas para indexação.

Cria uma Conta de Serviço no Google Cloud e usa o endpoint indexing.googleapis.com para notificar o Google sobre páginas novas ou atualizadas.

Após o envio pela API de Indexação, o Google indexa as páginas em 24–48 horas, em vez das 2–8 semanas habituais.

Configuração em ~10 min: crie projeto no Google Cloud, ative a Indexing API, crie Conta de Serviço, adicione o email como Proprietário no GSC, e faça upload da chave JSON no IndexFast. Guia completa: Documentação.
